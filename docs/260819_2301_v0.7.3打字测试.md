# 三个长文本打字测试（v0.7.3）

v0.7.3 沿用真实命名管道逐键回放门禁，覆盖 `tests/data/real_world_text_corpus.txt` 中三个长文本、翻行、数字选字、空格提交与标点提交。

本版改的正是按键热路径本身。每一次按键现在可能跑三轮候选生成：完整读法一轮，词尾回退 1 个音节一轮，回退 2 个音节再一轮（仅全拼，且仅当最后一个音节还能生长时）。每轮各自包含一次有界动态规划拼接和一次未完成音节补全，补全前还要查一次长词前缀取上下文读法。逐键回放因此是这项改动最直接的性能门禁。

回退读法只对全拼开启。双拼一个音节固定两键，读法不随下一次按键生长——这条限制本身就是被 `piinput-host-process` 的逐键回放拦下来的：未加 schema 判断的版本里，小鹤 `xnhe` 首选变成了键盘拼不出的「小黑」。
