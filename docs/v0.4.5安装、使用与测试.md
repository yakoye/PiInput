# PiInput v0.4.5 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.4.5-dev-windows-x64.zip`，不要在压缩包预览窗口中直接运行；
2. 可先双击 `PiInput-Test.exe` 测试词库和候选；
3. 双击根目录 `PiInput-Install.exe`，在系统询问管理员权限时选择“是”；
4. 安装完成后关闭安装窗口；
5. 在要测试的程序中按 `Win + Space`，选择“PiInput 中文输入法（开发版）”。

## 基本使用

- 默认输入方案由设置文件决定，可使用全拼或小鹤双拼；
- 输入字母后默认只显示一行候选；
- 空格确认当前候选，Enter 提交当前输入；
- 数字 `1`～`9` 选择当前行候选；
- 左/右方向键移动当前候选；
- `=` 或下方向键显示下一行；没有可靠整词时进入单字/分段取字；
- `-` 或上方向键返回上一行；
- Esc 取消当前组合；
- 单独按 Shift 切换中文/英文。

## 本版重点测试

### 候选框稳定

1. 在 Notepad4 输入 `woxmzd` 或小鹤对应编码；
2. 每输入一个字母，观察候选框外框；
3. 在按空格或 Esc 前，候选框的左边、上边和宽度应保持不动；
4. 按 `=` 时只允许高度增加，不允许左右跳动。

### 空格和 Enter

1. 在 Codex、Notepad4 分别输入 `woxmzd`；
2. 按空格应把当前候选写入文本框；
3. 再输入一组拼音并按 Enter，应完成提交；
4. 即使目标程序暂时拒绝同步编辑，也不应吞掉原拼音或让候选永久消失。

### 切换窗口

1. 输入一部分拼音但不提交；
2. 切换到另一程序再切回来；
3. 继续输入时，候选应在当前文本插入点附近恢复；
4. 不应沿用另一程序的候选位置。

## 卸载

双击解压目录根部的 `PiInput-Uninstall.exe`。普通卸载保留用户词库、设置和学习数据，除非卸载界面明确提供并由你主动选择删除用户数据。

## 出现问题时提供什么

请提供：测试程序名称、输入编码、按下的确认键、候选截图，以及安装包版本。不要只截图候选内容，尽量同时包含文本插入点和候选框位置。
