# PiInput v0.8.0 版本说明

v0.8.0 让中文输入时也能打出英文单词。这项功能默认关闭，开启前后中文输入的行为完全一致。

本版同时包含 v0.7.16 的全部修复：升级后重启不再丢失程序文件、Windows 搜索里能看到候选、安装器有了界面、一键更新的 UAC 从两次降到最多一次。

## 中文模式英文候选

真正解决的问题是**拼写辅助**：忘了一个词怎么拼，打出记得的前几个字母，让输入法补出来。

```text
belie   →  believe  believed  belief
info    →  information  info  informed
palad   →  palladium
```

打开方式：设置程序的英文页，勾选「中文输入时也给出英文候选」。这一项与「英文模式下启用英文候选」相互独立，英文模式的行为不受任何影响。

### 什么时候会出英文

同一串字母既是拼音又可能是英文词。这里的标准只有一条：**打字过程中不该频繁冒出英文，而真想用英文的时候要能匹配出来。** 按这条标准标定的结果是按输入长度分档：

| 输入长度 | 行为 |
| --- | --- |
| 1–2 个字母 | 完全不给。双拼下两个字母正好是一个音节，而那里住着「我」和「的」，英文赢不了 |
| 3 个字母 | 只认完整的词，且只查基础词库。中文足够常用时直接放弃 |
| 4 个字母 | 可以按前缀补全，但仍只查基础词库 |
| 5 个字母及以上 | 打开完整词库，拼写辅助的主场 |

三个字母那一档最容易误伤，因为双拼下三个字母必然是词打到一半：`wom` 是「我」加个 m，`car` 是「擦」加个 r。所以那里除了要求把词打完整，还要看中文有多确定——`bus` 对应「不是」，那是你真正想打的，不给英文；`car` 对应「擦」，就给。

**把词完整打出来永远算数，再生僻也给。** `bucolic` 会出，`bucoli` 不会——差别不在这个词有多冷僻，而在有没有打完。

一次最多两个英文候选。全词命中且不超过四个字母时只给这个词本身，不会连带拖出 `catch`、`cathedral` 这类同前缀的长词。

顺带清掉了一批混进英文词库的汉语拼音。词频统计的是真实英文文本，而拼音在英文语境里出现得不少，`hao`、`xie`、`dui`、`mei`、`zhong` 因此都成了「英文词」，权重和 `car`、`cat` 挤在一起。它们已在词库生成阶段剔除，`can`、`he`、`me`、`man`、`men`、`sun`、`tan` 这些同样是合法音节的真英文词不受影响。

### 快捷命令不受影响

`calc` 打开计算器、`sj` 给出时间这类快捷码是手工配置的，它们的候选编号不会因为混入英文而改变。英文候选一律排在快捷命令之后：

```text
calc  →  1 中文候选   2 计算器   3 calculate   4 calculation
```

固定候选和删除候选作用于词库，因此对英文候选直接拒绝，不会误伤同位置的中文词。

### 词库

英文词库扩充到约 25 万词，分三层：

| 层 | 规模 | 内容 |
| --- | --- | --- |
| 高频层 | 24,180 | 原有词表（原 24,323，剔除混入的拼音后剩余），日常高频词永远排在最前 |
| 中频层 | 26,350 | 按真实词频收录，`palladium`、`paladin`、`obsidian` 都在这层 |
| 低频层 | 199,999 | 覆盖用，只保证打得出来 |

分层是必需的而不是优化：只有词形没有词频时，`palad` 会被 `palladia`、`palladic` 这类同前缀的生僻词按词长挡在三个候选之外，而这两个词在词频统计里根本不存在——正说明没人用它们。

词库数据来自 dwyl/english-words（Unlicense，公有领域）与 wordfreq（数据 CC BY-SA 4.0，须署名 SUBTLEX 作者）。完整许可证、来源与取用方式随包安装在 `bin/licenses/EnglishWordlist/`，另见 `LICENSE_NOTICE.md`。

### 学习

选中的英文词会被记住，与英文模式共用同一份学习数据——在哪个模式打过这个词，并不影响下次是否还想用它。词库再大也覆盖不到领域专名，打过一次即可补全，这是长尾唯一的出口。

## 来自 v0.7.16 的修复

- **升级后重启不再丢失程序文件。** 旧版升级是「先卸载再安装同一批路径」，卸载时被占用的文件删不掉，就把整棵安装树排进了系统的重启待删队列；安装器随后把新文件写回同样的路径，装完当场可用，下一次重启却被系统按队列删光，只剩注册表。现在删不掉的文件先改名到一次性路径再排队，稳定路径永不进队列。
- **Windows 搜索里能看到候选了。** 此前候选窗其实一直在画，只是被搜索面板盖住——它绘制在普通置顶窗口无法逾越的层级上。候选窗现在避开面板摆放，且只对 Windows 搜索生效，其余程序位置逐像素不变。
- **安装器有了界面**：确认页说明装到哪里、为何需要一次管理员权限，安装过程有进度条，完成页把「打开设置」改成可勾选而非强制弹窗。
- **一键更新改为原地覆盖升级**，UAC 提示从两次减到最多一次，Shim 未变时一次都不需要。
