# PiInput v0.6.1-dev 安装、使用与测试

## 安装

1. 解压 `PiInput-v0.6.1-dev-windows-x64.zip`。
2. 双击 `PiInput-Install.exe`。
3. 接受 Windows 管理员权限提示。
4. 完全关闭并重新打开用于测试的编辑器。
5. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版测试

请在 Notepad++ 中不间断输入：

```text
我，他们。我们明天，去哪里？明天、后天！打后天。
```

重点观察：

- 标点之后继续输入文字时，组合区和候选是否立即跟上；
- 每次按键后候选是否随即刷新，而不是滞后一两个字母；
- 候选框位置是否稳定，不再随每次按键闪动；
- 最终文字是否完整且顺序正确。

本版只做性能修复，候选内容和顺序与 v0.6.0 一致。如果发现某个词的首选发生变化，属于回归，请反馈。

## 卸载

在 Windows“已安装的应用”中卸载 PiInput，或运行安装目录中的 `PiInput-Uninstall.exe`。
