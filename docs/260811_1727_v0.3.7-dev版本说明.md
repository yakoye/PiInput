# PiInput v0.3.7-dev 版本说明

## 英文候选基础完善

- 随 Windows 包提供 24,323 个带词频的离线英文单词，不再只带 43 个开发示例词；
- 叠加独立的金融、市场和技术补充词表；
- 当前原始输入始终保留为第一候选，未收录的名称和缩写也能直接上屏；
- 真正的前缀候选按用户词、学习次数、基础词频、补全长度和稳定 ID 排序；
- 输入至少三个字母、真正前缀不足时，才追加少量有界近似候选；
- `r/re/rev/reve`、`b/bo/boo/book` 已建立逐键回归；
- 用户提供的市场、科技和金融段落已建立逐词自动补全回归；
- `book` 可得到 `books`、`booked`、`booking` 等词形；
- 英文候选仍默认关闭，由 `[english] enabled=true` 开启。

## 数据来源

基础词频来自固定提交的 `aparrish/wordfreq-en-25000`，转换结果按 CC BY-SA 4.0
随包分发；来源、提交、原始文件 SHA-256 和许可证链接记录在 `LICENSE_NOTICE.md`
与 `dictionary_sources.json`。

## 保持不变

- 纯离线输入，无 AI、语音、广告和云端实时联想；
- 中文全拼、小鹤双拼、精确诗句和分段取字逻辑不变；
- 安装器不自动切换输入法；
- 本版只生成安装包，不自动安装、不推送仓库。
