# PiInput v0.4.3-dev 验证记录

验证环境：Windows x64、MSVC 19.51、Visual Studio 18 Build Tools、Windows SDK 10.0.26100.0。

## 测试驱动证据

- RED：新增测试台英文模式门禁后，`piinput-windows-source-regression` 因缺少 `EnglishSession` 和中英文模式失败；
- GREEN：接入英文词库、模式控件和多行测试文本后，定向源码回归与英文词库测试通过。
- RED：Windows 源码门禁确认 Host 单实例锁发生在大词库加载之后、Shim 冷启动仅等待 500 ms；
- GREEN：单实例锁前移到运行时初始化之前，Shim 后台冷启动改为有界 5 s，首个中文字母在握手期间也会排队；
- RED：候选窗没有在计算尺寸和 caret 间距前取得目标显示器 DPI；
- GREEN：候选窗采用隐藏的两阶段定位，125%/200% 缩放间距和工作区约束测试通过；
- RED：真实大词库首个客户端因前缀缓存未建立约需 458 ms；
- GREEN：Host 健康状态发布前预热 26 个首字母，同一 501,935 词库首客户端降至约 26 ms。
- RED：默认移除完整低频单字表后，7000 通用字覆盖为 6993/7000，缺少 7 个极低频字；
- GREEN：只把 `塃、塮、揾、檵、礳、耲、葓` 的公开读音加入精选补漏表，101,469 条热词库恢复全拼和小鹤 7000/7000 覆盖；
- GREEN：默认热词库从 16.75 MB 降到 4.00 MB，核心加载约 96 ms；真实 Host 进程测试为冷启动 384 ms、首客户端 24 ms、第二客户端 16 ms。

## 最终验证

- Visual Studio 18 / MSVC Release 全目标单并发构建：通过；
- 完整 CTest（功能、Windows 源码、SHA、真实外部词库和性能）：51/51 通过，0 失败；
- `resident-hot-v1`：101,469 条、4,004,169 字节；3500/7000 汉字全拼与小鹤覆盖均为 100%；
- 10,000 次 `wo` 查询：加载约 96 ms，P50 约 24 微秒、P95 约 38 微秒、P99 约 79 微秒；
- 任意长度增量输入 `biruwoycuibuv`：三轮 P95 中位数约 452 微秒、P99 中位数约 581 微秒；
- 真实 Host 进程：冷启动及 26 首字母预热约 384 ms，首客户端约 24 ms，第二客户端约 16 ms；
- 125% 实机候选窗截图检查：字体清晰、默认单行、文本光标下方 5 物理像素；200% 间距由几何回归验证为 8 物理像素；
- 发布目录中的 `piinput-base.lex` 与外部已验证缓存大小及 SHA-256 一致；
- 最终 ZIP 已重新解压检查，安装器、卸载器、独立测试台、稳定 TSF、Host、符号数据、热词库和中文使用文档齐全；
- 本轮只构建、验证和打包，不安装、不激活、不修改当前系统输入法。
