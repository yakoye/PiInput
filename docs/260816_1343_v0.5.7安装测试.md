# PiInput v0.5.7 安装、使用与测试

## 安装或升级

1. 完整解压 `PiInput-v0.5.7-dev-windows-x64.zip`。
2. 双击根目录的 `PiInput-Install.exe`。
3. Windows 管理员确认出现时选择“是”。
4. 安装完成后，在目标程序中按 `Win + Space`，选择“PiInput 中文输入法”。

已有 PiInput 时直接运行安装程序升级，不需要先卸载。安装器使用固定 TSF 入口，输入核心与词库由独立 Host 统一提供；普通升级保留 `%LOCALAPPDATA%\PiInput\UserData` 中的设置和学习数据。

## 常用输入

- `Space`：上屏当前候选；
- `1`～`9`：选择当前选中行中的候选；
- `=` / `↓`：展开并向下一行，选中该行第一项；
- `-` / `↑`：向上一行，选中该行第一项；
- `←` / `→`：在当前行内移动；
- 单独按 `Shift`：切换中文和英文；
- `Enter`：上屏原始字母；
- `Esc`：取消当前组合和候选框。

候选默认只显示一行。第一次按 `=` 后显示设置的多行数量；继续按 `=` 会让候选像队列一样逐行向下滚动，第一行可以离开视野。系统先浏览所有真实词语，词语耗尽后才进入分段取字；进入取字后，原整词候选仍保留在同一候选队列中。只有当前选中行显示数字。

## 设置

候选栏右侧四格按钮打开菜单，再选择“设置”。可设置：

- 全拼或小鹤双拼；
- 默认中文或英文；
- 每行候选数量；
- 展开候选行数（1～6，默认 3）；
- 候选字体大小与单行高度；
- 中文标点风格和英文候选。

设置文件位于 `%LOCALAPPDATA%\PiInput\UserData\settings.ini`。展开行数对应：

```ini
[candidates]
visible_rows=3
```

可以设置为 1～6；修改后在下一次组合时生效。

## 本版建议测试

1. 小鹤输入 `mktm`，首选应为“明天”。连续按 `=`：每次选中下一行首项，三行窗口持续滚动；非当前行不显示数字。
2. 全拼输入 `mingtian`，行为与小鹤一致；真实词语浏览完后才出现“明、名、命”等单字。
3. 分段选择“开”与“悟”并成功上屏一次，再输入 `kaiwu` 或小鹤 `kdwu`：下一次“开悟”应进入第一行。
4. 输入全拼 `sihua` 或小鹤 `sihx`：首选应为“丝滑”。
5. 输入较长全拼 `wojintianxiawuyaoquchaoshimaidianshuiguo`，候选应在输入过程中持续响应，无明显逐键卡顿。

## 卸载

双击根目录 `PiInput-Uninstall.exe`，或从 Windows“设置 → 应用 → 已安装的应用”卸载 PiInput。默认保留用户数据；只有明确选择删除用户数据时才移除 `%LOCALAPPDATA%\PiInput\UserData`。

## 发给别人

只发送完整的 `PiInput-v0.5.7-dev-windows-x64.zip`。发布包已经包含程序、基础二进制词库、符号和英文候选数据，不需要发送开发用的外部 `dicts` 目录。
