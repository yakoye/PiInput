# PiInput v0.6.0-dev 版本说明

本版只处理连续输入时出现的固定约五秒卡顿，不增加新功能。

## 修复内容

- 稳定 TSF 入口不再为每个失败请求等待 5000 毫秒；
- Host 首次不可用时只执行一次、最多 750 毫秒的冷启动连接；
- 同一故障窗口内后续按键快速返回，避免在 FIFO 队列中堆积后批量补字；
- 1750 毫秒后允许一次新的有界重连；
- Host 恢复后自动清除断线状态。

## 实测依据

用户视频中多次出现约 5.1～6.0 秒没有界面更新。当前机器完全停止 Host 后重新启动到健康响应约 357 毫秒，因此 750 毫秒预算能够覆盖正常冷启动，同时避免永久阻塞输入。

## 验证句

```text
我，他们。我们明天，去哪里？明天、后天！
```

请连续输入，不要故意停顿，重点检查标点前后是否还会冻结并在数秒后批量出现。
