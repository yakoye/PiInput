# PiInput v0.7.8 版本说明

本版处理 v0.7.7 反馈的四件事。

## 候选窗右键菜单点别处不消失

菜单弹出后点其他地方关不掉，只能一直挂着。

候选窗带 `WS_EX_NOACTIVATE`，永远不会成为前台窗口，而弹出菜单的宿主窗口如果不在前台，菜单就不响应外部点击。现在菜单交给一个隐藏的普通窗口托管，点击外部和按 Esc 都能关闭。

## 候选可以用鼠标点选

左键点候选直接上屏，和按对应数字键一样。右键仍然是「固定首位／删除该词／取消固定」。

实现上，Host 只知道点中了哪个候选，把文字送进应用是输入法端的事，所以 Host 把候选 id 交回给输入法，由它走正常的选词路径提交——与数字键完全同一条路。

## 托盘图标左边多了中/英

其他输入法在图标旁边放的那个中/英指示，现在也有了：托盘里是两个图标，左边显示当前是「中」还是「英」，右边是 PiInput 图标。点任意一个都能切换语言。

Windows 不允许在一个通知图标里放两个元素，所以它确实是第二个图标——图标上的字是按当前状态实时画出来的。

## 托盘「符号」调用外部工具

菜单里的「符号」现在启动你自己的符号程序，点一下直接打开。

在设置窗口「标点符号」页填上完整路径，或者在 `settings.ini` 里写：

```ini
[general]
symbol_tool=D:\你的路径\yesymbol.exe
```

没有配置时，会先找程序目录下的 `yesymbol.exe`；再找不到就提示怎么设置。

## 验证

完整 CTest 60/60 通过。设置往返测试增加了符号工具路径这一项。
