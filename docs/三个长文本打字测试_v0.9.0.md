# 三个长文本打字测试（v0.9.0）

v0.9.0 继续执行三组真实文本逐键回放、段落输入、结构化语料和逐键延迟门禁，结果与 v0.8.6 一致，无回归。

本版新增的两件东西都在正常输入路径之外：常用语只在触发码命中时才进入候选行，数字建议只在没有合成串且打出的数字串匹配到某条常用语时才出现。默认配置里**常用语表是空的**，所以语料回放不经过任何新代码，结果预期逐字节不变。

## 本版必须复验的项

- **回放输出与 v0.8.6 逐字节一致。** 默认配置下新路径一条都走不到。出现任何差异都要查清原因。
- **数字一个都不能丢。** 这是本版风险最集中的地方：数字建议的整个设计前提就是「数字键没有被改动」。语料里的数字、编号、小数、日期必须逐字符如实输出。统计输入的数字键次数与输出中的数字个数是否相等。
- **标点数量守恒。** 沿用 v0.8.6 的检查：每一个按下的标点都必须到达文档。
- **延迟门禁未退化。** 常用语匹配是纯字符串比较，中文触发码的词库反查放在设置加载时做一次、不在按键路径上；数字建议只在没有合成串时才可能触发。三条都不应出现在 p95 里。
- **v0.8.4 – v0.8.6 的修复仍然有效**：横杠可输入、句号形态由提交文本决定、候选解析耗尽时标点不被丢弃。

## 真实应用手工测试

必须使用验证记录中的同一 build ID。**每个受测程序都要完全退出重开**——输入法组件是 DLL。

1. **数字输入完全没变**（最重要）：记事本、浏览器地址栏、远程桌面地址框里打 `123`、`0.8.1`、`2026`，逐字符如实输出，不弹任何候选框。
2. **没录常用语时与上一版无差异**：不添加任何常用语，打一段完整中文。
3. **别名常用语**：`dzjl` → 中文地址，候选框第 2 位，选中后完整上屏。
4. **中文内容留空触发码**：保存后重开设置，触发码列应显示「（自动）按首字拼音声母」；打首字声母能命中。
5. **数字补全**：`15801616544` 留空触发码，打 `158` 出建议，按 `Tab` 得到完整号码；按空格或回车**不应**补全。
6. **填了触发码的数字常用语**：打它开头三位不应再弹建议。
7. **常用语不进学习**：反复选用后再打同一触发码，不应出现重复的整条内容。
8. **升级不中断已开程序**：装上本版后不重启任何已打开的程序，在其中继续打字应正常工作。
