# 三个长文本打字测试（v0.7.7）

v0.7.7 没有改动按键处理路径。托盘图标与设置窗口都在按键热路径之外：托盘只在收到鼠标消息时工作，设置窗口是独立进程。

托盘窗口与候选窗共用 Host 主线程，因此它依赖 v0.7.6 修好的消息泵；逐键回放同时覆盖了这一点——如果消息泵回退，托盘菜单和候选窗点击会一起失灵。
