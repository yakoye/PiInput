# PiInput v0.9.1 版本说明

小版本，只做一件事：设置里新增「关于」页。

## 设置 → 关于

此前「关于」只有语言栏右键里那个消息框，它显示版本号和构建标识，但消息框画不了图。现在设置程序里有一页真正的「关于」：

- 版本号、构建标识、构建时间、Git commit、项目地址
- 页面下方一行小字加两个小二维码：**♥ 觉得不错？请作者喝杯咖啡～**

**刻意做得不显眼。** 二维码各约 100px，靠页面左下，底下留大片空白；上面那句话只说一次。不滚到那儿就看不见，不想理会它就完全可以不理会。

语言栏右键的「关于」没有放码，只加了一行「赞赏作者：设置 → 关于」。那个框是查版本号用的，往里塞二维码会把一次查询变成一次劝捐。

### 两处实现上的取舍

**红心配蓝字需要自绘。** `WM_CTLCOLORSTATIC` 给的是整个控件一个颜色，拆不开一行。先用红色画心、量出宽度，再用蓝色接着画后半句。

**心用 `♥`（U+2665）而不是 `♥️`（U+2764 + 变体选择符）。** 后者会被当成 emoji 交给 Segoe UI Emoji 彩色渲染，那条路上 `SetTextColor` 不起作用，红不红要看字体脸色。

**GDI+ 只链给设置程序。** 它是独立 exe，不是注进别人进程的 DLL，所以这个依赖没有活动上下文方面的风险；同样的事放在 shim 里就不能这么做。图加载不到或解码失败就整块不画——不留占位、不弹错。赞赏入口缺席不该打扰任何人。

## 没有改动的部分

输入、候选、协议、安装器全部未动。v0.9.0 的常用语和安装向导原样保留，协议仍是普通报文发 v5、`digit_run` 发 v7。
