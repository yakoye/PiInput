# PiInput 词库查询与分段取字

## 候选页顺序

PiInput 先按固定顺序展示完整用户词、静态整词和真实同音词。`=` / `↓` 每次只进入下一行并选中第一个；`-` / `↑` 返回上一行并选中第一个。正常词语页耗尽后，再按一次 `=` 才进入分段取字，不会在词语页中间突然跳到单字。

分段取字只查询当前剩余拼音可命中的真实词段：长词段优先，单字兜底。已经选择的文字保留在组合区，全部拼音处理完后只上屏一次。成功上屏的两字及以上组合会成为本地用户词；下一次相同标准拼音输入时进入第一行。

删除误学词不会重排或重写基础词库。PiInput 只删除该词的学习状态并保存本地屏蔽记录，当前候选后的项目立即向左补位。取消固定与删除是两个独立动作。

适用范围：全拼、小鹤双拼、离线中文词库。

## 一、两类长输入

PiInput 现在区分两类长输入：

1. 词库中存在完整词条：完整词条优先，不再被逐字拼接结果压过；
2. 词库中不存在可靠整句：按 `=` 或 `↓` 进入分段取字，逐段选择，最后一次性上屏。

例如：

```text
小鹤：hlheruhdlq       → 黄河入海流
全拼：huangheruhailiu → 黄河入海流
```

`黄河入海流` 来自本地诗词词库，完整拼音命中时排第一。候选内部保留“完整词库词条”和“逐字拼接路径”的来源信息，因此不会只靠最终分数猜测候选是否可靠。

## 二、分段取字

候选窗默认仍只显示一行。

- 如果下一行还有可靠词库候选，按 `=` / `↓` 正常下移一行；
- 如果后面只剩逐字拼接的低可信结果，按 `=` / `↓` 进入分段取字；
- 分段模式只显示第一个未解决位置的词语或单字，不自动伪造剩余整句；
- 数字键或空格选中一段后，该段保留在组合区，不立即写入应用；
- 所有音节都选完后，已选文字一次性上屏；
- `Backspace` 优先撤销最近选中的一段；
- 在分段模式第一行按 `-` / `↑`，返回普通候选；
- `Esc` 第一次退出分段模式，第二次才取消整个组合。

这种方式适合不存在于词库的长输入，也适合逐段修正长句。选择过程中不会把半句写入应用，因此可以回退修改。

## 三、查询本地词库

双击仓库或发布包根目录中的：

```text
query-dictionary.cmd
```

输入中文词语时按词条反查：

```text
黄河入海流
```

输入带单引号的标准拼音时按拼音精确查询：

```text
huang'he'ru'hai'liu
```

默认查询当前用户正在使用的离线词库：

```text
%LOCALAPPDATA%\PiInput\UserData\lexicons\piinput-imported.lex
```

也可以在命令行中查询：

```powershell
.\piinput-cli.exe --lexicon <词库路径> --lookup-word 黄河入海流 --top 20
.\piinput-cli.exe --lexicon <词库路径> --lookup-pinyin "huang'he'ru'hai'liu" --top 20
```

词语反查使用延迟创建的索引，普通输入启动时不会为该功能额外扫描完整词库。

## 四、更新本地词库

大型源词库继续放在源码仓库同级的外部目录：

```text
C:\Users\color\Downloads\PiInput\dicts
```

双击：

```text
update-dictionaries.cmd
```

构建脚本会合并通用词库、单字读音、诗词、成语以及能够解析的本地 SCEL，生成新的 `piinput-imported.lex`。诗词和成语使用独立低权重来源；只有完整拼音精确命中时才获得完整词条优势，不会无条件污染日常首选。

本次构建同时生成：

```text
dicts\generated\dictionary-build-report.tsv
```

报告区分整词读音、逐字推导读音和无法解析条目，便于检查词库质量。

## 五、验证示例

```text
hlheruhdlq       → 黄河入海流（小鹤，首选）
huangheruhailiu → 黄河入海流（全拼，首选）
```

若某个长输入没有完整词条，普通候选只保留第一行即时猜测；继续按 `=` 后应看到分段候选，而不是多行无意义的完整伪句子。
