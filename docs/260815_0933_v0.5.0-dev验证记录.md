## 多显示器定位

- 正式输入链路继续优先使用 TSF 文本插入光标坐标；仅在应用不提供文本布局时退回鼠标位置；
- 候选内容增长、展开候选行以及打开工具菜单后都会再次限制到原文本光标所在显示器的工作区；
- 自动测试覆盖主屏右侧显示器、主屏左侧负坐标显示器和 150% DPI；
- 便携视觉测试程序不再使用固定屏幕坐标，而是根据当前前台窗口生成测试锚点，避免测试窗口误跑到另一块屏幕。
