# PiInput v0.7.6 安装、使用与测试

## 安装

直接双击最外层 `PiInput-Install.exe`，不需要先卸载。安装完成后点「确定」会自动打开设置目录。

确认版本：

```text
%LOCALAPPDATA%\PiInput\bin\PiInputHost.exe --build-id
```

应输出 `0.7.6`。

## 本版重点测试

### 一、微信里候选窗不再压住文字

在微信输入框里打 `xianzai`：候选窗应该完整地落在**正在输入的那行文字下方**，不遮住已经打出来的拼音。

顺带在别的程序里也各打一次（记事本、Chrome、VS Code），确认它们的候选窗位置**没有变化**——本版只把过矮的插入点补足到一行高，报告正常行高的程序不受影响。

### 二、候选窗鼠标点击（关键）

1. 记事本里输入 `nihao`，候选窗出现；
2. **停手等 3 秒以上**——这一步很重要，以前正是「停下来再点」才卡；
3. 点右侧展开按钮 `∨`：应立刻展开多行；
4. 点右侧菜单按钮：应立刻弹出；
5. 直接点某个候选词：应立刻上屏；
6. 在候选词上点右键：应弹出「固定首位 / 删除该词 / 取消固定」。

判断标准：**每一次点击都要立刻响应**。以前是点了毫无反应、窗口像死掉，然后一敲键盘又突然生效。

### 三、候选词用完之后有单字

全拼下依次输入，按 `=` 或 `↓` 往后翻：

```text
mk     前面是词（模块 门口 煤矿…），后面应接上单字：吗 没 面 明 名 马 美 命 目 满 魔 们…
dddyn  词很少（动荡的一年 短短的一年），后面应接上 d 开头的单字
sdsf   词之后应接上 s 开头的单字
```

以前这三个都是词给完就断了。

### 四、设置窗口

双击 `%LOCALAPPDATA%\PiInput\bin\PiInput-Settings.exe`，应弹出标题为「PiInput 设置」的窗口。

再双击一次：不应开出第二个窗口，而是把已有窗口拉到前面。

### 五、确认没有引入卡顿

连续打一段长文本，逐键不应有卡顿感。本版改了 Host 等待按键的方式，这一条是回归检查。

## 如果候选窗位置还有问题

光标定位日志可以直接抓到数据：

1. 在 `%TEMP%` 下建一个空文件 `piinput-caret-trace.on`；
2. 复现一次；
3. 把 `%TEMP%\piinput-caret-trace.csv` 的最后几十行发来。

字段是 `has_caret` 和 caret/bar 两个矩形，能直接看出程序报的插入点位置和候选窗的实际落点。

## 本版没有做的

- 系统托盘与右键设置菜单；
- 程序内直观的版本号显示（目前只能靠上面那条命令）。

这两项是同一件事的两面，托盘右键菜单就是版本号最自然的位置，留到一起做。
