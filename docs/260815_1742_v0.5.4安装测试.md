# PiInput v0.5.4 安装、使用与测试

## 安装

1. 解压 `PiInput-v0.5.4-dev-windows-x64.zip`。
2. 双击根目录的 `PiInput-Install.exe`，确认 Windows 管理员提示。
3. 安装完成后重新打开测试程序，通过 `Win + Space` 选择 PiInput。

## 基本操作

- `Shift`：切换中文/英文。
- `Space`：确认当前候选。
- 数字键：选择当前行候选。
- 左右方向键：移动候选；上下方向键：移动候选行。
- `=`：下一行；可信词候选结束后进入当前音节单字选择。
- `-`：上一行；在单字选择首行继续按可返回词候选。
- `Esc`：取消当前组合并删除尚未上屏的字母。

## 候选右键菜单

在某个候选文字上点击鼠标右键：

- **固定首位**：该拼音下把所选候选固定到第一位。
- **删除该词**：从该拼音候选中隐藏所选词。
- 菜单打开后点击菜单外或按 `Esc`：关闭菜单并取消当前组合。

## 本版检查项

1. 输入 `fdsafds`：应用组合区保留字母，但不出现空白候选框。
2. 小鹤输入 `mktm`：首选“明天”；按 `=` 后出现“明、名、命”等单字。
3. 输入任意较长拼音，截图或切换焦点后回来继续输入：原始字母不得复制一遍。
4. 打开候选右键菜单，点击外部或按 `Esc`：候选窗与刚输入的字母一并清除。
5. 固定或删除候选后重新打开程序：设置仍保留。

## 卸载

双击安装目录或发布包中的 `PiInput-Uninstall.exe`。默认保留个人词频与设置；需要彻底清除用户数据时，按卸载器提示选择。
