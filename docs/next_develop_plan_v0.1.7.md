# LiteIME v0.1.7-dev 下一步开发计划

## 第一优先级：Windows TSF 真机闭环

根据 v0.1.6 在 Windows 真机上的编译、注册、状态检查和输入日志继续修复：

- Windows 设置列表刷新；
- `Win + Space` 切换；
- TSF `Activate` 生命周期；
- Composition 写入；
- 候选窗位置；
- 空格和数字键上屏；
- 应用退出和 DLL 卸载。

## 第二优先级：基础词库

- 扩充高频单字和常用词；
- 建立通用词库与专业词库权重隔离；
- 增加候选准确率回归语料；
- 增加错误候选屏蔽测试。

## 第三优先级：设置程序

- 输入方案选择；
- 双拼方案选择；
- 标点模式；
- 词库启停；
- SCEL 导入；
- 用户学习数据管理。
