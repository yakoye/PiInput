# PiInput v0.3.3-dev 版本说明

本版是阻断级安全修复，不增加新的输入功能。

## 修复系统卡顿风险

`v0.3.2-dev` 在 Windows TSF 的 `Activate` 回调中同步加载并展开 459,505 条完整词库。PiInput DLL 会进入多个桌面应用进程，因此仅切换输入法就可能让多个宿主同时进行高开销初始化。真机基准显示单进程完整加载约需 690ms；这种按进程复制和同步初始化会放大为系统级卡顿。

`v0.3.3-dev` 改为：

- 切换输入法和焦点变化时不加载完整词库；
- 只有当前应用收到第一个有效字母按键时才初始化中文引擎；
- 初始化使用 `LazyLoadGate`，加载过程中的重入请求不会再次递归初始化；
- 成功后同一宿主进程复用已加载引擎；
- 初始化失败时不吞掉无关按键，并允许后续有效按键重试；
- 停用文本服务时重置延迟加载状态。

`v0.3.2-dev` 已撤回，不应继续安装或使用。

## 修复候选窗初始布局

- 每次新输入或候选快照默认只显示一行；
- `=`/`↓` 展开到配置行数并向下移动一行；
- `-`/`↑` 展开到配置行数并向上移动一行；
- 继续输入后，新的候选快照重新折叠为一行；
- `visible_rows` 现在表示“展开后的最大可见行数”，而不是初始行数。

## 保留能力

- 全拼和小鹤双拼；
- `u/v` 兼容与任意长度增量候选；
- 完整基础词库、单字路径兜底和本地学习；
- 中文标点、符号搜索和可选离线英文候选；
- 版本并存安装和稳定 TSF 身份。

## 本版不做

- 不加入 AI、云端实时联想或语音；
- 不改变候选排序与词库权重；
- 不把外部 SCEL 打进源码仓库；
- 不推送远程仓库，先完成 Windows 真机安装验证。
