# PiInput v0.4.2-dev 版本说明

本版是 `v0.4.0/v0.4.1` 稳定 Host 架构的回归修复版，不增加新的产品功能。

## 修复

- `PiInputHost.exe` 安装后常驻并随当前用户登录启动；大词库只加载一次，所有应用共用，避免每个新程序首次输入等待 5～10 秒。
- 稳定入口在注册表路径丢失时可从原子 `current.json` 恢复当前 Host。
- 候选 Host 启用 Per-Monitor-V2 DPI 感知，字体、间距和窗口尺寸按当前显示器 DPI 重建，恢复 `v0.3.8/v0.3.9` 的清晰显示。
- 候选坐标在写入组合文本的同一个 TSF 编辑会话中取得，优先紧贴真实文本光标；只有宿主不提供位置时才回退到鼠标附近。
- 独立 `Shift` 重新可靠切换中英文；Shift 与字母或其他修饰键组合时不误切换。
- 默认候选只显示一行；`=`/下箭头逐行展开，`-`/上箭头逐行返回。
- 可靠词语候选耗尽后进入分段取字，自动高亮当前未解决音节的单字；已选文字留在组合区，全部完成后一次上屏。
- 左右箭头在当前候选行移动高亮，上下箭头在候选行之间移动。
- Host 协议升级到 v2，传递分段组合文本、活动列和候选模式，同时继续接受 v1 稳定入口。
- 一次性入口修订被旧应用占用时改为并行安装，新打开应用立即使用新版，不要求统一结束所有程序或重启。

## 保持不变

- 纯离线、无 AI、无语音、无广告、无实时云联想。
- 默认小鹤双拼，可在设置中切换全拼。
- 本地用户词库、SCEL 导入和学习数据继续保存在 `%LOCALAPPDATA%\PiInput\UserData`。
- 中文帮助和新的符号中心暂缓，待本版稳定性由用户实测确认后继续。
