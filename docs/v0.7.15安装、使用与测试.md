# PiInput v0.7.15 安装、使用与测试

## 安装

完整解压 `PiInput-v0.7.15-windows-x64.zip`，运行根目录 `PiInput-Install.exe`。机器 TSF 注册会请求一次窄范围管理员授权；用户文件和设置仍安装在当前普通用户目录。安装完成后重新打开测试程序，通过 `Win+Space` 选择 PiInput。

## 核心检查

1. 在记事本、Notepad++、Chrome 和 Windows 搜索分别输入 `zhongwen`，确认组合、候选和空格上屏。
2. 输入数字 `123`，不得丢失首个数字；远程桌面地址框等数字输入框应直接透传。
3. 中文组合输入 `cmd` 后单按 Shift，应上屏 `cmd` 并切到英文。
4. 中文标点下验证 `1.文本`、`1..`、`12:23`、`2/3` 和中文冒号、分号；英文标点模式下物理标点应全部为 ASCII。
5. 在快捷表中新增一个图标行，保存并重新打开设置，确认五个字段和行数不丢失；删除后不得被旧索引键复活。
6. 开启英文候选输入 `calc`，确认 `calc` 在候选 1、两个计算器在候选 2/3；关闭英文候选后 `calc` 应逐键直接上屏。

## 工具入口

- `fh/bq/sz`：候选 2 分别打开符号、表情和设置。
- `jsq`：候选 2 打开 Windows 计算器，候选 3 打开随包程序员计算器。
- `msp`：候选 2 打开 Windows 画图。
- `kuaijie`：不得出现启动动作候选。

设置的“快捷调用”页是一张表，列为“触发码、候选位置、图标、名称、调用程序”。默认显示符号、表情、设置、Windows 计算器、随包程序员计算器和画图，可使用“添加/编辑/删除”，上限 64 项；“恢复默认”可找回内置行。多个触发码用逗号分隔，候选位置为 2～9；目标支持 EXE、HTML、文件、URL、`ms-settings:`、环境变量路径、`cmd:命令` 或 `shell:程序|参数`。

“Windows 工具模板”提供搜索和分类筛选，共 95 项系统入口及 Everything。选中模板后仍需填写触发码，保存后才进入候选。Everything 只查找本机安装程序，不随 PiInput 分发。

英文候选开启时，输入英文触发码后原始字母仍在候选 1，动作按配置位置显示。英文候选关闭时字母逐键直输、不拦截快捷码；需要调用时按 Shift 切到中文再输入。

## 版本确认

```powershell
& "$env:LOCALAPPDATA\PiInput\bin\PiInputHost.exe" --version
& "$env:LOCALAPPDATA\PiInput\bin\PiInputHost.exe" --build-id
```

输出应分别为 `0.7.15` 和验证文档记录的精确 `0.7.15+<commit>`。

## 卸载

从 Windows“已安装的应用”卸载 PiInput，或运行包根目录 `PiInput-Uninstall.exe`。卸载默认保留 UserData；安装、卸载结果窗口应显示在前台。
