# PiInput v0.7.11 安装、使用与测试

## 安装

双击最外层 `PiInput-Install.exe`，不需要先卸载。装完后**重新打开要测试的程序**，再用 `Win+Space` 切到 PiInput。

## 本版重点测试

### 一、单音节输入的首选（唯一改动）

切到**全拼**，逐个打下面的音节，看第一个候选：

| 输入 | 首选应为 | 改前是 |
| --- | --- | --- |
| `xie` | 些 | 西鄂 |
| `xian` | 先 | 西安 |

`xian` 再多看几位：前面应该是一串常用单字（先 现 显 线 险 仙 咸 鲜…），**「西安」仍在第一页**，大约第 18 位。它没有被删掉，只是回到了自己词频该在的位置。

### 二、确认「词优先于字」没被改坏

这条规则在同一种切分内部必须保留：

| 输入 | 首选应为 | 单字应在其后 |
| --- | --- | --- |
| `nihao` | 你好 | 你、尼、泥 |
| `women` | 我们 | 我、握、窝 |
| `mingtian` | 明天 | 明、名、命 |
| `beijing` | 北京 | 被 |
| `gongzuo` | 工作 | 公、工 |

如果这里出现单字排在词组前面，就是改坏了。

### 三、回归确认

以下应与 v0.7.10 完全一致：

```text
zhongguo    中国
ceshi       测试
pingguo     苹果
wenti       问题
shijian     时间
shenme      什么
zhidao      知道
fangfa      方法
mk / dddyn / sdsf     词组之后有单字
srf / sruf / shrfa    首选都是「输入法」
```

界面部分与 v0.7.10 一致，快速过一遍即可：

```text
Shift 切换            光标旁出现 中 / a
CapsLock              光标旁出现 A
按住 Shift 打 Hello   全程无提示
任务栏中/英           切换应用后与实际语言一致
左键点图标            中英切换
右键点图标            弹出菜单
```

版本确认：

```text
%LOCALAPPDATA%\PiInput\bin\PiInputHost.exe --build-id
```

应输出 `0.7.11`。

## 关于「西安」的位置

如果你经常打 `xian` 要「西安」，现在需要往后翻一点。这是有意的：改前「西安」「西岸」「锡安」三个词占住前三位，把「先」「现」挤到第四第五，而后两者的词频高出前者一到两个数量级。

选过一次之后，用户学习会把「西安」提到前面——这条路径不受本次改动影响。

## 本次重点实测：新窗口的默认语言

这一条是为了验证「从其他输入法切过来是英文」到底修没修掉。

先确认配置：

```ini
[general]
default_language=chinese
```

然后按下面这个顺序走一遍，重点是**开关窗口**——旧的缺陷要靠进程号被回收才会现形：

1. 打开记事本，切到 PiInput，按 Shift 切成英文，随便打几个字母；
2. **关掉记事本**；
3. 再开几个程序（浏览器、资源管理器、编辑器都行），各自点一下输入框；
4. 重新打开记事本，点进输入框。

**第 4 步应该是中文。** 修复前，如果新记事本恰好拿到了旧记事本的进程号，
它会直接继承那个已经关掉的窗口留下的英文状态。

反复几次，多开关几个程序，命中概率更高。任务栏图标和实际打出的字应当始终一致。

如果还是会出现英文，麻烦记一下：出现时是刚开的窗口还是用了一会儿的窗口，
以及此前有没有按过 Shift。这两点能区分是会话继承还是别的原因。

## 长时间运行

这一版还给宿主的会话加了上限（64 个，按最近最少使用回收）。
之前每切换一次输入焦点就留下一个永不释放的会话。
正常用一天后，宿主的内存占用应当保持平稳，不再随使用时长单调上涨。

## 重点实测：Ctrl+Shift 切换输入法

这一条是本次修复的核心，请务必测：

1. 在任意输入框里，**连续按 Ctrl+Shift 十几次**（这是 Windows 切换输入法的快捷键）；
2. 每次轮到 PiInput 时，看任务栏图标——**应当始终是「中」**；
3. 随便打几个字确认，出来的应该是中文候选，不是英文字母。

修复前，Ctrl+Shift 里的 Shift 会被 PiInput 当成中英切换键，切一次就变一次英文。

同时确认单击 Shift **仍然能正常切换中英**——这个功能不能被误伤。

## 重点实测：切走再切回来保持状态

```text
在 PiInput 里按 Shift 切成英文
  → Ctrl+Shift 切到别的输入法
  → 再切回 PiInput
  → 应该还是英文

切成中文，同样切走再切回来
  → 应该还是中文
```

`settings.ini` 里的 `default_language` 现在只决定「开机后第一次用」从哪里起步，
之后以你最后一次的选择为准。
