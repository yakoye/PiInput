# PiInput v0.7.1 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.7.1-windows-x64.zip`。
2. 双击最外层 `PiInput-Install.exe`。
3. 接受 Windows 权限提示。
4. 完全关闭并重新打开要测试的应用。
5. 按 `Win + Space` 选择 `PiInput 中文输入法`。

本版更换了中文基础词库，`data/piinput-base.lex` 约 39 MB，解压和安装比以前慢一些。

## 本版重点测试

### 结尾半个拼音

小鹤双拼下输入 `woxmzdb`，想要的是「我现在不」，最后的 `bu` 只打了 `b`：

1. 按空格，取「我现在」，组合区保留剩下的 `b`；
2. 候选栏应给出「不」「把」等单字；
3. 再按一次空格，整句「我现在不」一次上屏。

同样测 `wovidcl`（「我知道了」，最后的 `le` 只打了 `l`）。

以前这两种输入按空格没有反应，按回车会把字母原样打到屏幕上。

### 候选不越界

小鹤双拼下分别输入 `bjg` 和 `bhg`，候选应该都是两个字的词：

```text
bjg  →  办公  半个  办个  办过  半干 …
bhg  →  帮个  帮工  帮过  帮规  帮哥 …
```

不应再出现「办公室自动化」「半个多世纪」「棒骨土豆地饵汤」这类还没打到的长词。

### 单字母候选

输入单个 `b`，候选应覆盖 `ba`、`bei`、`bu`、`ben`、`bian` 等不同音节：

```text
b  →  把  被  不  本  边  吧  白  别 …
w  →  我  为  无  问  外  王  位  文 …
```

不应该只剩同一个音节的字。

### 数字与小数点

新开一个应用窗口，第一次就输入：

```text
3.
0.7.1
1.2.3
```

应分别得到 `3.`、`0.7.1`、`1.2.3`。以前一个会话里第一次敲 `3.` 常常得到 `3。`，删掉重敲才正常。

`3..` 仍然得到 `3.。`，这是有意保留的：第二个点回到中文句号，否则数字后面就打不出 `。`。

## 卸载

在 Windows「已安装的应用」中卸载 PiInput，或运行安装目录中的 `PiInput-Uninstall.exe`。
