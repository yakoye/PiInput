# PiInput v0.5.3-dev 验证记录

验证环境：Windows x64、Visual Studio 18 2026、MSVC 19.51、Windows SDK 10.0.26100.0。

## 自动验证

- Release 全目标构建：通过。
- CTest：53/53 通过，0 失败。
- 3500 常用汉字：全拼 3500/3500，小鹤 3500/3500。
- 7000 通用汉字：全拼 7000/7000，小鹤 7000/7000。
- 真实字典：101,470 个去重词条。
- `wo` 热查询 10,000 次：P50 26.3 微秒、P95 28.6 微秒、P99 70.1 微秒。
- 发布文件 SHA-256 清单、版本元数据、PowerShell/JSON 语法和源码差异检查：通过。

## 候选质量

- 小鹤 `nibawodetubn`：首选“你把我的图标”。
- 小鹤 `hzxrkl`：首选“候选框”。
- `𫛭` 等 Unicode 扩展区字符不再进入普通候选前排。
- 固定首位、删除该词、旧候选 ID 拒绝与用户模型往返保存测试：通过。

## Windows 候选窗和图标

- 候选文本按微软雅黑 UI 的实际字体高度居中，20/30/40 DIP 行高计算测试通过。
- 候选窗右键菜单包含“固定首位”和“删除该词”。
- 安装升级顺序为：刷新 TSF Profile 名称/图标元数据、加入当前用户键盘列表、重试验证状态。
- 紫色 π 图标独立复制到稳定 `Runtime\Shim\piinput_icon.ico`，Profile 不再引用易变化的版本目录。

本验证不宣称已替用户点击 UAC；最终系统语言栏图标显示仍需安装后由 Windows 真机刷新确认。
