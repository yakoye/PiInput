# PiInput v0.7.5 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.7.5-windows-x64.zip`；
2. 双击最外层 `PiInput-Install.exe`；
3. 接受 Windows 权限提示；
4. 安装完成的对话框会列出安装目录和用户设置目录，点「确定」后自动打开设置目录；
5. 完全关闭并重新打开要测试的应用；
6. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版重点测试：全拼简拼

切到全拼（`Win+Space` 后确认方案为全拼，或在 `settings.ini` 里 `schema=full`）。

### 一、三种写法都要出同一个词

```text
srf     →  输入法
sruf    →  输入法
shrfa   →  输入法
shurf   →  输入法
```

四种输入的首选都应该是「输入法」。这是搜狗帮助文档里举的例子。

### 二、声母简拼与首字母简拼等价

```text
zly     →  候选里有「张靓颖」
zhly    →  候选与 zly 完全相同
zsjs    →  候选里有「指示精神」
zhshjsh →  候选与 zsjs 完全相同
```

`zh/ch/sh` 按首字母归约，两种写法不应有任何差别。

### 三、打几个声母出几个字

```text
srf   →  首选「输入法」（三字），不应出现「输入法软件」「输入法论坛」
```

打三个声母就是要三个字的词。更长的词是在猜用户没打的字。

### 四、不干扰正常全拼

这几个必须和以前完全一样：

```text
wang    →  王 望 往
cao     →  草 操
shuang  →  双 爽
nihao   →  你好
xianzai →  现在
kadun   →  卡顿
```

`wang` 尤其重要——它能读成 w+a+n+g 四个声母，但绝不能让四字词把「王」挤下去。

### 五、双拼不受影响

切回小鹤双拼：

```text
xpzdw    →  卸载完
xpzdwji  →  卸载完成
gjjt     →  感觉
jisrji   →  计算机
xnhe     →  小河 / 小盒 / 小鹤
```

### 六、开关

编辑 `%LOCALAPPDATA%\PiInput\UserData\settings.ini`：

```ini
[pinyin]
simplified_pinyin=false
```

保存后重新开始输入，`srf`、`zsjs` 应不再出简拼候选，其余行为不变。

### 七、首次简拼的一次性延迟

第一次输入简拼时，简拼索引会构建，约 0.3 秒。之后不再发生。如果每次简拼都卡，请反馈。

## 卸载测试

v0.7.4 的卸载修复仍在本版中，测试要点见 `v0.7.4安装、使用与测试.md`。要点是：卸载不应再报「PiInput active-version directory is missing」，卸载后 `%LOCALAPPDATA%\PiInput` 应只剩 `UserData`，`current.json` 应消失。

## 反馈时请附上

- 输入方案（全拼 / 小鹤）与完整按键串；
- 期望的候选和实际的候选，以及目标词排在第几；
- `simplified_pinyin` 的当前取值。
