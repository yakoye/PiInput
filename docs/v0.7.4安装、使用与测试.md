# PiInput v0.7.4 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.7.4-windows-x64.zip`。
2. 双击最外层 `PiInput-Install.exe`。
3. 接受 Windows 权限提示。
4. 安装完成的对话框会列出安装目录和用户设置目录，点「确定」后会自动打开设置目录。
5. 完全关闭并重新打开要测试的应用。
6. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版重点测试

### 一、卸载能完成

这是本版的主要修复。以前卸载会弹出：

```text
PiInput 卸载失败：
PiInput active-version directory is missing
```

**测试方法**：从「设置 → 应用 → 已安装的应用」找到 PiInput 点卸载，或直接运行安装目录下 `Uninstall\PiInput-Uninstall.exe`。

预期：弹出确认框，确认后提示「PiInput 已卸载，相关文件和注册表项已清理。」

如果提示变成「已卸载，但以下项目需要重启后才能清理干净」并列出条目，那是正常的——文件被其他进程占用时会安排在重启后删除。重启一次再检查即可。

### 二、卸载确实清理干净

卸载后逐项检查（保留用户数据的默认卸载）：

```text
%LOCALAPPDATA%\PiInput\
  应只剩 UserData\（词库、设置、学习记录）
  bin\、data\、Uninstall\、Runtime\、Dev\ 都应消失
  current.json 应消失          ← 以前会留下，导致下次卸载失败
```

注册表检查（`regedit`）：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\PiInput      应消失
HKCU\Software\PiInput                                            应消失
HKCU\Software\Classes\CLSID\{13EB305F-2DA3-4CF7-8C45-16B016B801B5}   应消失
```

输入法列表检查：`Win + Space` 里不应再出现 PiInput；「设置 → 时间和语言 → 语言和区域 → 中文 → 语言选项 → 键盘」里也不应再有。

### 三、勾选「同时删除用户词库」时全部清空

再装一次，卸载时勾选「同时删除用户词库、设置和学习记录」。预期 `%LOCALAPPDATA%\PiInput` 整个目录消失。

### 四、旧版本也能卸载

如果机器上还留着更早版本的安装，直接运行本包里的 `PiInput-Uninstall.exe` 即可，不需要先重装。本版会在所有历史目录布局里查找程序。

### 五、安装后自动打开设置目录

安装完成点「确定」，应自动弹出资源管理器窗口，定位到：

```text
%LOCALAPPDATA%\PiInput\UserData
```

里面应有 `settings.ini`。用记事本编辑保存后，下次开始输入时生效。

命令行加 `--silent` 安装时，不应弹窗，也不应打开目录。

## 输入行为

本版不改输入行为，v0.7.3 的逐键候选改动原样保留。回归确认几条即可：

```text
小鹤 xpzdw     →  卸载完
小鹤 xpzdwji   →  卸载完成
全拼 jintia    →  今天
全拼 wanchen   →  完成
全拼 kadun     →  卡顿（不能出现「卡吨」）
```
