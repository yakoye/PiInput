# PiInput v0.5.6 安装、使用与测试

## 安装或升级

1. 完整解压 `PiInput-v0.5.6-dev-windows-x64.zip`。
2. 双击根目录的 `PiInput-Install.exe`。
3. Windows 管理员确认出现时选择“是”。
4. 安装完成后，在目标程序中按 `Win + Space`，选择“PiInput 中文输入法（开发版）”。

如果电脑上已经安装过 PiInput，也直接运行同一个 `PiInput-Install.exe`。它会升级现有版本，不需要先卸载，不需要逐个关闭正在编辑的程序；管理员确认只用于 Windows 输入法注册和升级固定入口。

普通升级不会关闭正在编辑的应用，也不会删除用户词库。永久输入入口固定在：

```text
%LOCALAPPDATA%\PiInput\Runtime\Shim\PiInputTSF.dll
```

输入核心和词库位于版本目录，由独立 Host 统一提供。安装后新输入应立即使用当前 Host；不应再因应用曾经加载不同版本的核心而得到不同候选行为。

升级时若旧入口仍被某些应用加载，安装器会尽量保留该进程正在使用的只读副本，并把新版放回上述固定路径。安装器只有在固定路径文件与发布包完全一致后才报告成功；若 Windows 不允许安全替换，会明确提示需要关闭哪些占用程序或重启后重试，不会把旧入口伪装成新版。

## 常用按键

- `Space`：上屏当前候选；
- `1`～`9`：选择当前行候选；
- `=` / `↓`：下一候选行，并选中第一项；
- `-` / `↑`：上一候选行，并选中第一项；
- `←` / `→`：同一行内移动；
- 单独按 `Shift`：切换中文/英文；
- `Enter`：上屏原始字母；
- `Esc`：取消本次组合。

## 符号与帮助入口

- `;;f`、`；；f` 或连续两个反引号再按 `f`：在候选栏打开符号中心；
- 单个反引号、Markdown 行内代码和三个反引号代码块保持 ASCII 原样；
- `;;h` 和 `;;u` 已保留给中文帮助、拆字模式，但 v0.5.6 尚未完成这两项，不能把只出现原始字母误认为已打开功能。

## 设置

候选栏右侧四格按钮打开工具菜单，再选择“设置”。可调整：

- 全拼或小鹤双拼；
- 默认中文或英文；
- 每行候选数；
- 候选字号和单行高度。

设置保存在 `%LOCALAPPDATA%\PiInput\UserData\settings.ini`。全拼/小鹤切换在下一组合边界生效；v0.5.6 不再要求重开应用。

## 建议验证

1. 在 Notepad4 输入小鹤 `gjjt`，空格上屏“感觉”。
2. 打开设置切换为全拼，在同一个 Notepad4 窗口连续输入 `ganjue`：组合区必须完整显示六个字母，首选“感觉”；不能停在 `gan`。再切回小鹤重复验证。
3. 在 Word 页面底部输入，候选栏应自动显示在文本光标上方，且不超出当前显示器工作区。
4. 在另一显示器和不同缩放比例窗口重复输入，候选栏应跟随文字插入点，而不是鼠标位置。
5. 运行 `bin\piinput-diagnostics.exe --status --json`，注册 DLL 路径应包含 `Runtime\\Shim\\PiInputTSF.dll`，当前 Host 应指向 v0.5.6 版本目录。

建议第一次安装后在新开的 Notepad4、Notepad++ 或 Word 中做一个最短冒烟测试：

```text
小鹤：gjjt + Space  -> 感觉
小鹤：mktm + Space  -> 明天
Shift -> book -> Shift
```

英文候选默认关闭，因此英文状态下字母会立即直通；需要英文联想时可在设置中开启。输入法更新后，已经运行的应用可能仍在内存中保留旧的只读入口副本，这是 Windows 进程加载 DLL 的正常行为，但输入核心和词库由独立 Host 统一提供，新组合不应再出现各应用候选版本不同的问题。新启动的应用会加载固定入口处的最新 DLL。

## 卸载

双击根目录 `PiInput-Uninstall.exe`，或在 Windows“设置 → 应用 → 已安装的应用”中卸载 PiInput。默认保留用户数据，只有明确选择删除用户数据时才移除 `%LOCALAPPDATA%\PiInput\UserData`。

## 发给别人

只需发送完整的 `PiInput-v0.5.6-dev-windows-x64.zip`。不要单独发送 DLL，也不需要发送你的外部 `dicts` 源目录；发布包已包含编译后的基础词库、符号和英文候选数据。
