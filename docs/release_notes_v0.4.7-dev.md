# PiInput v0.4.7-dev 版本说明

本版只修复 Shift 中英文切换链路，不改变中文标点映射、词库、候选布局或输入方案。

## 修复

- 修复部分 TSF 宿主漏发 Shift KeyUp 后，中英文状态无法切换的问题；
- 正常收到 Shift KeyUp 时仍立即切换，不增加等待；
- 漏失 KeyUp 时，在下一次普通按键到达且物理 Shift 已松开后，先补做一次切换，再处理该按键；
- Shift 仍被按住并与字母或符号组合时，只作为修饰键使用，不误切换；
- 迟到的 KeyUp 不会重复切换；
- 英文候选默认关闭时，Shift 仍可切到英文直输，字母和英文标点直接上屏；
- 英文直输状态可跨独立 Host 重启恢复。

## 使用结果

默认设置无需开启英文候选：

```text
中文状态 → 单按 Shift → 英文直输
英文状态 → 单按 Shift → 中文输入
```

若宿主漏掉第一次 Shift KeyUp，切换会在下一次普通键按下时恢复，因此该普通键按切换后的模式处理。

## 不在本版调整

- 中文状态整套符号映射仍保持 v0.4.6 行为；
- 与搜狗、微信输入法的全键盘符号对照会单独建立测试矩阵后再发布，避免未经验证地改变 Markdown、编程和中文标点习惯。
