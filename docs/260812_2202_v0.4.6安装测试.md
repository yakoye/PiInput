# PiInput v0.4.6 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.4.6-dev-windows-x64.zip`；
2. 先双击 `PiInput-Test.exe` 检查全拼、小鹤和英文候选；
3. 双击 `PiInput-Install.exe`，同意一次管理员权限请求；
4. 安装器完成后，重新打开要测试的软件；
5. 按 `Win + Space`，选择“PiInput 中文输入法（开发版）”。

不要直接在 ZIP 预览窗口里运行 EXE。安装包不会自动结束当前应用，也不会自动切换输入法。

## 基本使用

- 单独按 `Shift`：中文/英文切换；
- `Space`：确认当前候选；
- `1`～`9`：选择当前活动行候选；
- `=` / `↓`：下一行，可靠整词耗尽后进入分段取字；
- `-` / `↑`：上一行；
- `←` / `→`：移动候选；
- `Enter`：提交原始输入；
- `Esc`：取消。

候选默认只有一行。短候选每行最多 6 项；句子较长时自动减少列数，避免把所有内容画成“我…”。按键内容不变时，候选窗不重新定位或反复缩放。

## 中英混合输入

目标文本：

```text
1.今天很不错。记住这个book_list——Bringup?
```

1. 中文状态直接输入 `1.` 和中文；数字后的点自动保持 ASCII；
2. 单独按 Shift 进入英文，输入 `book_list`；
3. 单独按 Shift 回中文，按 Shift+- 输入 `——`；
4. 再切到英文，输入 `Bringup?`；
5. 中文状态的 `--`、`==`、`++` 也保持半角 ASCII。

英文候选需在 `%LOCALAPPDATA%\PiInput\UserData\settings.ini` 中设置 `enabled=true`。

## 多窗口重点测试

依次在 Notepad4、Notepad++ 两个标签页、资源管理器重命名框、Chrome 文本框中：

1. 输入一半拼音但不确认；
2. 切换到另一个标签页或窗口；
3. 输入新的拼音；
4. 新窗口不得继承旧拼音，首键应出现组合文本和候选；
5. 候选应靠近当前文本插入点；应用不提供 caret 坐标时才使用鼠标附近；
6. Space 应确认候选，Shift 应能往返切换中英文。

## 卸载

双击解压目录根部的 `PiInput-Uninstall.exe`。默认保留用户设置、词库和学习数据。
