## 自动验证

- 干净 Release 构建，全量 CTest 通过（68 项）。
- `piinput-sha256-regression` 恢复为通过。该项自 v0.8.1 的 `f98c9bb` 起一直失败——那次提交改了 `src/full_pinyin_variants.cpp` 却没同步 `SHA256SUMS.txt`。此前记录的"68 项全绿"在该提交之后不成立，现已更正。
- `piinput-keystroke-latency` 与 `piinput-typing-latency` 未退化。本版在按键路径上新增了 `key_offered` / `key_down` / `key_up` 三个追踪点，追踪默认关闭时只多一次 `snprintf`，与既有的 `key_dispatch` 同一形态。
- 新增单元测试：v6 协议报文在字段作废后仍可解出且不校验其取值、高度为 0 的矩形不被当作光标、零宽光标仍可用、无光标时的落点算式（实测窗口 / 4K 走上限 / 小窗口走比例 / 高 DPI 缩放上限 / 零尺寸矩形）。
- 新增源码门禁：`host_protocol_v6` 必须留在受理白名单里，`show_composition` 必须留在设置默认文本里。

## 实机验证（本机，带追踪取证）

本版三条修复都是先在真实程序里取到数据再动代码的，修复后又用同样方式复验：

| 项目 | 修复前 | 修复后 |
| --- | --- | --- |
| MobaXterm 退格 | 交出 21 次 / 送达 0 次 / 派发 0 次 | 交出 15 次 / 补做 15 次 / 派发 15 次 |
| Notepad++ 退格（对照） | —— | 交出 27 次 / 送达 27 次 / 补做 0 次 |
| MobaXterm 光标来源 | 53 次全部为固定假值 `1919.1019-1920.1019`（宽 1 高 0） | 假值被拒，退到几何兜底 |
| 协议兼容 | v6 报文被整包丢弃 | 对运行中的 Host 实测：v5 与 v6 均有回复，v7 静默丢弃 |

MobaXterm 的 `GetScreenExt` 实测返回 `1025.133-1026.134`，53 次不变——与 `GetTextExt` 同样是 1×1 常量。据此排除该接口作为位置来源。外部探针另证实该程序**全程不维护系统光标**（空闲、词间、合成中，`hwndCaret` 均为 0），且把一个零尺寸的 `TListBox` 报为焦点窗口。

## 已确认的行为

- **协议版本号一旦发布不可撤回。** 本版一度把 v6 连同它承载的字段一起删掉，结果是所有已经打开的程序立刻无法输入，直到各自重启。Shim 是 DLL，加载进应用进程后一直存在，用户不会因输入法更新而重启全部程序；Host 不认版本时 `decode_host_envelope` 返回空，`pipe_server.cpp` 中所有分支被跳过，**连回复都不写**，而按键此时已被吃掉。已固化为单元测试与源码门禁。
- **应用可以答应交出按键却不交。** MobaXterm 对 Backspace 即如此。`OnTestKeyDown` 与 `OnKeyDown` 各加一个追踪点才把边界划清——在此之前，"应用没给"和"我们自己吞了"在追踪里都表现为"什么都没有"，无法区分。此前据此得出的两个诊断结论均被这组数据推翻。
- **形状可以证伪一个坐标。** 高度为 0 的矩形不是插入点，无论它落在哪里。这与既有的宽度上限是同一类判断。

## 尚未验证（阻止转为正式版）

- Host 8 小时、TSF/App 8 小时长稳未运行。`tsf_app_soak` 的用例准备用 `SetWindowTextW` 写入种子文本，TSF 看不见，导致 `chinese_mode` 断言失败、soak 循环从未真正开始；该用例在 `PIINPUT_ENABLE_INTERACTIVE_TESTS` 之后，不在 68 项内。
- P0 真实宿主矩阵未运行。
- 安装器界面未实机运行。
- 中文模式英文候选未实机使用（该功能默认关闭，本版未触及）。
- **无可信 Authenticode 签名与 RFC 3161 时间戳。** 与 v0.8.1 相同，对开启智能应用控制强制模式的机器是硬阻塞。详见 `docs/VERIFICATION_v0.8.1.md` 中的实测证据与定位结论，本版未做改变。

## 本版遗留的已知问题

- **MobaXterm 里候选框不跟随光标，这是原理上做不到的。** 该程序不维护系统光标，`GetTextExt` 与 `GetScreenExt` 都返回固定的退化矩形，没有任何接口能问出插入点在第几行第几列——那个信息只存在于它自己的绘图代码里。本版做到的是稳定、不乱跳、落在输入区附近，不是跟随。
- 兜底落点的比例与像素上限（25% / 300px、18% / 150px）是从 MobaXterm 的实际布局量出来的，对其他终端未做校准。

## 结论

本版三条修复均有实机前后对照数据支撑，自动回归完整通过，并修正了自 v0.8.1 起失效的校验清单门禁。

长稳、宿主矩阵、安装器界面均未实机验证，签名门禁未完成。**只能作为候选版分发，不得转入 `releases/current`。**
