# PiInput v0.9.0 安装、使用与测试

## 安装

完整解压 `PiInput-v0.9.0-windows-x64.zip`，运行根目录 `PiInput-Install.exe`。

**本版安装器换成了五页向导**：欢迎、安全提示、安装位置、进度、完成。前三页会说明装到哪两个位置、为什么需要一次管理员权限，以及 Windows 的安全机制可能拦下什么。完成页有三个勾选项：打开设置、查看操作指引、立即激活输入法，一件都不强加。

已装过旧版时**不需要先卸载**，直接运行安装器即可覆盖升级，用户词库、设置和学习记录都会保留。

`--silent` 的行为与以往逐字节相同：完全没有窗口，脚本和一键更新继续可用。

## 如果 Windows 拦下了安装器

PiInput 目前**没有代码签名证书**，因此在开启了防护的机器上会被拦。这不是程序有问题，是 Windows 无法验证发布者。

**智能应用控制（Smart App Control）** 会显示「已阻止可能不安全的应用……因为无法验证其发布者」，并且只给「正常」和「从 Microsoft Store 获得应用」两个按钮 —— 它在强制模式下**不提供绕过入口**。唯一的办法是关闭它：

> 设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制 → 关闭

**注意这个操作是单向的**：一旦关闭，除非重装系统否则无法重新开启。

**注意「正常」按钮不是放行。** 它相当于「确定」，作用只是关掉弹窗，应用依旧不会运行。改名、换目录、用命令行启动都无效，已实测。

**Microsoft Defender SmartScreen** 是另一回事，它的拦截可以绕过：在「Windows 已保护你的电脑」弹窗上点「更多信息」→「仍要运行」。

查看某个机器的智能应用控制状态：

```powershell
(Get-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy" -Name VerifiedAndReputablePolicyState).VerifiedAndReputablePolicyState
```

`0` 是关闭，`1` 是强制，`2` 是评估模式。

## 如果装好了却一个字也打不出来

**先跑诊断，不要先怀疑输入法的改动。**

```powershell
& "$env:LOCALAPPDATA\PiInput\bin\piinput-diagnostics.exe"
```

`host_exists` 是 `false` 而 `shim_exists` 是 `true`，说明 **Defender 把引擎进程当木马隔离了**（常见判定 `Trojan:Win32/Wacatac.C!ml`，是对本地编译、无签名可执行文件的通用误报）。shim 是 DLL 不被查杀，所以语言栏照常显示，但按键送不到引擎。

确认是不是它：

```powershell
Get-MpThreatDetection | Where-Object { ($_.Resources -join ';') -like '*PiInput*' }
```

恢复要三步：以**管理员身份**加一条排除项（改安全设置必须由你自己执行），重新运行安装器，然后用诊断复验。

```powershell
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\PiInput\bin"
```

加排除项意味着 Defender 不再扫描该目录，请确认你了解这个取舍。

## 本版改动

### 常用语

设置里新开一页「常用语」。存长文本，打几个字母从候选框取出来。

| 内容 | 触发码 | 怎么用 |
| --- | --- | --- |
| 北京市海淀区xx街道xx小区 | `dzjl` | 打 `dzjl`，候选框第 2 位 |
| 622322199005012219 | `sfz` | 打 `sfz` 取用 |
| 15801616544 | 留空 | 打前 3 位 `158`，按 `Tab` 补齐 |

触发码留空时按内容首字符推导：中文用首字拼音声母，拉丁用自己的前几个字母，数字走补全建议。**填了触发码就只认触发码**——这同时是开关：不想让证件号在打任意数字前缀时弹出来，给它填个触发码即可。

数字那条路**没有改动数字键本身**：数字照常直接输入，建议只补齐没打完的部分，按 `Tab` 接受，按其他任何键都是正常输入。

### 安装器与操作指引

向导见上。随包新增 `piinput-guide.html`，完成页和托盘「帮助与反馈」都能打开。

## 本版必测项

1. **数字输入完全没变**（最重要）：在记事本、浏览器地址栏、远程桌面地址框里打 `123`、`0.8.1`、`2026`，必须逐字符如实输出，不得丢字、不得弹出任何候选框。
2. **没录常用语时行为与上一版相同**：不添加任何常用语，正常打一段中文，与 v0.8.6 对比应无差异。
3. **别名常用语**：添加 `dzjl` → 一段中文地址，打 `dzjl`，候选框第 2 位是它，选中后完整上屏。
4. **中文内容留空触发码**：添加一条中文常用语、触发码留空，保存后重开设置，确认触发码列显示「（自动）按首字拼音声母」；打首字声母能命中。
5. **数字补全**：添加 `15801616544`、触发码留空，打 `158` 出现建议，按 `Tab` 得到完整号码；打 `158` 后按空格或回车**不应**补全。
6. **填了触发码的数字常用语不被数字触发**：给号码填上触发码后，打它开头三位不应再弹建议。
7. **常用语不进学习**：选用一条常用语若干次后，再打同一个触发码，候选框里不应出现重复的整条内容。
8. **安装器五页**：逐页读过去，确认文案完整未被裁切；完成页三个勾选项各自生效。
9. **操作指引能打开**：完成页勾选后应在浏览器打开 `piinput-guide.html`；托盘右键「帮助与反馈」同样。
10. **升级不中断已开程序**：装上本版后**不重启**任何已打开的程序，在其中继续打字，应正常工作。
11. **重启后文件仍在**：升级安装后重启电脑，跑 `piinput-diagnostics.exe`，`shim_exists`、`host_exists`、`lexicon_exists` 必须全部为 `true`。

**注意：每个受测程序都要重启。** 输入法组件是 DLL，程序不重启就还是旧版本。

## 核心检查

1. 在记事本、Notepad++、Chrome 和 Windows 搜索分别输入 `zhongwen`，确认组合、候选和空格上屏。
2. 输入数字 `123`，不得丢失首个数字；远程桌面地址框等数字输入框应直接透传。
3. 中文组合输入 `cmd` 后单按 Shift，应上屏 `cmd` 并切到英文。
4. 中文标点下验证 `1.文本`、`1..`、`12:23`、`2/3` 和中文冒号、分号。
5. 中文模式打 `apple-book`，横杠应正常落下。
6. 在快捷表中新增一个图标行，保存并重新打开设置，确认五个字段和行数不丢失。

## 工具入口

- `fh`/`bq`/`sz`：候选 2 分别打开符号、表情、设置。
- `jsq`：候选 2 打开 Windows 计算器，候选 3 打开随包程序员计算器。
- `msp`：候选 2 打开 Windows 画图。

## 诊断

在临时目录放置 marker 文件开启日志，默认全部关闭：

| Marker | 日志 | 用途 |
| --- | --- | --- |
| `piinput-candidate-trace.on` | `piinput-candidate.log` | 宿主是否接管候选显示 |
| `piinput-caret-trace.on` | `piinput-caret-trace.csv` | 候选窗定位与实际落点 |
| `piinput-langbar-trace.on` | `piinput-langbar.log` | 语言栏按钮注册 |
| `piinput-key-trace.on` | `piinput-key-trace-<pid>.csv` | 每个按键的去向 |

按键追踪只记录「这个键发生了什么」，不记录输入的文本内容。排查完请删除 marker 文件。

## 版本确认

```powershell
& "$env:LOCALAPPDATA\PiInput\bin\PiInputHost.exe" --version
& "$env:LOCALAPPDATA\PiInput\bin\PiInputHost.exe" --build-id
```

输出应分别为 `0.9.0` 和 `0.9.0+<发布提交短哈希>`，**不得带 `-dirty` 后缀**。精确值见候选目录的 `BUILD-ID.txt` 或 GitHub Release 正文。

## 已知限制

**终端里候选框不跟随光标。** MobaXterm 这类程序不向系统报告插入点位置，`GetTextExt`、`GetScreenExt` 和系统光标三条路都问不出结果。做到的是稳定、不乱跳、落在输入区附近。

**有些程序会主动禁用输入法。** 例如 YeImageViewer 调用了 `ImmDisableIME`，那之后 Windows 不会把任何输入法加载进该进程。

**中文常用语的自动触发码依赖词库反查。** 生僻字查不到读音时推导会停下；推不出两个字母的行需要手工填触发码，设置界面会在触发码列直接说明。

## 卸载

从 Windows「已安装的应用」卸载 PiInput，或运行包根目录 `PiInput-Uninstall.exe`。卸载默认保留 UserData。
