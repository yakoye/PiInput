# PiInput v0.1.3-dev 版本说明

## 版本定位

本版本把项目从“SCEL 工具链基线”推进到“可实际验证的输入核心 + Windows 原生预览”。

它仍不是 Windows 语言栏中的正式 TSF 输入法，但已经可以在 Windows 上构建出原生 EXE，用于验证拼音、双拼、句子候选、符号和学习逻辑。

## 新增功能

### 拼音与双拼

- 新增 413 项标准拼音音节表；
- 新增连续全拼切分；
- 新增 `'` 手动边界；
- 新增小鹤双拼；
- 新增自然码双拼；
- 新增微软双拼；
- 新增智能 ABC 双拼；
- 新增方案枚举与统一解码接口。

### 词库

- 新增自有 `.lex` 二进制格式；
- 新增 `piinput-lexicon-compiler`；
- 编译时按词和拼音去重；
- 批量 SCEL 导入；
- 生成每个独立词库及合并词库 `piinput-imported.lex`。

### 候选与学习

- 新增句子 Beam 解码；
- 新增候选快照 generation；
- 新增候选唯一 ID；
- 拒绝旧快照选择；
- 新增本地选词计数和近期加权；
- 新增用户模型原子保存；
- 新增组合串中间编辑的核心数据模型。

### 标点与符号

- 新增中文、英文、程序员标点模式；
- 新增 140 个内置符号；
- 支持中文名称、全拼、英文名称和别名搜索。

### Windows

- 新增原生 Win32 `piinput-preview.exe`；
- 支持全拼和四种双拼切换；
- 支持 `;` 前缀符号搜索；
- 双击候选复制并记录本地学习；
- 新增开始菜单开发预览快捷方式；
- 根目录 `setup-dev.cmd` 一键构建、测试、安装和导入词库；
- 自动识别 Visual Studio 2026/2022 及其 CMake。

### 工具和测试

- 新增 `piinput-benchmark`；
- 新增真实 SCEL 回归；
- 新增全拼歧义、四套双拼、二进制词库、句子解码、符号、标点、用户学习和候选快照测试；
- 增加 ASan/UBSan 验证。

## 已知限制

- 尚未注册为 Windows TSF 输入法；
- Windows 预览程序需要用户本机完成 MSVC 编译验证；
- 目前使用专业 SCEL 作为测试数据，不等同于高质量通用基础词库；
- `.lex` 当前为第一版小型格式，尚未使用内存映射和完整索引；
- 用户学习只有基础选择加权，尚无置顶、屏蔽和管理界面；
- 符号尚无完整浏览面板。
