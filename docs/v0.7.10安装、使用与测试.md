# PiInput v0.7.10 安装、使用与测试

## 安装

双击最外层 `PiInput-Install.exe`，不需要先卸载。装完后**重新打开要测试的程序**，再用 `Win+Space` 切到 PiInput。

## 本版重点测试

### 一、模式提示窗（新功能，关键）

在任意输入框里操作，看**光标旁边**：

| 操作 | 光标上方应浮出 | 停留 |
| --- | --- | --- |
| 按 Shift 切到中文 | 中 | 约 2 秒 |
| 按 Shift 切到英文 | a | 约 2 秒 |
| 按 CapsLock 打开 | A | 约 2 秒 |
| 按 CapsLock 关闭 | 回到 中 或 a | 约 2 秒 |
| 点任务栏「中」图标切换 | 中 或 a | 约 2 秒 |

要点：

1. **按住 Shift 打一串大写字母，例如输入 `Hello`、`ABC`，全程不应有任何提示。** 这是有意设计的：Shift 是瞬时的，每个大写字母弹一次会非常吵；
2. 提示窗在光标**上方**，候选框在下方，两者不应互相遮挡——可以在打字打到一半时按 CapsLock 验证；
3. 提示窗**鼠标穿透**，在它上面点击应该点到下面的正文，不会挡住操作；
4. 弹出时**不应打断输入**，光标不跳走，正在打的字不丢；
5. 连续快速切换几次，最后一次的提示应完整停留 2 秒，而不是提前消失。

边界情况：

- 光标在屏幕最顶端时，提示窗应翻到光标**下方**，不越出屏幕；
- 光标在屏幕最右侧时，提示窗应收回屏幕内。

中文模式下按 CapsLock 显示的是「中」而不是「A」，这是对的：中文模式下大写锁定不产生大写字母，字母照样进拼音解码。

### 二、任务栏「中/英」不再停在旧状态（重点修复）

这一条是上一版的问题：设了默认中文，切过来却显示英文。

1. 在记事本里按 Shift 切到英文，任务栏图标显示「英」；
2. **切换到另一个程序**（或用 `Win+Space` 切到别的输入法再切回来）；
3. 任务栏图标应显示「**中**」，与实际输入的语言一致。

修复前这里会一直停在「英」。

### 三、默认语言设置生效

编辑 `%LOCALAPPDATA%\PiInput\UserData\settings.ini`：

```ini
[general]
default_language=chinese
```

改完在任意程序里重新聚焦输入框，任务栏图标与实际打出的字应都是中文。改成 `english` 再试一次，两者应都变成英文——重点是**图标和实际行为一致**，不能一个说中一个打英。

### 四、暗色任务栏上图标可见（重点修复）

1. Windows 设置 → 个性化 → 颜色，切到**深色**；
2. 任务栏上的「中」应是**白字**，看得清楚；
3. 切到**浅色**，应变成**黑字**。

修复前，系统主题读不到时会一律画黑字，在深色任务栏上等于隐形——看起来像图标没了。

### 五、回归确认

以下应与 v0.7.9 一致：

```text
左键点任务栏图标          中英切换
右键点任务栏图标          弹出菜单
右键菜单「符号」          直接启动 yesymbol
右键菜单「设置」          设置窗口打开
候选右键菜单点外部        要消失，Esc 也要
左键点候选                直接上屏
候选窗停 3 秒后点工具栏    要有反应
设置窗口 5 页             能改能存，注释保留
mk / dddyn / sdsf         词组之后有单字
srf / sruf / shrfa        首选都是「输入法」
```

版本确认：

```text
%LOCALAPPDATA%\PiInput\bin\PiInputHost.exe --build-id
```

应输出 `0.7.10`。右键菜单「关于 PiInput」也应显示 `0.7.10`。

## 如果指示器里看不到按钮

语言栏按钮由 Windows 在输入指示器里绘制，需要输入法处于活动状态。先在任意程序里用 PiInput 打一个字，再看任务栏。
