# PiInput v0.7.0 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.7.0-windows-x64.zip`。
2. 双击最外层 `PiInput-Install.exe`。
3. 接受 Windows 权限提示。
4. 完全关闭并重新打开要测试的应用。
5. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版重点测试

重新登录 Windows 后不应再出现运行 `PiInputHost.exe` 的黑色终端窗口。首次使用 PiInput 时，Host 会在后台自动启动。

在 Notepad++ 中连续快速输入 `我们。我们`、`。我们`，标点后的首个字母应立即进入组合区，不再等待约半秒后与后续字母一起出现。

中文模式下直接测试：

```text
0.7.0
1.2.3
0..
```

应分别得到 `0.7.0`、`1.2.3`、`0.。`。

## 卸载

在 Windows“已安装的应用”中卸载 PiInput，或运行安装目录中的 `PiInput-Uninstall.exe`。
