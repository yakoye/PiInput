# PiInput v0.5.9 安装、使用与测试

## 安装或升级

1. 完整解压 `PiInput-v0.5.9-dev-windows-x64.zip`；
2. 双击根目录的 `PiInput-Install.exe`；
3. Windows 管理员确认出现时选择“是”；
4. 安装结束后，在准备测试的程序中重新选择“PiInput 中文输入法”；
5. 如果某个已经打开的程序仍保留旧输入状态，只需关闭并重新打开该程序，不需要重启电脑。

已有 PiInput 可以直接升级。设置、用户词和学习数据保存在 `%LOCALAPPDATA%\PiInput\UserData`，升级不会删除。

## 本版重点测试

请先测试连续中文与符号，不要刻意放慢：

```text
我，他们。
我们明天，去哪里？
这个是bug吧，你觉得？怎样！
（我们），明天。
你：我；他！
```

预期：标点立即上屏，标点后的下一段中文立即开始组合，不丢键、不冻结、不重复。

## 常用按键

- `Space`：上屏当前候选；
- `1`～`9`：选择当前行候选；
- `=` / `↓`：展开并移动到下一行；
- `-` / `↑`：移动到上一行；
- `←` / `→`：移动当前行候选；
- 单独按 `Shift`：切换中文和英文；
- `Enter`：上屏原始字母；
- `Esc`：取消当前组合。

## 设置、词库和卸载

- 设置：候选栏右侧菜单中的“设置”；
- 设置文件：`%LOCALAPPDATA%\PiInput\UserData\settings.ini`；
- 发布包已经包含运行词库，发给其他人时只需发送整个发布 ZIP；
- 卸载：双击发布包根目录的 `PiInput-Uninstall.exe`，或从 Windows“已安装的应用”卸载。
