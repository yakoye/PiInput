# PiInput v0.3.4-dev 版本说明

本版只处理安装身份、调试可用性和已发现的系统输入阻断，不增加输入功能。

## 修复

- PiInput 使用新的 TSF CLSID `{D73AABA7-BE3E-4E53-8DE2-652D352743F3}`。
- PiInput 使用新的 Profile GUID `{13D6EB0B-023B-4AA8-ADE1-2A360820EC49}`。
- 安装器在注册新身份前，尽力停用、移除并注销旧 TSF 身份。
- 安装验证脚本、解析脚本和实际 DLL 统一使用同一套标识。
- 保留 v0.3.3 的延迟词库加载与禁止重入保护。

## 调试

- 发布包根目录新增 `PiInput-Test.exe`。
- 测试台直接使用输入核心，不加载 TSF DLL；日常词库、全拼、小鹤双拼和候选测试无需关闭其他应用。
- 系统输入法仍使用版本目录并存。已打开的应用继续运行它已加载的版本；重新打开单个测试应用即可加载新版本，无需结束所有程序。

## 已知边界

Windows TSF 是进程内组件。若要让所有已经运行的应用都彻底卸载旧 DLL，只能让这些应用自然退出，或注销/重启 Windows；这不是安装器可以安全强制完成的操作。
