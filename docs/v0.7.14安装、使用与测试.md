# PiInput v0.7.14 安装、使用与测试

## 安装

完整解压 `PiInput-v0.7.14-windows-x64.zip`，双击根目录的 `PiInput-Install.exe`。安装完成后重新打开要测试的程序，再通过 `Win+Space` 选择 PiInput。

设置程序位于安装目录，也可以从 PiInput 语言栏菜单打开。进入：

```text
标点符号 → 中文输入时的标点 → 英文标点
```

## 中文输入使用英文标点

选中后验证：

1. 输入 `wo`，仍应出现“我”等中文候选。
2. 输入 `.,:;/?[]{}\\|\"'`，全部按 ASCII 原样上屏。
3. 输入中文后按句号，输出 `.`，不进入中文句号或临时标点状态。
4. 选回“中文标点”，再验证中文正文句号为 `。`、`12:23` 保持英文冒号、`2/3` 保持斜杠。

对应配置文件值为：

```ini
[punctuation]
mode=english
```

这只改变标点，不会切换输入语言。

## Shift 切换测试

保持中文状态，依次按 `c`、`m`、`d`，在字母仍位于组合区时单按并释放 Shift。预期 `cmd` 原样上屏，状态切换为英文；接下来输入的字母按英文模式处理。不得丢失 `cmd`，也不得把它选成中文候选。

## 工具候选

- `fh/fuhao/fuh/fuhc`：候选 2 为 `Ω符号`。
- `bq/biaoqing/biaoq/bnqk/bnq`：候选 2 为 `😜表情`。
- `shizhi/uevi/sz/shiz/uev`：候选 2 为 `⚙️设置`。

分别输入 `fh`、`bq`、`sz` 并按数字 `2`：前两项应打开当前安装版本同目录的 `yesymbol.exe`，第三项应打开 `PiInput-Settings.exe`；动作标签本身不得上屏。正式安装中 TSF Shim 位于 Program Files，工具位于当前 Host 同目录，验证时应以注册表 `CurrentHostPath` 指向的活动目录为准。

## 版本确认

```powershell
& "$env:LOCALAPPDATA\PiInput\bin\PiInputHost.exe" --version
& "$env:LOCALAPPDATA\PiInput\bin\PiInputHost.exe" --build-id
```

第一行应为 `0.7.14`，第二行应以 `0.7.14+` 开头。

也可以从 PiInput 语言栏菜单打开“关于 PiInput”，其中应同时显示构建标识、UTC 构建时间、完整 Git Commit ID 和联系方式 `https://github.com/yakoye/PiInput`。反馈问题时请一并提供这些信息。

本地 ZIP 是未签名开发包。Windows 安全策略严格的其他机器可能阻止未签名程序；正式分发仍需代码签名。
