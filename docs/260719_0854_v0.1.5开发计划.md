# PiInput v0.1.5-dev 下一步开发计划

## 第一优先级：Windows TSF 真机闭环

根据用户 v0.1.4 Windows 构建和运行日志完成：

- 修复 MSVC、Windows SDK、链接或 DEF 导出问题；
- 修复 COM 注册问题；
- 修复语言配置文件未出现在 Win+Space 的问题；
- 修复 Composition 创建、更新、提交和取消问题；
- 修复候选窗不出现、位置错误或生命周期错误；
- 验证空格和数字键实际上屏；
- 验证卸载和重新注册。

## 第二优先级：基础输入状态

- 中英文模式切换；
- 状态持久化；
- 中文、英文、程序员标点接入 TSF；
- Shift 临时英文输入行为评估；
- 中英文标点快速切换；
- Enter、Space、Esc 和标点的完整状态机测试。

## 第三优先级：候选窗正式化

- 使用 TSF 文本布局获得候选位置；
- 高 DPI；
- 多显示器边界；
- DirectWrite；
- Direct2D；
- 深色模式；
- 页码和候选数量；
- 鼠标点击；
- 无障碍基础。

## 第四优先级：兼容测试

先建立：

```text
记事本
Visual Studio
VS Code
Chrome
Edge
微信
Windows Terminal
```

每个应用记录：

- 可否激活；
- Composition；
- 候选位置；
- 上屏；
- 光标编辑；
- 崩溃；
- 退出和重启。

## 第五优先级：词库质量

- 扩充有明确许可的通用基础词库；
- 增加常用单字；
- 建立通用、专业、用户分层权重；
- 建立首选率测试语料；
- 避免专业词抢占普通候选。

## 不在 v0.1.5 范围

- AI；
- 语音；
- 移动端；
- 跨设备同步；
- 正式云服务；
- 正式签名发布。
