# PiInput v0.4.7 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.4.7-dev-windows-x64.zip`，不要在压缩包预览窗口中运行；
2. 双击最外层的 `PiInput-Install.exe`；
3. Windows 弹出管理员权限确认时选择“是”；
4. 安装完成后按 `Win + Space` 选择“PiInput 中文输入法（开发版）”。

安装器使用稳定 TSF 入口和版本化 Host。普通升级不要求关闭所有应用；已经打开的应用若仍缓存旧入口，重新打开该应用即可。

## Shift 中英文切换

- 单独按一下 `Shift`：中文与英文互相切换；
- `Shift` 与字母、数字或符号组合：只作为大小写或符号修饰键，不切换模式；
- 某些程序漏发 Shift 松开事件时：松开 Shift 后按下的第一个普通键会先恢复切换，再按新模式输入；
- 英文候选默认关闭时：英文按键直接上屏，不弹候选；
- 需要英文候选时，在 `%LOCALAPPDATA%\PiInput\UserData\settings.ini` 中设置：

```ini
[english]
enabled=true
```

## 建议测试

在 Notepad4、Notepad++、Chrome、Codex 等程序中分别执行：

1. 选择 PiInput，输入 `wo`，按空格确认“我”；
2. 单按 Shift，输入 `book_list?`，应直接得到半角英文与符号；
3. 再单按 Shift，输入 `jt`, 应显示小鹤双拼“觉”等中文候选；
4. 按住 Shift 输入一个大写字母，松开后继续输入，不能误切换两次；
5. 切换窗口后重复上述步骤，模式切换不得卡死或丢首键。

## 其他基本按键

- `Space`：确认当前候选；
- `1`～`9`：选择当前活动行候选；
- `=` / `↓`：下一行或进入分段取字；
- `-` / `↑`：上一行；
- `←` / `→`：移动候选；
- `Enter`：提交原始输入；
- `Esc`：取消。

## 卸载

双击解压目录最外层的 `PiInput-Uninstall.exe`。默认保留用户设置、词库和学习数据。
