# PiInput v0.5.0 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.5.0-dev-windows-x64.zip`，不要只单独复制安装程序。
2. 双击最外层的 `PiInput-Install.exe`。
3. Windows 弹出管理员权限确认时选择“是”。
4. 安装完成后，重新打开要测试的文本程序。
5. 按 `Win + Space`，选择“PiInput 中文输入法（开发版）”。

普通升级会保留用户词库、学习记录和设置。安装包中的稳定 TSF 入口负责连接常驻 Host；各应用不再分别加载 50 万词大词库。

## 基本输入

- 默认输入方案由设置文件决定，支持全拼和小鹤双拼；
- 空格确认当前候选；
- 数字键选择对应候选；
- `=` 或下方向键向下一行浏览；
- `-` 或上方向键向上一行浏览；
- Shift 切换中英文；
- `;;f`、`；；f` 或 <code>``f</code> 打开符号中心；
- `;;h`、`；；h` 或 <code>``h</code> 查看帮助；
- `;;u`、`；；u` 或 <code>``u</code> 进入拆字模式。

## 候选栏工具菜单

候选栏最右侧采用两个固定按钮：向下箭头展开下一行候选，四格按钮打开工具菜单。点击四格按钮后在同一个候选窗口中显示：

- 符号：打开符号中心；
- 设置：打开 PiInput 设置程序。

菜单不占用候选序号，也不会把输入焦点从当前文本框抢走。

## 调整输入与候选栏

1. 在任意中文候选栏最右侧点击四格按钮。
2. 点击“设置”。
3. 选择输入方案：全拼或小鹤双拼。
4. 选择启动后的默认输入语言：中文或英文。
5. 选择候选文字大小（10～28）。
6. 选择单行候选框高度（20～72）。
7. 点击“应用”。
8. 结束当前组合，再开始一次新输入；设置从这个组合边界开始生效。

候选文字会随高度始终上下居中。单行高度设为 20 时仍保持同一基线对齐，不会上下漂移。
鼠标停在“候选文字大小”或“单行候选框高度”上滚动滚轮，可以每格增加或减少 1，例如 12、13、14 或 16、15、14。

默认值为：

```ini
[general]
schema=flypy
default_language=chinese

[candidates]
font_size=16
window_height=48
```

设置保存在：

```text
%LOCALAPPDATA%\PiInput\UserData\settings.ini
```

## 卸载

可以使用任意一种方式：

- Windows“设置 → 应用 → 已安装的应用 → PiInput → 卸载”；
- 安装目录中的 `PiInput-Uninstall.exe`；
- 发布包最外层的 `PiInput-Uninstall.exe`。

默认卸载保留用户词库和学习数据；只有明确选择删除用户数据时才清除。

## 建议测试

分别在 PiInput-Test、Notepad4、Notepad++、Word 中检查：

1. 打开程序后立即输入 `wo`，候选应快速出现“我”；
2. 输入 `gjjt`，应出现“感觉”；
3. 按空格，候选应一次上屏；
4. 按 Shift，确认中英文可以往返切换；
5. 输入 `book`，英文候选开启时应提供补全；
6. 输入 `;;f`，确认符号中心出现；
7. 点击候选栏工具菜单中的“符号”；
8. 打开“设置”，分别切换全拼/小鹤和默认中文/英文，再改变字号与高度，并在下一次新输入验证；
9. 在四个程序间来回切换，候选框应跟随各自文本光标；
10. 同一输入未变化时，候选内容和窗口位置不应跳动。

## 排查

- `Win + Space` 没有 PiInput：重新运行安装器。
- 某个已打开程序仍使用旧入口：完全退出该程序后重新打开；普通 Host 版本升级不需要关闭所有软件。
- 设置没有立即改变当前正在输入的候选：先按 Esc 结束当前组合，再开始下一次输入。
- 词库问题：运行 `query-dictionary.cmd` 查询目标词是否已经进入合并词库。
