# PiInput v0.7.7 版本说明

本版加两样东西：系统托盘图标，以及一个覆盖全部选项的设置窗口。

## 系统托盘

安装后托盘里会出现 PiInput 图标。鼠标悬停显示当前状态，例如 `PiInput  中  小鹤双拼`。

**左键**切换中文／英文。**右键**打开菜单：

```text
中文              ← 显示当前状态，点击切换
小鹤双拼          ← 显示当前方案，点击在全拼与双拼间切换
──────────
符号
设置
──────────
关于              ← 版本号在这里
帮助与反馈
──────────
退出 PiInput
```

菜单里的前两项直接显示当前状态，而不是写「切换到英文」这种说法，所以菜单本身就是状态显示。

「关于」里能看到版本号——以前确认版本只能靠命令行 `PiInputHost.exe --build-id`。

托盘属于 Host 进程，所以它在你第一次用 PiInput 输入之后出现。

## 设置窗口

以前只有 4 个选项可调，其余全靠手工编辑 `settings.ini`。现在引擎读取的 **30 个选项全部可以在窗口里改**，分五页：

| 页 | 内容 |
|---|---|
| 输入 | 输入方案、默认语言、ü 用 v 输入、u: 写法、未完成音节候选、简拼、记住用词习惯 |
| 候选窗 | 每行候选数、展开行数、总数上限、文字大小、单行高度、横向排列、= - ↓ ↑ 四个键的行为 |
| 标点符号 | 标点模式、`Shift+[` 括号样式、符号面板开关与快捷键、`·` 别名 |
| 英文 | 英文候选开关、内置词库、自定义词库、记住用词习惯、每行候选数 |
| 高级 | 保存后自动生效、前缀搜索宽度、前缀扫描上限 |

候选窗那一页保留了实时预览：改字号或行高，预览立刻跟着变，数字下拉框也支持滚轮微调。

**保存不会动你的文件**。它只重写自己管的那些键，你写的注释、手工加的键、这个版本不认识的配置项，全都原样保留。

## 界面文字里的括号样式

括号样式的两个选项以前写作「搜狗」和「微信」，现在直接显示 `{ }` 和 `「 」`。这两个样式和那些产品没有关系，用符号本身表示更准确。

配置文件里的取值名 `sogou` / `wechat` 保持不变——改了会让已有的 `settings.ini` 失效。

## 验证

完整 CTest 60/60 通过。新增一条回归：30 个选项逐一走完「读取 → 修改 → 保存 → 再读取」，并确认保存后文件里的注释、未知键都还在，从未出现过的配置段会被追加。

逐键延迟与 v0.7.6 一致。

## 升级

直接安装，不需要先卸载。现有的 `settings.ini` 会被原样读取，第一次在窗口里保存时才会补齐缺少的键。
