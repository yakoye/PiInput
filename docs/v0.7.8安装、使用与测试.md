# PiInput v0.7.8 安装、使用与测试

## 安装

双击最外层 `PiInput-Install.exe`，不需要先卸载。

## 本版重点测试

### 一、候选窗右键菜单能关掉

1. 打几个字让候选窗出现；
2. 在某个候选上**点右键**，弹出「固定首位／删除该词／取消固定」；
3. **点菜单以外的任何地方** → 菜单应立刻消失；
4. 再弹一次，**按 Esc** → 菜单应立刻消失。

以前这个菜单点哪都关不掉。

### 二、鼠标点选候选

1. 打几个字；
2. **左键单击**任意候选 → 该候选应直接上屏，效果和按它的数字键一样；
3. 按 `=` 展开多行后，点第二行、第三行的候选也应能选中；
4. **右键单击**候选 → 仍然是固定／删除菜单。

### 三、托盘的中/英图标

先打几个字（托盘属于 Host 进程，输入后才出现）。托盘里应看到**两个**图标：

```text
[中]  [PiInput]
```

- 左边那个显示当前语言，中文时是「中」，英文时是「英」；
- **点任意一个图标**都切换语言，左边的字应立刻跟着变；
- 鼠标悬停在左边图标上，提示是「中文  小鹤双拼」这样的当前状态。

如果只看到一个图标，多半是 Windows 把新图标收进了溢出区：任务栏设置 →「其他系统托盘图标」里把 PiInput 打开。

### 四、托盘「符号」调用你的工具

1. 打开设置窗口 →「标点符号」页 → 最下面「托盘符号工具」；
2. 填入 `yesymbol.exe` 的完整路径；
3. 保存；
4. 托盘右键 →「符号」→ 应直接启动该程序。

没填路径时，会先找 PiInput 程序目录下的 `yesymbol.exe`；都没有就弹出提示告诉你去哪填。

也可以直接编辑 `settings.ini`：

```ini
[general]
symbol_tool=完整路径\yesymbol.exe
```

### 五、回归确认

以下应与 v0.7.7 一致：

```text
候选窗停 3 秒后点工具栏按钮   要有反应
设置窗口 5 个标签页            能改能存
settings.ini 里的注释          保存后仍在
mk / dddyn / sdsf              词组之后有单字
srf / sruf / shrfa             首选都是「输入法」
```

版本确认：

```text
%LOCALAPPDATA%\PiInput\bin\PiInputHost.exe --build-id
```

应输出 `0.7.8`。
