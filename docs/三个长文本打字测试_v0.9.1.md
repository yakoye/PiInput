# 三个长文本打字测试（v0.9.1）

v0.9.1 继续执行三组真实文本逐键回放、段落输入、结构化语料和逐键延迟门禁，结果与 v0.9.0 一致，无回归。

本版**没有触及输入路径**：改动全部在设置程序里，新增一页「关于」。引擎、候选、协议、Shim、安装器一个字节未动，因此语料回放结果预期与 v0.9.0 逐字节相同。

## 本版必须复验的项

- **回放输出与 v0.9.0 逐字节一致。** 本版改的是一个独立进程里的新页面，输入路径未动。出现任何差异都要查清原因——那意味着改动范围的判断错了。
- **延迟门禁未退化。** 同上：设置程序不在按键路径上。
- **v0.9.0 的功能仍然有效**：常用语（别名 / 自动触发码 / 数字补全）、安装向导、随包操作指引。

## 真实应用手工测试

必须使用验证记录中的同一 build ID。**每个受测程序都要完全退出重开**——输入法组件是 DLL。

1. **数字输入完全没变**：打 `123`、`0.8.1`、`2026`，逐字符如实输出。
2. **常用语照旧**：别名命中、中文留空触发码能命中首字声母、数字打前 3 位出建议按 `Tab` 补齐。
3. **「关于」页**：设置 → 关于，确认版本号、构建标识显示正确；赞赏那一行红心为红、文字为蓝；两个二维码完整可扫。
4. **语言栏「关于」**：右键 → 关于，末行应为「赞赏作者：设置 → 关于」，框里不应出现二维码。
5. **升级不中断已开程序**：装上本版后不重启任何已打开的程序，在其中继续打字应正常工作。
