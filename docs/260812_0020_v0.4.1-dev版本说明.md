# PiInput v0.4.1-dev 版本说明

## 本版核心变化

本版保持 `v0.4.0-dev` 的永久稳定 TSF Shim 与独立 `PiInputHost.exe` 架构，集中修复候选窗定位。

- TSF Shim 在组合文本更新成功后查询当前应用真实的文本插入点；
- 使用 `ITfContext::GetSelection`、活动视图和 `ITfContextView::GetTextExt` 获取屏幕坐标；
- 文本光标坐标通过独立 caret IPC 消息交给候选 Host；
- Host 先暂存候选，只在收到同一会话、同一 generation 的位置后显示，避免鼠标位置闪现和旧坐标覆盖；
- 过期、超前、错误会话及畸形坐标消息全部拒绝；
- 支持位于主屏左侧的负坐标显示器，并按目标显示器工作区约束候选窗口；
- 极少数不提供文本位置的程序继续使用鼠标附近回退，不影响输入；
- Windows 输入法 Profile 继续使用 `PiInputTSF.dll` 内嵌的紫色 `π` 多尺寸图标。
- 安装器逐字节验证稳定 Shim；不同版本会原子刷新，仍被占用时明确阻止安装，不会静默保留旧 DLL 后切换新 Host。

## 安装和升级

完整解压用户包后双击根目录 `PiInput-Install.exe`。普通升级只切换版本化 Host；第一次安装或稳定 Shim 发生变化时，安装器会完成必要注册。安装器不自动激活 PiInput，也不强行结束当前应用。

从 `v0.4.0-dev` 升级到本版时稳定 Shim 确实发生变化。若安装器报告入口仍被占用，只需重启 Windows 后再次运行安装器；安装事务在此之前不会启用不兼容的新 Host。当前系统中没有旧入口时可直接安装。

详细步骤见包内《安装与使用指南.md》。

## 兼容与限制

- 当前为 Windows x64 开发测试版，尚未正式签名；
- 自动测试覆盖文本坐标协议、候选暂存、Host IPC、多显示器坐标、回退策略以及既有全拼、小鹤、词库、英文、符号、安装和卸载能力；
- 真实应用中的 TSF 光标几何仍需用户安装后在记事本、ChatGPT、Chrome、VS Code 等程序中最终确认。
