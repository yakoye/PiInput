# PiInput v0.7.7 安装、使用与测试

## 安装

双击最外层 `PiInput-Install.exe`，不需要先卸载。

## 本版重点测试

### 一、系统托盘

先在任意程序里用 PiInput 打几个字（托盘图标属于 Host 进程，输入后才会出现）。

1. 托盘里应出现 PiInput 图标；
2. 鼠标悬停，提示应类似 `PiInput  中  小鹤双拼`；
3. **左键单击**：中／英切换，提示文字随之变化；
4. **右键单击**，菜单应包含：当前语言、当前方案、符号、设置、关于、帮助与反馈、退出；
5. 点「小鹤双拼」那一项：应切到全拼，菜单再打开时显示「全拼」；
6. 点「关于」：应显示版本 `0.7.7`；
7. 点「设置」：应打开设置窗口；
8. 点「退出 PiInput」：Host 退出，托盘图标消失。再次输入时会自动重新拉起。

### 二、设置窗口的 30 个选项

打开设置窗口，五个标签页依次检查：

- 每一页的标签与控件应**左右对齐、不重叠、不越界**；
- 「候选窗」页底部有候选栏预览，改「候选文字大小」或「单行候选框高度」时预览应立刻变化；
- 在数字下拉框上**滚动鼠标滚轮**，数值应逐格变化。

### 三、保存不破坏你的配置（重要）

1. 先用记事本打开 `%LOCALAPPDATA%\PiInput\UserData\settings.ini`，在任意位置加一行注释，例如 `# 我的备注`；
2. 回到设置窗口，改任意一项，点「保存」；
3. 再打开 `settings.ini`：**你的注释必须还在**，被改的那一项应已更新。

### 四、括号样式

「标点符号」页的 `Shift+[ 和 Shift+]` 应显示 `{ }` 和 `「 」` 两个选项，不再出现任何产品名称。

选 `「 」` 保存后，在应用里按 `Shift+[` 应输出 `「`。

### 五、回归确认

以下与 v0.7.6 应完全一致：

```text
候选窗停 3 秒后鼠标点击      要有反应
微信输入框里打字            候选窗不压住文字
mk / dddyn / sdsf           词组之后要有单字
srf / sruf / shrfa          首选都是「输入法」
wang / cao / nihao          不受简拼干扰
```

版本确认：

```text
%LOCALAPPDATA%\PiInput\bin\PiInputHost.exe --build-id
```

应输出 `0.7.7`。
