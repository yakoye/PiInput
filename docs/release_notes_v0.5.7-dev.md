# PiInput v0.5.7-dev 版本说明

本版继续收敛中文输入核心，不增加 AI、云联想或语音功能，重点修复候选浏览、一次学习和长拼音卡顿。

- Windows 输入法显示名称改为“PiInput 中文输入法”，不再显示“开发版”后缀。

## 候选浏览

- 默认仍只显示一行；按 `=` 或 `↓` 后展开设置中的行数，默认三行；
- `=` 每按一次向下移动一行并选中该行第一项，连续按时采用滚动队列，最早一行可以滚出视野；
- `-` 或 `↑` 向上移动一行；
- 先完整展示真实词语候选，真实词语耗尽后才追加分段取字与单字候选；
- 进入取字层后保留前面的整词候选，不再用单字列表覆盖整词；
- 只有当前选中行显示数字，其他可见行只显示候选文字；
- 展开行数可在设置程序中选择 1～6 行，默认 3 行并持久保存。

## 用户学习与基础词库

- 用户通过分段选字成功组合的新词，在一次成功上屏后立即学习；
- 新词下一次输入即可进入第一行，无需重复输入五次；
- 学习只在 TSF 确认上屏成功后记录，失败或取消不会污染用户词库；
- 基础词库新增“开悟”和“丝滑”，全拼与小鹤双拼均纳入自动验证。

## 性能

- 长拼音使用自适应 Beam：短输入保持较宽搜索，长输入限制路径交叉增长；
- 真实 101,472 条二进制词库下，长全拼 `wojintianxiawuyaoquchaoshimaidianshuiguo` 的 Release P95 从约 15.9 ms 降至约 2.5 ms；
- 新增真实大词库长全拼性能门禁：P95 不超过 5 ms，P99 不超过 10 ms；
- Host 回归直接测量每次按键请求，避免把 Windows 偶发的测试进程启动调度误判为引擎卡顿；
- 词库仍由独立常驻 Host 统一加载，不在每个应用中重复加载。

## 保持不变

- 默认小鹤双拼，可在设置中切换全拼；
- `Space` 上屏当前候选，数字键只选择当前行；
- 单独 `Shift` 切换中文和英文；
- 用户设置与学习数据继续保存在 `%LOCALAPPDATA%\PiInput\UserData`；
- 不访问网络热路径，不上传输入内容。
