# PiInput 功能入口、中文帮助与符号中心设计

日期：2026-08-12  
状态：已确认，待实施

## 1. 目标

本阶段只实现三个紧密相关的能力：

1. 一个不会破坏中文输入、编程符号或 Markdown 的统一功能入口；
2. 完全中文化、直接显示在候选窗口中的输入法帮助；
3. 可分类浏览并允许用户扩展的符号中心。

用户不需要记忆 `sheshidu`、`copyright` 等英文或拼音命令。帮助和符号中心不打开独立窗口，复用现有候选窗口、数字选词、方向键与滚动操作。

拆字输入使用同一入口体系，但拆字数据、匹配算法和许可策略属于下一份独立设计；本阶段只保留稳定的路由标识，不展示尚未实现的功能。

## 2. 功能入口

### 2.1 默认入口

`Ctrl + Alt + 反引号键` 打开功能总菜单。该快捷键在中文和英文输入状态下都可用，但只在 PiInput 当前激活时处理。

不默认使用 `Ctrl + 反引号`，因为它是 VS Code 等开发工具打开集成终端的常用快捷键。功能快捷键必须可在配置文件中修改或关闭；用户可以主动改成 `Ctrl + 反引号`，但 PiInput 不替用户抢占该组合。

总菜单使用中文显示：

```text
1. 符号中心
2. 使用帮助
```

拆字模式完成后再增加：

```text
3. 拆字输入
```

### 2.2 可选的中文文本别名

以下实际 Unicode 文本序列可以在配置中启用为别名：

```text
··f / ··F  → 符号中心
··h / ··H  → 使用帮助
··u / ··U  → 拆字输入（拆字功能完成后启用）
```

只有两个 U+00B7 中文间隔号后紧跟已定义字母时才触发。未定义序列必须原样保留，不能吞字。

该别名默认关闭。原因是普通 PC 键盘没有独立的 U+00B7 键，通常需要复用反引号键；若默认复用，就无法同时无歧义地满足中文间隔号、Markdown 行内代码、双反引号定界和三反引号代码块。默认入口因此始终是无歧义的可配置快捷键。用户明确启用中文别名后，PiInput 才在中文标点模式中把连续反引号按键解释成间隔号前缀；英文和程序员标点模式始终原样输出反引号。

配置加入固定字段：

```ini
[commands]
enabled=true
hotkey=ctrl_alt_grave
middle_dot_alias=false
```

`hotkey` 第一版只接受 `ctrl_alt_grave`、`ctrl_grave` 和 `disabled`，避免实现任意全局热键解析器。错误值保留上一份有效设置并写入本地诊断日志。

### 2.3 Markdown 与代码兼容

反引号不作为文本前缀。单反引号、双反引号和三反引号全部原样交给应用：

```text
`行内代码`
``双反引号内容``
```代码块```
```

为保证中文状态下也能书写 Markdown，未按 Ctrl 的反引号键不进入功能状态，不等待后续按键，不根据后续的 `f/h/u` 猜测命令。

默认配置下，现有中文标点模式中的反引号映射调整为 ASCII `` ` ``；中文间隔号 `·` 改由符号中心选择。Shift+反引号仍按当前标点模式输出波浪号。只有用户主动启用 `middle_dot_alias=true` 时，中文标点模式才使用间隔号前缀规则。

### 2.4 状态安全

- 打开菜单前如存在中文或英文组合，先保留该组合，不擅自提交或丢弃；功能菜单关闭后恢复原组合及候选快照。
- Esc 返回上一级；在顶层按 Esc 关闭功能菜单并恢复原输入状态。
- 切换应用、切换输入法、Host 重启或 IPC 断开时，功能状态必须安全取消，不向正文写入残缺前缀。
- 候选 ID 仍使用会话与 generation 校验，旧菜单项不可在新快照中误选。

## 3. 中文帮助

帮助直接显示在候选窗口中，不创建独立窗口或网页。

第一层目录：

```text
1. 基本输入
2. 候选与翻页
3. 中英文切换
4. 全拼与小鹤双拼
5. 标点与符号
6. 词库导入与查询
7. 安装、升级与卸载
8. 隐私与数据位置
```

每一页使用简短中文说明，避免英文术语；必要按键使用键帽名称，并同时说明用途。例如：

```text
空格：选择当前候选
1～9：直接选择候选
= / ↓：向下一行
- / ↑：向上一行
Shift：切换中文和英文
Ctrl + Alt + `：打开功能菜单
```

帮助内容来自安装包中的 UTF-8 数据文件，而不是硬编码在 TSF Shim 中。Host 可在普通版本升级时更新帮助，不需要让应用重新加载 TSF DLL。

帮助文件固定为：

```text
data/help_zh.tsv
```

每条记录至少包含稳定 ID、父目录 ID、显示顺序、标题和正文。格式错误时跳过单条并写本地诊断日志；整个帮助文件不可导致输入法加载失败。

## 4. 符号中心

### 4.1 分类

内置符号使用中文分类浏览：

```text
最近使用
我的符号
中文标点
单位符号
数学与逻辑
货币符号
箭头与几何
序号与制表
希腊字母
版权与商标
```

现有 `data/symbols.tsv` 中的 140 个符号继续作为只读基础数据，但用户界面不再要求输入拼音或英文别名。旧别名字段可暂时保留用于数据兼容和测试，系统输入法不再公开或宣传 `;sheshidu` 一类快捷命令。

### 4.2 候选窗口交互

- 第一层显示中文分类。
- 进入分类后横向显示“符号 + 中文名称”。
- 数字键选择当前可见项。
- `=` 或下方向键向下一行；`-` 或上方向键向上一行。
- Backspace 返回上一级；Esc 退出符号中心。
- Enter 或空格选择当前高亮符号。
- 默认只显示一行；用户主动向下浏览后才展开多行，遵守现有候选窗口规则。
- 选择符号后关闭符号中心，并恢复进入前尚未提交的普通组合；符号插入位置必须是当前 TSF 文本光标位置。

### 4.3 最近使用

最近使用保存在用户数据目录中，只记录符号稳定 ID、使用次数和最后使用时间，不记录周边正文。排序使用确定性规则：最近使用时间、使用次数、稳定 ID。同一状态下候选不可异步跳动。

### 4.4 用户自定义符号

内置文件与用户文件分离：

```text
安装目录\data\symbols.tsv
%LOCALAPPDATA%\PiInput\UserData\symbols_user.tsv
```

内置文件随版本更新；用户文件在升级和默认卸载时保留。只有用户明确选择“删除个人数据”时才删除。

用户文件采用 UTF-8 TSV：

```text
文本<TAB>中文名称<TAB>分类<TAB>排序<TAB>启用
※<TAB>参考标记<TAB>我的符号<TAB>100<TAB>1
（待确认）<TAB>待确认标记<TAB>我的短语<TAB>90<TAB>1
```

规则：

- `文本`可以是一个 Unicode 符号，也可以是短文本；设置合理的长度上限，拒绝控制字符和换行。
- `中文名称`与`分类`不能为空。
- 排序必须是有界整数；启用只接受 `0/1`。
- 无效记录按行忽略并记录错误，不影响其他记录。
- 同文本重复时用户记录优先于内置记录；用户文件中的重复项采用最后一条有效记录。
- 加载完成后生成不可变快照；文件变化只在下一次打开符号中心时原子重载，不修改已经显示的候选顺序。

本阶段不制作独立设置窗口。帮助中明确给出用户文件位置、格式示例和“恢复默认”的方法。后续设置界面只编辑同一文件格式。

## 5. 模块边界

功能放在可升级 Host 中，不增加稳定 TSF Shim 的业务职责：

- `CommandRouter`：识别可配置的功能快捷键和已启用的中文文本别名，维护菜单层级。
- `HelpCatalog`：读取中文帮助文件并生成菜单项。
- `SymbolCatalog`：合并内置符号和用户符号，提供分类与稳定查询。
- `RecentSymbols`：管理最小化的本地最近使用数据。
- `HostSession`：保存普通输入与功能菜单的独立状态，负责进入、退出和恢复。
- `CandidatePresenter`：继续负责一行默认显示、用户请求后的多行展开及文本光标定位。

TSF Shim 只把修饰键和按键事件传给 Host，并执行 Host 确认后的文本提交；不解析帮助文件或符号文件。

## 6. 失败处理

- 帮助文件缺失：显示内置的最小中文错误页，并提示重新安装；中文输入本身继续可用。
- 内置符号文件缺失：符号中心显示错误说明；输入法其他功能继续可用。
- 用户符号文件缺失：视为空文件，首次需要时创建示例文件。
- 用户文件部分损坏：仅跳过错误行；不得清空或覆盖用户原文件。
- 最近使用数据损坏：隔离损坏文件并从空记录开始，不影响符号选择。
- Host 异常退出：稳定 Shim 按现有重启机制恢复；未确认的菜单选择不得写入应用。

## 7. 测试与验收

### 7.1 入口兼容

- `Ctrl+Alt+反引号` 在中文、英文状态均打开功能菜单。
- `Ctrl+反引号` 默认交给应用，确保 VS Code 集成终端等快捷键不被抢占。
- 单、双、三反引号在中文和英文状态均原样输出；Markdown 行内代码与代码块完整不变。
- `middle_dot_alias=false` 时所有间隔号与反引号原样处理；`true` 时 `··f`、`··h` 大小写形式正确触发，未知 `··x` 原样保留。
- Shift、Ctrl、Alt 组合不产生重复按键或错误的中英文切换。

### 7.2 帮助

- 所有帮助目录和正文均为中文。
- 键盘操作、全拼、小鹤、候选数量、翻页、Shift、词库、安装卸载和数据位置都有入口。
- 帮助文件缺失和坏行不会导致输入法崩溃。

### 7.3 符号

- `data/symbols.tsv` 的全部 140 个内置符号逐项可浏览、可选择、可正确上屏。
- 分类总数与每类数量固定校验，不允许发布时遗漏符号。
- 一行默认显示；按 `=`/下方向键后按现有规则展开和滚动；`-`/上方向键反向移动。
- 用户符号覆盖、禁用、重复、Unicode、多字符、非法字段和长度边界均有测试。
- 最近使用排序稳定，不记录上下文文本。

### 7.4 回归

- 运行现有全部全拼、小鹤、406 合法码、3500/7000 汉字、长句、分段取字、英文补全、中文标点、安装卸载、Host 重启和候选光标定位测试。
- 功能菜单不得让其他输入法失效，不得导致 TSF 递归、堆栈溢出或候选窗口无输入时自动弹出。

## 8. 发布与文档

发布包必须包含：

```text
data\help_zh.tsv
data\symbols.tsv
docs\安装与使用指南.md
```

安装指南增加“按 `Ctrl + Alt + 反引号` 打开功能菜单”的图文说明、用户符号文件示例和 Markdown 兼容说明。版本说明明确指出旧的分号符号命令不再作为公开交互；用户通过符号中心浏览全部内容。

本阶段不自动安装、不推送远程仓库。完成编译和全量测试后生成新的 Windows ZIP，由用户自行运行安装器验证。
