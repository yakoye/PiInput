# PiInput-Test 英文候选与自由文本测试区设计

## 目标

让独立的 `PiInput-Test.exe` 同时验证中文拼音/双拼和离线英文候选，并提供一个可直接输入、粘贴、换行、选择和删除文本的多行编辑区，用作不占用 TSF DLL 的轻量测试记事本。

## 界面与行为

- 顶部“测试文本”区域是标准 Win32 多行编辑框，始终允许自由编辑；候选提交追加到当前插入点，而不是强制追加到末尾。
- “输入模式”下拉框包含“中文候选”和“英文候选”。
- 中文模式继续显示“全拼/小鹤双拼/自然码/微软/智能 ABC”方案；英文模式隐藏拼音方案的实际作用，但保留用户上次中文方案。
- 英文模式读取发布包中的 `english_lexicon.tsv`、`english_supplement.tsv` 和补全偏好，并合并本机可选的 downloaded/user/learning TSV。
- 英文候选输入框接受 ASCII 字母；输入一个字母即显示 typed candidate 与多个补全候选。空格、Enter、数字键、上下键和双击均可选词。
- 英文候选提交后自动追加一个空格，便于连续句子测试；中文和符号提交不自动加空格。
- 清空按钮只清空测试文本，不修改词库和学习文件。

## 边界与错误处理

- 英文词库文件缺失时程序仍能打开，状态栏明确说明缺失文件；中文测试不受影响。
- 测试台仅链接 `piinput_core`，不加载 `PiInputTSF.dll`，不注册/卸载输入法。
- 英文学习数据只在用户实际选择候选后保存到 `%LOCALAPPDATA%\PiInput\UserData\english_learning.tsv`。

## 验证

- 源码回归测试锁定模式控件、多行编辑、英文资源与学习路径。
- 复用 `EnglishSession` 已有行为测试验证 `r/re/rev/book` 等前缀候选。
- Windows Release 构建后人工验证中文候选、英文候选、自由文本输入/粘贴/换行及候选插入点提交。
