# PiInput v0.2.0 输入基础完善设计

## 目标与边界

本版本只完善全拼、小鹤双拼、本地词库、候选排序、检索性能与自动化测试。保持纯离线、无 AI、无语音、无广告、候选不跳变、用户数据可控。自然码、微软双拼、智能 ABC 保持现状，不扩展新功能。

## 输入解析

- 词库内部统一保存无声调、以 `'` 分隔的标准拼音。
- 全拼支持连续切分、手工分隔、`ü/v/u:` 归一化和稳定的歧义切分顺序。
- 小鹤双拼以公开键位规则生成完整合法音节映射，严格验证零声母、`j/q/x/y + ü`、双键音节和多音节组合。
- 奇数长度的小鹤输入保留为合法前缀状态，但只对已经完成的双键音节产生候选，避免人为等待。

## 词库流水线

外部词库固定在源码同级 `dicts/`，源码更新不得删除。`update-dictionaries.cmd` 调用 PowerShell 脚本下载或更新以下开源仓库，并保留本地 SCEL/TSV：

- `mozillazg/pinyin-data`：单字读音；
- `mozillazg/phrase-pinyin-data`：词语读音；
- `rime/rime-pinyin-simp`：通用输入词库；
- `thunlp/THUOCL`：可选领域词表。

下载采用 Git 浅克隆或快进更新，断网或更新失败时保留上一版可用缓存。构建器把 Rime YAML、pinyin-data 和 PiInput TSV 转为统一 TSV，再交给现有二进制编译器生成 `.lex`。THUOCL 默认不混入通用词库，避免专业词污染普通候选。

## 检索与排序

- 词库只在引擎启动时加载一次；按键热路径不访问网络、不解析源词库、不写磁盘。
- 内存索引按标准拼音直接定位候选桶，不扫描完整词库。
- 排序键固定为：综合分、基础权重、词长、拼音、汉字，确保相同输入和数据得到相同顺序。
- 用户学习使用有上限的本地加权，不允许溢出，也不改变已经显示的候选快照。
- 句子组合只读取每个拼音区间的有限候选，避免词库扩大后组合爆炸。

## 测试与验收

- 数据驱动测试覆盖用户给出的 32 组小鹤口诀字、全部零声母、常用组合词和同批全拼。
- 候选测试区分“编码正确”和“目标字/词可检索”，冷僻字不强求首选。
- 增加非法输入、删除回退、歧义切分、候选稳定、重复词合并和大词库查询测试。
- Windows Release 必须构建全部目标并通过 CTest。
- `wo → 我` 核心热查询以 10,000 次基准记录 P50/P95/P99；本版本目标 P95 不超过 2 ms，P99 不超过 5 ms。

## 数据与许可证

仓库只提交脚本、小型回归夹具和许可证说明，不提交下载得到的大型源词库。每个下载源记录仓库地址、用途和许可证。搜狗公开 SCEL 只由用户本地导入；不提取搜狗或微信安装目录中的内部基础词库。
