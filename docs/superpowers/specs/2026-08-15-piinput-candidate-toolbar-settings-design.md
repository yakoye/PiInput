# PiInput 候选栏工具入口与视觉设置设计

## 目标

在保持候选栏单行、简洁、稳定且不抢输入焦点的前提下，在候选栏右侧增加工具入口。首版仅提供“符号”和“设置”，并允许用户通过原生设置窗口调整候选文字大小与单行候选框高度。

## 范围

- 候选栏最右侧增加固定工具按钮，不占候选编号，不挤占数字键选词。
- 点击工具按钮后显示仅含“符号”“设置”的轻量菜单。
- “符号”复用现有符号中心和符号数据，不模拟键盘输入 `;;f`。
- “设置”打开独立的原生 Win32 设置程序。
- 设置程序负责全拼/小鹤双拼、默认中文/英文、候选文字大小和单行候选框高度。
- 配置仍保存到 `%LOCALAPPDATA%\PiInput\UserData\settings.ini`，使用安全的临时文件替换方式写入。
- 不修改解码、词库加载、候选排序和输入热路径。

## 用户交互

### 候选栏

- 普通输入时保持现有 48 DIP 单行候选布局。
- 右侧工具按钮固定宽度，不参与候选宽度估算。
- 工具菜单使用 `WS_EX_NOACTIVATE`，打开与点击“符号”时不夺走编辑框焦点。
- 菜单关闭条件：选择项目、按 Esc、候选组合结束、焦点切换到其他输入会话。

### 符号

- 点击“符号”后，当前输入组合保持安全一致；Host 直接进入现有符号中心状态。
- 候选栏显示符号候选，数字键、方向键、空格等继续使用现有选词逻辑。

### 设置

- 点击“设置”启动 `PiInput-Settings.exe`，设置窗口允许获得焦点。
- 当前编辑程序中的组合状态由既有 Host/TSF 恢复机制保存；设置窗口关闭后可继续输入。
- 设置项：
  - 候选文字大小：10～28 DIP，默认 18 DIP。
  - 单行候选框高度：20～72 DIP，默认 48 DIP，文字始终垂直居中。
  - 输入方案：全拼或小鹤双拼，默认小鹤双拼。
  - 默认输入语言：中文或英文，默认中文。
- 设置窗口显示与实际候选栏相同风格的预览。
- “应用”原子写入配置；“恢复默认”恢复 18/48；非法值不能写入。
- 为避免正在显示的候选框突然跳动，视觉配置在下一次输入组合开始时应用。

## 数据模型

在 `[candidates]` 增加：

```ini
font_size=18
window_height=48
```

对应 `CandidateSettings`：

```cpp
std::uint32_t font_size{18U};
std::uint32_t window_height{48U};
```

解析范围固定为 10～28 和 20～72。输入方案只接受 `full`/`flypy`，默认语言只接受 `chinese`/`english`。字段缺失保持默认值；字段非法时保留上一个有效值并记录设置错误。

## 模块边界

- `settings.*`：配置解析、默认值和序列化。
- `candidate_window.*`：视觉尺寸、工具按钮绘制、鼠标命中和无激活菜单。
- `candidate_presenter.*`：向窗口下发当前视觉设置并接收工具动作。
- `session_manager.*`：把“符号”动作路由到当前 HostSession。
- `PiInput-Settings.exe`：负责加载、预览和原子保存输入方案、默认语言与视觉设置。
- 安装器/打包脚本：安装设置程序和创建可调用入口。

## 稳定性约束

- 工具入口不得导致候选重排、候选代次变化或窗口位置跳动。
- 绘制与点击不得加载词库、访问网络或同步写入用户学习数据。
- 候选窗继续使用 DPI 感知的 GDI ClearType 绘制。
- 设置程序失败不得影响输入法；读取失败时使用当前有效配置。
- 鼠标点击工具按钮和菜单不得把按键发送到错误的输入会话。

## 验收

自动测试覆盖设置边界、默认值、配置保留、候选高度与字体缩放、命中区域、菜单动作、符号路由、设置程序写入和发布文件。

真实 Windows 测试覆盖 PiInput-Test、Notepad4、Notepad++、Microsoft Word：

- 新开程序后立即输入，无额外词库加载延迟；
- 候选窗跟随文本光标，清晰度正常；
- 工具按钮、符号入口与设置入口可用；
- 修改字体和高度后，下一个输入组合按新值显示；
- 跨窗口切换后配置一致，候选与编辑焦点正常；
- 普通数字键、空格、方向键、`-`、`=` 行为不回退。
