# 候选交互与常用词完善 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成全拼/小鹤常用词命中、动态分页、横向候选和 Shift 中英文切换，并建立系统化测试集合。

**Architecture:** 在跨平台核心新增纯逻辑分页、设置和 Shift 状态机，Windows TSF 只负责键盘事件与绘制。词库构建器按来源可信度合并词频，避免无词频数据覆盖真实词频；所有交互规则先由核心单元测试验证，再接入 TSF。

**Tech Stack:** C++20、CMake/CTest、Win32/TSF/GDI、PowerShell、LiteIME `.lex`
