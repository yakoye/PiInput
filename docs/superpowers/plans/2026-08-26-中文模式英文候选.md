# 中文模式英文候选 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在中文输入模式下混入英文单词候选，核心场景是拼写辅助（打 `belie` 补出 `believe`，打 `palad` 补出 `palladium`），默认关闭，开启后不破坏任何现有行为。

**Architecture:** 新增纯函数组件 `english_completion` 承担全部规则计算（位置查表、触发条件、大小写），输入是"输入串 + 中文候选摘要 + 词库 + 设置"，输出是"插到第几位 + 插哪些词"。`HostSession::snapshot()` 只负责调用它并按返回位置合并，合并时跳过快捷命令占位。词库分两层：现有 24,323 词表占高分段，开源大表占低分段，靠现有排序链天然分层。

**Tech Stack:** C++20、CMake、CTest；现有 `EnglishLexicon`（已有前缀索引、学习与持久化）、`CandidateEvidence::covers_all_input`、`CandidateKind`。

enum class EnglishCandidateFlag : std::uint32_t {

// include/piinput/host_session.h

};

// include/piinput/settings.h
struct EnglishSettings {
    bool enabled{false};
    bool builtin_dictionary{true};

- [ ] **Step 4: 写位置查表实现**

`src/english_completion.cpp`：

```cpp
#include "piinput/english_completion.h"

#include <algorithm>
#include <cctype>

namespace piinput {
namespace {

// 阈值对着实测的竞品行为标定：全拼下 he（和 6252031）不给英文，
// an（按 3826950）压到行尾，name（那么 501795）第二位，
// code（错的 105000）第一位。
struct StartPositionThresholds {
    std::int64_t suppress_above;   // 高于此值完全不给英文
    std::int64_t demote_above;     // 高于此值排到 demoted_position
    std::int64_t second_above;     // 高于此值排第二位
    std::size_t demoted_position;
};

constexpr StartPositionThresholds kFullPinyin{
    .suppress_above = 5000000,
    .demote_above = 1000000,
    .second_above = 200000,
    .demoted_position = 5U,
};

// 双拼下 he、an、time、name、code 全都能拼出高频中文，covers_all_input
// 几乎总是真，所以门槛整体抬高，避免英文抢掉常用字。
constexpr StartPositionThresholds kDoublePinyin{
    .suppress_above = 3000000,
    .demote_above = 600000,
    .second_above = 100000,
    .demoted_position = 5U,
};

}  // namespace

std::size_t english_start_position(
    const ChineseCandidateSummary& chinese, const bool double_pinyin) noexcept {
    if (!chinese.has_candidates) return 1U;
    // 中文候选只是简拼或前缀猜出来的，本质不确凿，英文理应排前面。
    if (!chinese.covers_all_input) return 1U;
    const StartPositionThresholds& limits = double_pinyin ? kDoublePinyin : kFullPinyin;
    if (chinese.top_score > limits.suppress_above) return 0U;
    if (chinese.top_score > limits.demote_above) return limits.demoted_position;
    if (chinese.top_score > limits.second_above) return 2U;
    return 1U;
}

std::string apply_input_case(
    const std::string_view input, const std::string_view word) {
    std::string result(word);
    if (input.empty() || result.empty()) return result;
    const auto is_upper = [](const char value) {
        return value >= 'A' && value <= 'Z';
    };
    const bool all_upper = std::all_of(input.begin(), input.end(), [&](const char value) {
        return !std::isalpha(static_cast<unsigned char>(value)) || is_upper(value);
    });
    if (all_upper && input.size() > 1U) {
        for (char& value : result) {
            value = static_cast<char>(std::toupper(static_cast<unsigned char>(value)));
        }
        return result;
    }
    if (is_upper(input.front())) {
        result.front() = static_cast<char>(
            std::toupper(static_cast<unsigned char>(result.front())));
    }
    return result;
}

EnglishCompletionPlan plan_english_completion(
    const std::string_view input,
    const ChineseCandidateSummary& chinese,
    const EnglishLexicon& lexicon,
    const EnglishCompletionSettings& settings) {
    if (!settings.enabled || settings.max_items == 0U) return {};
    // 单字母噪音过大，且 a、i 会与大量拼音冲突。
    if (input.size() < 2U) return {};
    const bool all_ascii_letters = std::all_of(
        input.begin(), input.end(), [](const char value) {
            return (value >= 'a' && value <= 'z') || (value >= 'A' && value <= 'Z');
        });
    if (!all_ascii_letters) return {};

    const std::size_t position = english_start_position(chinese, settings.double_pinyin);
    if (position == 0U) return {};

    EnglishCompletionPlan plan;
    plan.start_position = position;
    for (const auto& candidate : lexicon.query(input, settings.max_items)) {
        plan.words.push_back(apply_input_case(input, candidate.word));
    }
    if (plan.words.empty()) return {};
    return plan;
}

}  // namespace piinput
```

- [ ] **Step 2: 写词库构建脚本**

`scripts/dev/build-english-lexicon.ps1`，把两层合并为一份 TSV：

```powershell
[CmdletBinding()]
param(
    [Parameter(Mandatory = $true)][string]$HighFrequencyTsv,
    [Parameter(Mandatory = $true)][string]$LargeWordlist,
    [string]$OutputTsv = "data/english_lexicon.tsv",
    [int]$LowFrequencyFloor = 50
)

$ErrorActionPreference = "Stop"
Set-StrictMode -Version Latest

# 高频层保留现有 24,323 词的相对次序，整体抬到 1,000,000 之上；
# 低频层压缩到 1..999,999。两段不重叠，因此大表里的任何词都压不过现有高频词。
$HighFrequencyBase = 1000000

$high = @{}
foreach ($line in Get-Content -LiteralPath $HighFrequencyTsv) {
    if ([string]::IsNullOrWhiteSpace($line)) { continue }
    $parts = $line -split "`t"
    if ($parts.Count -lt 2) { continue }
    $high[$parts[0].ToLowerInvariant()] = [int]$parts[1]
}
Write-Host "高频层：$($high.Count) 词"

$rows = New-Object System.Collections.Generic.List[string]
foreach ($word in $high.Keys) {
    $rows.Add(("{0}`t{1}`t2" -f $word, ($HighFrequencyBase + $high[$word])))
}

# 大表按词频降序读入，映射到 1..999,999；低于 LowFrequencyFloor 的丢弃，
# 冷僻词进候选只会制造噪音。
$large = @()
foreach ($line in Get-Content -LiteralPath $LargeWordlist) {
    if ([string]::IsNullOrWhiteSpace($line)) { continue }
    $parts = $line -split "[`t ,]+"
    $word = $parts[0].ToLowerInvariant()
    if ($word -notmatch '^[a-z]+$') { continue }
    if ($high.ContainsKey($word)) { continue }
    $weight = if ($parts.Count -ge 2) { [double]$parts[1] } else { 1.0 }
    $large += [pscustomobject]@{ Word = $word; Weight = $weight }
}
$large = $large | Sort-Object Weight -Descending
Write-Host "低频层候选：$($large.Count) 词"

$rank = 999999
$kept = 0
foreach ($entry in $large) {
    if ($rank -lt $LowFrequencyFloor) { break }
    $rows.Add(("{0}`t{1}`t2" -f $entry.Word, $rank))
    $rank--
    $kept++
}
Write-Host "低频层保留：$kept 词"

Set-Content -LiteralPath $OutputTsv -Value $rows -Encoding UTF8
Write-Host "已写出 $OutputTsv，共 $($rows.Count) 行"
```

## 风险与回滚

| 风险 | 处理 |
| --- | --- |
| 双拼阈值定得不准，英文抢位或永不出现 | 阈值集中在 `kDoublePinyin` 一处常量，用户实测后改一个数即可，不牵动逻辑 |
| 大词库引入噪音 | `-LowFrequencyFloor` 参数控制，重跑构建脚本即可调整，不改代码 |
| 前缀查询拖慢按键 | `piinput-keystroke-latency` 是硬门禁；若退化，改为仅在输入长度 ≥ 3 时查询 |
| 开关关闭时行为改变 | Task 3 Step 5 的回归断言专门锁这一条，失败即阻断 |
| 词表许可证不合规 | Task 2 Step 1 先核对再取用；不合规则换来源，不进入后续任务 |
