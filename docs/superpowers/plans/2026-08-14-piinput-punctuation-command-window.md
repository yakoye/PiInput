# PiInput 中文符号、命令入口与候选窗口实施计划

> 实施时遵循测试先行；不修改或清理工作区内其他未提交功能。

## 任务 1：配置与符号映射

1. 在设置测试中加入 `bracket_style=sogou|wechat`、默认值及非法值回滚测试。
2. 扩充 `punctuation_cases.tsv`，覆盖所有普通/Shift 符号。
3. 给 `PunctuationTransformer` 增加括号风格参数，实现搜狗默认和微信可选映射。
4. 更新默认设置、安装器默认配置和中文说明。

## 任务 2：命令路由

1. 在 HostSession 测试中加入 `;;f`、双反引号别名、旧符号搜索、未知序列和 Markdown 反引号失败用例。
2. 新增独立的纯 C++ 命令前缀分类器，区分等待、触发、普通文本。
3. 将命令分类器接入 HostSession；符号中心复用 SymbolIndex。
4. 为帮助和拆字保留 `h/u` 字母，但在对应数据尚未实现时按未知序列处理，不吞键也不打开窗口。
5. 在稳定 TSF shim 中把反引号/分号作为可组合原始按键交给 Host，不在 DLL 内重复实现路由。

## 任务 3：候选窗口

1. 增加候选窗口布局纯函数测试：新组合重置、工作区上限、DPI、行数变化、长文本无省略。
2. 移除只增不减的宽度锁定；锁定锚点，允许当前快照按受限规则重新计算尺寸。
3. 标题改为按文本光标水平裁剪，绘制不使用 `DT_END_ELLIPSIS`。
4. 候选列按屏幕预算和完整文本宽度选择每行项目数，不截断候选文字。
5. 保持一次输入变更只提交一个不可变候选快照；相同数据不重绘。

## 任务 4：验证和交付

1. 构建 Release 全目标并运行全部 CTest。
2. 安装布局测试确认配置、符号表、Host 和稳定入口 DLL 均存在。
3. 生成版本说明、验证记录和安装使用文档。
4. 打包开发 ZIP；本轮不推送远程仓库。
