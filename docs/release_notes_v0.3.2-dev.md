# PiInput v0.3.2-dev 版本说明

本版修复 Windows 输入法安装后短暂出现、随后从键盘列表消失的问题，并修复首次安装只加载演示词库导致合法拼音空候选的问题，不扩展新的产品功能。

## 修复

- 产品改名继续保留 PiInput 的显示名称、文件名、安装目录和用户数据目录。
- 恢复改名前已经被 Windows 接受的稳定 TSF/COM 内部身份，避免把产品改名错误地变成一个全新的第三方 IME 身份。
- 安装器继续使用版本并存目录，注册路径指向 `%LOCALAPPDATA%\PiInput\Dev\versions\<版本-构建号>\bin\PiInputTSF.dll`。
- 保留 `InstallLayoutOrTip` 当前用户键盘列表注册、Profile 激活和状态检查。
- 注册并在每次升级时刷新 Windows 系统托盘兼容类别，避免 Profile 已注册却从键盘列表消失。
- 安装包携带 459,505 条已验证的完整二进制基础词库，运行时优先加载，不再只依赖 349 条开发演示词。
- 增加完整合法音节的单字组合兜底回归：`xnhe`、`xnheul` 以及对应全拼不允许空候选。
- 品牌门禁继续禁止旧产品名称和路径，但允许不可见、必须稳定的内部 GUID。

## 未改变

- 默认小鹤双拼；
- 全拼、任意长度增量候选、候选排序和词库格式；
- 无 AI、无语音、无云端实时联想；
- 用户词库和设置继续保存在 `%LOCALAPPDATA%\PiInput\UserData`。
