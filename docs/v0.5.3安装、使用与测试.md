# PiInput v0.5.3 安装、使用与测试

## 安装

1. 解压 `PiInput-v0.5.3-dev-windows-x64.zip`。
2. 双击根目录的 `PiInput-Install.exe`。
3. 安装完成后，重新打开准备测试的程序，通过 `Win + Space` 选择 PiInput。

安装器采用稳定入口 DLL 和版本化 Host。升级不会要求关闭所有正在使用输入法的软件；已经打开的软件继续使用稳定入口，新组合会连接当前 Host。

## 基本输入

- 默认输入方案与默认中英文状态可在候选框右侧菜单的“设置”中选择。
- `Shift`：中文/英文切换。
- `Space`：确认当前候选。
- 数字键：选择当前行对应候选。
- 方向键：在候选间移动。
- `=`：向下展开/移动；`-`：向上移动。
- `;;f`、`；；f`、``f：符号中心。

## 固定与删除候选

在候选文字上点击鼠标右键：

- **固定首位**：当前拼音下，该候选立即移到第一位。
- **删除该词**：当前拼音下，该候选立即隐藏。

这两项只写入 `%LOCALAPPDATA%\PiInput\UserData\user_model.tsv`，不会改写随安装包分发的基础词库。

## 本版重点检查

- 小鹤输入 `nibawodetubn`：首选应为“你把我的图标”。
- 小鹤输入 `hzxrkl`：首选应为“候选框”。
- 右键固定第二个候选：它应立即成为第一候选；重新打开程序后仍保持。
- 右键删除某候选：它应立即消失；重新打开程序后仍保持。
- Windows 语言切换面板与任务栏应显示紫色 π 图标。Windows 图标缓存可能在安装后的第一次 `Win + Space` 刷新。
