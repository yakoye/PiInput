# PiInput v0.5.3-dev 版本说明

本版集中修复候选质量与可控性，不增加联网、AI 或语音功能。

- 升级时刷新 Windows TSF Profile 的紫色 π 图标缓存。
- 中文候选改用 `Microsoft YaHei UI` 并按真实字体高度垂直居中。
- 句中“吧、吗、呢”等语气词降权，避免“你吧我的图标”压过“你把我的图标”。
- Unicode 扩展区生僻字在普通候选中降权。
- 补充常用词“候选框”，全拼 `houxuankuang`、小鹤 `hzxrkl` 均为首选。
- 在候选上点击鼠标右键，可选择“固定首位”或“删除该词”。设置原子保存到本地用户模型，不修改原始词库。
