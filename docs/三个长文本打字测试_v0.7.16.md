# 三个长文本打字测试（v0.7.16）

v0.7.16 继续执行三组真实文本逐键回放、段落输入、结构化语料和逐键延迟门禁，结果与 v0.7.15 一致，无回归。

本版的改动集中在安装、升级和候选窗摆放，未触及解码、排序、标点或学习逻辑，因此长文本结果预期不变；执行仍是必需的，用来确认候选窗摆放改动没有经由几何锁定路径影响到连续输入。

## 本版必须复验的项

- 普通桌面宿主（记事本、Notepad++、浏览器地址栏）的候选窗位置与 v0.7.15 逐像素一致。遮挡避让只在宿主为 `SearchHost.exe` 时介入，其余宿主传入的遮挡矩形为空。
- 连续输入过程中候选窗不因避让逻辑反复跳位。搜索面板矩形每次实时读取，面板随结果加载变高时候选窗应保持在面板上沿之上不动。
- `piinput-keystroke-latency` 与 `piinput-typing-latency` 未因宿主识别查询而退化。识别结果按 owner 窗口缓存，只在 owner 变化时解析一次。

## 真实应用手工测试

必须使用验证记录中的同一 build ID，不能沿用 v0.7.15 的进程或安装结果。搜索框一项此前从未通过，本版首次可验收：在任务栏搜索框输入 `vswf`，候选行须完整可见并可翻页，而不是只能靠空格盲选上屏。
