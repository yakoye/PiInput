# PiInput 词库更新说明

## 一键更新

将源码目录与 `dicts` 放在同一父目录：

```text
C:\Users\color\Downloads\piinput
├── PiInput-repo
└── dicts
```

在源码目录双击 `update-dictionaries.cmd`。脚本会下载或更新 `pinyin-data`、`phrase-pinyin-data`、`rime-pinyin-simp` 和 `THUOCL`，转换本地 SCEL 与用户 TSV，生成统一词库，运行关键候选及延迟验证，最后才原子替换旧词库。

完整英文词频源不是默认更新项。如需下载固定版本的
`aparrish/wordfreq-en-25000` 到外部 `dicts/sources`，运行：

```powershell
.\scripts\update-dictionaries.ps1 -IncludeEnglish
```

脚本会验证固定 SHA-256，下载或校验失败时保留已有英文缓存，并继续使用现有中文词库。
源码包只安装精简的 `data/english_lexicon.tsv`，不会打包完整 25k 第三方数据。

## 目录用途

```text
dicts/
├── sources/      自动管理的开源源仓库，不要手工改动
├── scel/         推荐放置用户下载的 SCEL
├── user/         自定义 TSV，格式为 word、pinyin、weight
├── generated/    可检查的统一 TSV
└── cache/        输入法使用的二进制词库
```

为兼容旧目录，放在 `dicts` 根目录的 `.scel` 也会被递归发现。

## 缓存和失败保护

- 源提交和本地文件哈希未变化时直接复用缓存；
- 下载、转换、候选测试或性能测试失败时不替换旧词库；
- 新词库先在临时目录生成并验证，再更新 `dicts/cache/piinput-base.lex`；
- 验证成功后同步到 `%LOCALAPPDATA%\PiInput\UserData\lexicons\piinput-imported.lex`；
- 输入法已加载旧词库时，重新切换 PiInput 或重新打开目标应用即可加载新数据。

## 排序原则

不同来源的原始权重不按多字路径直接相加。引擎使用对数词频、完整词奖励、每词惩罚、用户本地学习和固定同分规则。相同输入、词库和用户模型得到相同候选顺序。

`THUOCL` 当前仅下载和缓存，不默认并入通用词库，避免专业词污染日常首选。

## 完整测试

双击 `run-ime-tests.cmd`。测试覆盖 413 个标准音节、用户指定的小鹤口诀字、零声母、常用组合、同批全拼、真实 SCEL、候选快照、稳定排序和 `wo` 热查询延迟。
