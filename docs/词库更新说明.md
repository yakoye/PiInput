# PiInput 词库更新说明

## 中文基础词库

源码目录与词库目录应位于同一父目录：

```text
C:\Users\color\Downloads\PiInput
├── PiInput-repo
└── dicts
    └── rime-ice-full
```

发布用中文候选只从 `rime-ice-full/rime_ice.dict.yaml` 声明的默认表导入：
`8105`、`base`、`ext`、`tencent`、`others`。脚本按声明顺序读取；同一“显示文字 + 拼音”
重复出现时，先声明的表获胜。

PiInput 原来的精选表、`rime-pinyin-simp`、THUOCL、SCEL、`pinyin-data`、
`phrase-pinyin-data` 和 `dicts/user/*.tsv` 不再混入发布用中文候选。发布包只携带编译后的
`data/piinput-base.lex`，不再携带 `base_lexicon.tsv`，避免项目自造词和多个公共来源互相污染。

构建命令：

```powershell
.\scripts\build-dictionaries.ps1 `
  -RimeIceRoot 'C:\Users\color\Downloads\PiInput\dicts\rime-ice-full'
```

只构建验证、不更新当前系统词库时加 `-SkipInstall`。导入明细写入
`dicts/generated/rime-ice-import-report.tsv`，最终二进制写入
`dicts/cache/piinput-base.lex`。构建使用 `rime-ice-default-v1` 配置，不私自启用 Rime Ice
默认入口没有声明的扩展表。

## 个人学习词库

`%LOCALAPPDATA%\PiInput\UserData\user_model.tsv` 是独立的个人学习层。它不会被打包进公共
基础词库，也不会在基础词库更新时被覆盖。

- 正常候选只显示基础词库中的真实词条或已经确认提交的个人学习词；
- 完整匹配的真实词在前，较短的真实前缀词可继续占用第二、第三行，最后才显示第一音节单字；
- 整串输入全部解码、但没有单条词库条目能覆盖它时，把词库里的真实多字词拼接成覆盖全部音节的候选并排在最前，最多两条；
- 拼接只能用真实多字词，单字不得作为衔接，因此 `bwffyshu` 给出「备份用户」，而全是单字的输入不会被拼成句子；
- 同样覆盖全部输入时，单条真实词库条目排在拼接候选之前；
- 同一显示文字只出现一次；
- 选择较短词或单字后保留剩余拼音，最后一个片段才一次提交；
- 应用确认提交成功后，整句、所选多字词和相邻片段进入个人学习层；失败的提交不学习；
- 选过一次即可在所属候选组内提升，但较短学习词不会越过完整输入的真实整词。

Rime Ice 原始权重决定首次排序。相同输入、基础词库和用户模型会得到稳定候选顺序。

## 目录用途

```text
dicts/
├── rime-ice-full/ Rime Ice 完整仓库，发布中文候选的唯一公共来源
├── sources/       旧源或开发对照材料，不进入发布中文候选
├── scel/          旧 SCEL 或开发对照材料，不进入发布中文候选
├── user/          旧自定义 TSV，不进入发布中文候选
├── generated/     可检查的统一 TSV 和 Rime Ice 导入报告
└── cache/         输入法使用的二进制词库
```

## 缓存和失败保护

- 源文件哈希未变化时直接复用缓存；
- 转换、候选测试或性能测试失败时不替换旧词库；
- 新词库先在临时目录生成并验证，再更新 `dicts/cache/piinput-base.lex`；
- 正常构建成功后同步到 `%LOCALAPPDATA%\PiInput\UserData\lexicons\piinput-imported.lex`；
- 使用 `-SkipInstall` 时不触碰当前系统词库；
- 输入法已加载旧词库时，重新切换 PiInput 或重新打开目标应用即可加载新数据。

## 英文词库

完整英文词频源不是默认更新项。需要固定版本英文源时运行：

```powershell
.\scripts\update-dictionaries.ps1 -IncludeEnglish
```

转换结果格式为 `word<TAB>positive_weight<TAB>flags`，只保留 ASCII-only 单词。
`flags` 是十进制 `uint32` 位掩码：`builtin=1`、`downloaded=2`、`user=4`、`proper=8`。
运行时文件包括 `english_downloaded.tsv`、用户维护的 `english_user.tsv` 和
`english_learning.tsv`；程序管理设置分别通过 `builtin_dictionary`、`user_dictionary`、
`user_learning` 控制加载和学习。

## 完整测试

双击 `run-ime-tests.cmd`。测试覆盖全拼与小鹤解析、真实词优先、多行词语、显示去重、
部分选择、确认后学习、词库导入报告、稳定排序和热查询延迟。
