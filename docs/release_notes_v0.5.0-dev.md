# PiInput v0.5.0-dev 版本说明

本版集中完善候选栏的常用入口和外观设置，不改变 PiInput 的核心定位：轻量、离线、快速、稳定，不加入 AI、语音或云端实时联想。

## 候选栏定位修正

- 候选框变宽、展开或打开工具菜单后会再次限制在文本光标所在显示器内；
- 支持位于主屏左侧、使用负坐标的显示器；
- 便携视觉测试不再使用固定屏幕坐标。

## 新增

- 候选栏改为 48 DIP、16 DIP 字体的紫色极简样式，使用浅灰自绘边框和淡紫圆角首选；
- 候选栏最右侧增加独立的展开按钮和固定工具按钮；
- 工具菜单当前只包含“符号”和“设置”；
- 点击“符号”直接进入原有符号中心，与 `;;f`、`；；f`、``f` 的结果一致；
- 新增原生 `PiInput-Settings.exe`；
- 可设置候选文字大小，范围为 10～28；
- 可设置单行候选框高度，范围为 20～72 像素，文字始终垂直居中；
- 可在设置中选择全拼或小鹤双拼；
- 可选择启动后的默认输入语言为中文或英文；
- 字号和高度下拉框支持鼠标滚轮逐格加 1、减 1；
- 设置页预览与实际候选栏使用垂直居中绘制，说明文字不再带灰色底纹；
- 设置页按输入和外观分组，统一间距、对齐、范围提示与按钮布局；
- 设置使用原子写入，保留配置文件中其他选项和注释；
- 保存后从下一次新输入开始生效，不重启 Host、不重新加载大词库。

## 交互约束

- 正常输入仍只显示一行候选；
- 只有用户按 `=`、下方向键或点击工具按钮时才展开相应内容；
- 工具按钮不占用数字候选编号；
- 点击工具菜单不抢走当前编辑框焦点；
- 候选内容没有变化时不重复刷新窗口。

## 测试重点

- 设置解析、边界、输入方案、默认语言、原子保存和保留未知配置；
- 工具按钮与菜单命中区域；
- 符号入口只作用于当前应用的当前输入会话；
- 设置热更新前后窗口高度确实变化；
- 大词库路径和条目数在视觉设置更新期间保持不变；
- Windows Release 全目标和完整 CTest。
