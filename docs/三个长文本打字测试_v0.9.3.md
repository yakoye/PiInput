# 三个长文本打字测试（v0.9.3）

v0.9.3 继续执行三组真实文本逐键回放、段落输入、结构化语料和逐键延迟门禁，结果与 v0.9.2 一致，无回归。

本版有两处改动会经过正常输入路径，所以这一轮比上一版更值得认真看：

- **标点兜底**只在「周边文本读不出来」时才启用。语料回放走的是能读出周边文本的路径，因此回放结果预期逐字节不变。
- **按位置插入的顺序**改了（从后往前改成从前往后并记住上一条落点）。快捷调用与常用语都经过它，所以候选行的内容必须逐项核对。

## 本版必须复验的项

- **回放输出与 v0.9.2 逐字节一致。** 出现任何差异都要查清原因——尤其要排除排序改动波及了普通词条。
- **候选位置没有移动。** `fh`/`bq`/`sz`/`msp`/`jsq` 仍固定在候选 2，`jsq` 的程序员计算器仍在候选 3，`riqi`/`shijian` 的日期时间入口仍在候选 2。
- **标点数量守恒。** 每一个按下的标点都必须到达文档。
- **延迟门禁未退化。** 兜底只是一次字符串赋值，调色板是一次结构体拷贝，两者都不应出现在 p95 里。
- **v0.8.4 – v0.9.2 的修复仍然有效**：横杠可输入、句号形态由提交文本决定、候选解析耗尽时标点不丢、常用语的三条触发路径。

## 真实应用手工测试

必须使用验证记录中的同一 build ID。**每个受测程序都要完全退出重开**——输入法组件是 DLL。

1. **飞书里的句号**（本版重点）：在飞书里打 `geek` 再按句号，应得 `geek.`；再按一次得 `geek.。`。打中文后按句号仍直接得 `。`。
2. **冒号同样**：飞书里打 `http` 再按冒号得 `http:`；打「注意」再按冒号直接得 `：`。
3. **普通编辑器未受影响**：记事本、Notepad++ 里重复上面两条，结果应与以前完全一致。
4. **配色三挡**：打 `zt`，候选 2/3/4 依次是跟随系统／浅色／暗色；各选一次，候选框配色立即改变。
5. **跟随系统**：选「跟随系统」后，在 Windows 的「个性化 → 颜色 → 默认应用模式」里切换深浅，下一次打字时候选框应跟上。
6. **双拼用户也能到**：把输入方案切到小鹤双拼，打 `vuti` 应同样出现三挡。
7. **数字输入完全没变**：打 `123`、`0.8.1`、`2026`，逐字符如实输出。
8. **常用语照旧**：别名命中、中文留空触发码命中首字声母、数字打前 3 位出建议按 `Tab` 补齐。
9. **升级不中断已开程序**：装上本版后不重启任何已打开的程序，在其中继续打字应正常工作。
