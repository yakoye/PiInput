# PiInput v0.6.8-dev 安装、使用与测试

## 安装

1. 解压 `PiInput-v0.6.8-dev-windows-x64.zip`。
2. 双击 `PiInput-Install.exe`。
3. 接受 Windows 管理员权限提示。
4. 完全关闭并重新打开用于测试的编辑器。
5. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版测试

### 一、分段取字连续选字

输入 `meilie`（全拼）或 `mwlp`（小鹤），按 `=` 进入逐字候选，按数字选「每」。

期望：「每」进入组合区，候选**立即切换到下一个音节 `lie` 的字表**，可以接着按数字选第二个字，不需要再翻行。

### 二、候选框五行

候选框展开后应显示五行。

注意：如果 `%LOCALAPPDATA%\PiInput\UserData\settings.ini` 里写着 `visible_rows=3`，它会覆盖新默认值，需要手工改成 `visible_rows=5`。

### 三、编号与文字对齐

展开多行候选，检查非活动行（不显示编号的行）的文字是否与活动行的文字左边对齐。

### 四、标点后输入

连续输入：

```text
中文符号中文符号中文
```

观察每个标点之后继续打字是否跟手。

### 五、标点后连续快速输入

打完标点后立刻连续敲两三个字母，第一个字母应当**单独、立刻**出现，而不是和第二个字母一起蹦出来。

## 卸载

在 Windows“已安装的应用”中卸载 PiInput，或运行安装目录中的 `PiInput-Uninstall.exe`。
