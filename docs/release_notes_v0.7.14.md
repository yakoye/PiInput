# PiInput v0.7.14 版本说明

v0.7.14 主要完善中文输入状态下的标点选择和常用工具入口。

## 中文输入时使用英文标点

- 设置页“标点符号”新增清晰可见的三态选择：“中文标点 / 中文时使用英文标点 / 程序员标点”。
- 选择“中文时使用英文标点”后，拼音组合和中文候选保持不变，全部物理标点键统一输出 ASCII。
- 句号、冒号、逗号和斜杠不再被 TSF 智能标点旁路抢先转换；设置只在新的组合边界生效，避免一个词输入到一半切换规则。
- 选回“中文标点”即可恢复数字、时间、版本号与中文正文的上下文智能规则。

## 分号与工具候选

- 中文状态的单个分号恢复标点本义，直接输出 `；`；旧 `;;f`、`;;u` 和 `;关键词` 命令不再占用分号。
- `fh/fuhao/fuh/fuhc` 的候选 2 为 `Ω符号`，`bq/biaoqing/biaoq/bnqk/bnq` 的候选 2 为 `😜表情`，选择后打开 `yesymbol.exe`。
- `shizhi/uevi/sz/shiz/uev` 的候选 2 为 `⚙️设置`，选择后打开设置程序。

## 发布边界

“关于 PiInput”现在显示版本、精确构建标识、UTC 构建时间、完整 Git Commit ID 和项目联系方式，便于截图或远程反馈时确认实际加载的 DLL 身份。

本地压缩包属于未签名开发包，用于安装与功能验证。正式公开发布仍需可信 Authenticode 证书、时间戳、完整安装升级卸载闭环以及同一冻结候选的真实宿主验收。
