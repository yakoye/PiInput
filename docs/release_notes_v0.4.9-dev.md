# PiInput v0.4.9-dev 版本说明

本版集中修复中文符号、符号中心入口和候选窗口，不增加联网或 AI 功能。

## 主要变化

- 中文符号默认采用搜狗拼音风格；全套普通/Shift 键位加入回归测试。
- `[punctuation] bracket_style=sogou|wechat` 可切换 `{}` 与 `「」`。
- `;;f`、`；；f` 和双反引号后接 `f` 打开同一个内置符号候选。
- 旧的 `;sheshidu` 等符号搜索继续兼容。
- 单反引号、Markdown 行内代码和三个反引号均保持 ASCII 原样；中文间隔号 `·` 从符号中心选择。
- 候选窗默认一行，显式按 `=`/下箭头后才逐行展开。
- 候选窗最大宽度限制为 600 DIP，长组合标题不再绘制省略号。
- 候选窗移除重复的编码标题行，折叠状态为 48 DIP；第一行按候选实际顺序逐项填充，空间足够时会提前显示原本位于展开行的后续候选。
- 4 字、6 字、8 字及更长候选会自动减少每行列数，避免候选文字被截断。
- 稳定入口优先使用宿主当前选择的真实插入点；选择位置无布局时才回退到 TSF Composition 末端，避免部分编辑器把候选窗向右多放一个组合串宽度。
- 文本坐标跨进程发送前按宿主窗口的 DPI 感知转换为物理屏幕坐标，避免不同缩放、不同编辑器中的横向和纵向间距不一致；应用确实不提供文本位置时才降级到系统 caret 或鼠标附近。
- 默认配置和安装文档增加中文括号风格说明。

## 保持不变

- 全拼、小鹤双拼、词库、候选排序和稳定 Host/TSF 架构不变。
- 中文模式中的 `++`、`--`、`==` 等常用操作符保持半角。
- 英文和程序员标点模式始终使用 ASCII。
- 本版不推送远程仓库。
