# PiInput v0.5.1 安装、使用与测试

## 安装

1. 解压 `PiInput-v0.5.1-dev-windows-x64.zip`；
2. 双击 `PiInput-Install.exe`；
3. 允许 Windows 管理员确认；
4. 安装完成后重新打开需要测试的程序；
5. 按 `Win + Space` 选择“PiInput 中文输入法（开发版）”。

## 基础使用

- 默认输入方案：小鹤双拼；
- `Space`：确认当前候选；
- 数字键：选择当前行候选；
- `=` / `↓`：展开或移动到下一行；
- `-` / `↑`：移动到上一行；
- 单独按下并松开 `Shift`：切换中文/英文；
- 候选栏尾部网格按钮：打开符号和设置入口。

默认候选栏为 40 DIP 高、16 DIP 字体。设置程序可将字号调整为 10～28 DIP，将单行高度调整为 20～72 DIP。

## 卸载

双击安装目录中的 `PiInput-Uninstall.exe`。默认保留用户词库和设置；需要彻底清理时，在卸载界面选择删除用户数据。

## 建议验收

分别在 Notepad4、Notepad++ 和 Word 中测试：

1. 输入 `wo`，候选第一项应为“我”；
2. 按空格，“我”应写入文档；
3. 候选框应贴近文本光标，并完整位于当前显示器；
4. 单独按 Shift 后应进入英文状态，再按一次返回中文；
5. 输入长串拼音时，候选框位置在当前 Composition 内保持稳定。
