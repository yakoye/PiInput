# PiInput v0.7.9 安装、使用与测试

## 安装

双击最外层 `PiInput-Install.exe`，不需要先卸载。`yesymbol.exe` 随包一起装到程序目录。

装完后**重新打开要测试的程序**，再用 `Win+Space` 切到 PiInput。

## 本版重点测试

### 一、中/英 和图标是一组（关键）

切到 PiInput 后，看**任务栏右下角的输入指示器**——就是平时显示「中」「英」的那个位置，不是通知区域的图标堆：

```text
中  π
```

要点：

1. 两个是**紧挨着的一组**，和微软拼音的「中 拼」位置一样；
2. **通知区域（小箭头展开的那片）里不应该再有 PiInput 图标**。上一版在那里放了两个，是错的；
3. 全屏数一下，整个任务栏只应有这一组，不该出现第三个图标。

### 二、中/英跟随系统主题

1. 当前主题下看「中」字的颜色；
2. 到 Windows 设置 → 个性化 → 颜色，切换浅色／深色；
3. 「中」字应跟着变成黑字或白字，背景始终透明，和旁边其他输入法的指示一致。

### 三、左键切换、右键菜单

1. **左键单击**任意一个按钮 → 中英切换，「中」立刻变「英」；
2. **右键单击** → 菜单：

```text
中文
小鹤双拼
──────────
符号
设置
──────────
关于 PiInput
帮助与反馈
```

3. 点「小鹤双拼」→ 切到全拼，再打开菜单应显示「全拼」；
4. 点「设置」→ 设置窗口打开；
5. 点「关于 PiInput」→ 显示版本 `0.7.9`。

### 四、符号直接打开 yesymbol

右键菜单 → 「符号」→ 应**直接启动 yesymbol**，不需要任何配置（它已随包安装）。

要换成别的路径：设置窗口 →「标点符号」页 →「托盘符号工具」填完整路径。

### 五、回归确认

以下应与 v0.7.8 一致：

```text
候选右键菜单点外部        要消失，Esc 也要
左键点候选                直接上屏
候选窗停 3 秒后点工具栏    要有反应
设置窗口 5 页             能改能存，注释保留
mk / dddyn / sdsf         词组之后有单字
srf / sruf / shrfa        首选都是「输入法」
```

版本确认：

```text
%LOCALAPPDATA%\PiInput\bin\PiInputHost.exe --build-id
```

应输出 `0.7.9`。

## 如果指示器里看不到按钮

语言栏按钮由 Windows 在输入指示器里绘制，需要输入法处于活动状态。先在任意程序里用 PiInput 打一个字，再看任务栏。
