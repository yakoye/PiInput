# 三个长文本打字测试（v0.7.2）

v0.7.2 沿用真实命名管道逐键回放门禁，覆盖 `tests/data/real_world_text_corpus.txt` 中三个长文本、翻行、数字选字、空格提交与标点提交。

本版在按键热路径上新增了整覆盖拼接：整串输入全部解码时，引擎会在最多 8 个音节范围内做一次有界的动态规划，对每个跨度取词库前 4 条、每个位置保留 4 条路径，只接受真实多字词。逐键回放因此同时是这项改动的性能门禁。

全拼前缀展开的排序也换了主键，从「完整音节数」改成「未解析字母数」加分词器评分，长文本回放覆盖的正是这条路径。

完整 Release CTest 的 `piinput-typing-latency`、`piinput-keystroke-latency`、`piinput-external-incremental-performance` 和 `piinput-external-long-full-performance` 结果记录在 `VERIFICATION_v0.7.2.md`。

该自动回放覆盖真实 Host、真实协议和真实引擎；目标应用自己的 TSF 行为由用户在 Notepad++ 等真实应用中补充验证。
