# 三个长文本打字测试（v0.8.0）

v0.8.0 继续执行三组真实文本逐键回放、段落输入、结构化语料和逐键延迟门禁，结果与 v0.7.16 一致，无回归。

本版新增的中文模式英文候选默认关闭，长文本测试在关闭状态下运行，因此结果预期不变。执行仍是必需的：英文词库从 24,323 词扩到约 25 万词，加载与查询代价都变了，需要确认它没有渗入按键路径。

## 本版必须复验的项

- **开关关闭时候选行逐字节不变。** 这是整条特性最重要的一条断言：默认关闭的新功能不得对现有用户产生任何影响。已有单元测试覆盖，长文本回放是它的实机对照。
- `piinput-keystroke-latency` 与 `piinput-typing-latency` 未因词库扩大而退化。前缀查询在按键路径上，词库大了约 12 倍。
- 开启英文候选后再跑一遍三组长文本。中文语料不含 ASCII 字母串，理论上不应触发英文候选；若触发，说明触发条件判定有误。

## 真实应用手工测试

必须使用验证记录中的同一 build ID，不能沿用 v0.7.16 的进程或安装结果。

开启英文候选后另需确认：

1. `belie` 能补出 believe / believed / belief；
2. `palad` 能补出 palladium（验证中频层生效）；
3. `calc` 的计算器仍在候选 2，英文补全排其后；
4. `he`、`an` 的中文候选顺序与关闭开关时完全一致；
5. 选中英文候选后再打同一前缀，该词应升到最前（验证学习）。
