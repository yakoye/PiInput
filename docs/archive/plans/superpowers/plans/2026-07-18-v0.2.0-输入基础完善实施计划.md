# PiInput v0.2.0 输入基础完善实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成可测试、可本地更新词库且低延迟的全拼与小鹤双拼输入基础。

**Architecture:** 输入解析继续输出统一标准拼音；独立词库构建器把开源数据转成稳定 TSV；现有编译器生成按拼音索引的 `.lex`；引擎在内存索引上执行确定性排序。外部 `dicts` 与源码分离。

**Tech Stack:** C++20、CMake/CTest、PowerShell、Git、Windows TSF。
