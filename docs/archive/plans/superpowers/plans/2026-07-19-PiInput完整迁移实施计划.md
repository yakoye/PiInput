> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前项目一次性迁移为 PiInput，并交付任意长度增量解码、全拼习惯兼容、热加载配置、可选英文候选、候选网格滚动、用户数据迁移和干净目录结构。

**Tech Stack:** C++20、CMake/CTest、Win32/COM/TSF、PowerShell、INI/TSV、MSVC 19.51、Git/GitHub CLI。

- [ ] **Step 4: 机械替换源码标识**

编写一次性未提交的 PowerShell 处理器，按以下顺序替换所有 Git tracked 文本文件，然后立即删除处理器：

```powershell
$replacements = [ordered]@{
    ('Lite' + 'IME') = 'PiInput'
    ('Lite' + 'Ime') = 'PiInput'
    ('lite' + '-' + 'ime') = 'piinput'
    ('lite' + '_ime') = 'piinput'
    ('lite' + 'ime') = 'piinput'
}
$utf8 = [Text.UTF8Encoding]::new($false)
git ls-files | ForEach-Object {
    $path = Join-Path $PWD $_
    if (-not (Test-Path $path -PathType Leaf)) { return }
    try { $text = [IO.File]::ReadAllText($path, $utf8) } catch { return }
    $updated = $text
    foreach ($pair in $replacements.GetEnumerator()) {
        $updated = $updated.Replace($pair.Key, $pair.Value)
    }
    if ($updated -ne $text) { [IO.File]::WriteAllText($path, $updated, $utf8) }
}
```

Expected: 命名空间为 `piinput`，包含路径为 `piinput/...`，目标前缀为 `piinput-`。

- [ ] **Step 2: 发现旧运行根目录**

从当前已注册 COM DLL 绝对路径向上查找第一个同时包含 `Dev` 和 `UserData` 的祖先目录，记录为 `$LegacyRuntimeRoot`。验证它位于 `%LOCALAPPDATA%` 下且不等于 PiInput 根目录。

```powershell
$LegacyClsid = '{D73AABA7-BE3E-4E53-8DE2-652D352743F3}'
$LegacyKey = Get-Item ("HKCU:\Software\Classes\CLSID\$LegacyClsid\InprocServer32")
$LegacyDll = [IO.Path]::GetFullPath([string]$LegacyKey.GetValue(''))
$Cursor = Split-Path $LegacyDll -Parent
$LegacyRuntimeRoot = $null
while ($Cursor -and $Cursor.StartsWith([IO.Path]::GetFullPath($env:LOCALAPPDATA))) {
    if ((Test-Path (Join-Path $Cursor 'Dev')) -and (Test-Path (Join-Path $Cursor 'UserData'))) {
        $LegacyRuntimeRoot = $Cursor
        break
    }
    $Parent = Split-Path $Cursor -Parent
    if ($Parent -eq $Cursor) { break }
    $Cursor = $Parent
}
if (-not $LegacyRuntimeRoot) { throw 'Cannot discover the legacy runtime root safely' }
if ([IO.Path]::GetFullPath($LegacyRuntimeRoot) -eq [IO.Path]::GetFullPath("$env:LOCALAPPDATA\PiInput")) {
    throw 'Legacy source unexpectedly equals the PiInput destination'
}
```
