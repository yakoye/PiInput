# PiInput 安装、中文标点与增量候选实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个不覆盖已加载 TSF DLL 的原生开发安装器，接通中文标点，并让全拼与小鹤双拼在尚未输入完整音节时立即产生稳定候选。

**Architecture:** 安装器采用版本目录并存策略，每次把构建产物复制到新的 `%LOCALAPPDATA%\PiInput\Dev\versions\<build-id>`，再原子更新 COM/TSF 注册，不关闭用户应用。输入核心新增“拼音键前缀查询”，精确候选优先，未完成音节候选附加固定惩罚；TSF 将所有可打印符号统一交给标点转换器。用户提供的测试语料完整归档，但本阶段只把已经承诺的全拼、小鹤、标点、状态机和性能用例设为发布门禁。

**Tech Stack:** C++20、Win32/COM/TSF、CMake/CTest、MSVC 19.51、PowerShell（仅构建辅助）、JSON/TSV 测试数据。

**执行状态（2026-07-19）：** 六项任务已实现并完成干净 Release 构建、8/8 CTest、45.9 万词条候选基准和并存安装器集成验证。逐项证据见 `docs/VERIFICATION_v0.2.0-dev.md`。

## 自检结果

- 需求覆盖：安装锁、中文标点、全部符号测试、`mkt`/`rug` 增量候选、用户语料、性能、文档和推送均有对应任务。
- 范围控制：纠错、模糊音、HMM/Viterbi、AI、云联想不在本轮实现，只保留语料和未来能力标签。
- 接口一致：词库统一使用 `query_prefix`，引擎统一使用 `PinyinPrefix`，TSF 不直接扫描词库。
- 安全约束：安装器不强制关闭应用、不覆盖已加载 DLL、不删除用户数据。
