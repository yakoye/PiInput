# PiInput 中文符号、命令入口与候选窗口设计

日期：2026-08-14  
状态：用户已确认

## 目标

本轮只调整三项现有输入交互：

1. 中文符号默认与搜狗拼音的常用映射一致，并允许切换微信风格括号；
2. 候选窗口默认保持一行、尺寸稳定、靠近文本光标，长输入和长候选不得显示省略号；
3. 在中文状态下支持 `;;字母`、`；；字母` 和双反引号命令别名，同时保护 Markdown 反引号输入。

不增加联网、AI、语音或独立帮助窗口。

## 中文符号

### 默认搜狗风格

主键与 Shift 结果：

| 按键 | 普通 | Shift |
|---|---|---|
| `` ` `` | `·` | `~` |
| `1`…`0` | `1`…`0` | `！@#￥%……&*（）` |
| `-` | `-` | `——` |
| `=` | `=` | `+` |
| `[` | `【` | `{` |
| `]` | `】` | `}` |
| `\\` | `、` | `|` |
| `;` | `；` | `：` |
| `'` | `‘`/`’` 成对轮换 | `“`/`”` 成对轮换 |
| `,` | `，` | `《` |
| `.` | `。` | `》` |
| `/` | `、` | `？` |

`@ # % & * { } | + - =` 保持半角或 ASCII 形态；中文专用符号使用全角形态。这样中文输入中仍可直接书写 `book_list`、`++`、`--`、`==`。

### 微信可选风格

仅改变 Shift 方括号：

- `Shift + [` → `「`
- `Shift + ]` → `」`

配置项：

```ini
[punctuation]
mode=chinese
bracket_style=sogou
```

`bracket_style` 允许 `sogou`、`wechat`；默认 `sogou`。英文和程序员模式始终输出 ASCII。

## 命令入口

中文模式支持下列等价入口：

| 功能 | 分号入口 | 全角显示兼容 | 反引号入口 |
|---|---|---|---|
| 符号中心 | `;;f` | `；；f` | 双反引号后接 `f` |

说明：物理分号键在中文模式下显示为全角，但命令路由按原始按键识别，因此 `;;f` 与 `；；f` 是同一入口。

路由规则：

- 只在输入串开头识别完整三键命令；
- 输入第一、第二个前缀时保留在组合区，可见且可退格；
- 本轮第三个字符为 `f` 时进入符号中心；`h/u` 留给帮助与拆字功能完成后使用；
- 未识别的第三个字符到来时，不吞键，按照当前符号模式原样提交前缀并继续处理字符；
- 单反引号、双反引号以及三个反引号代码块均不会单独触发命令；
- 三个反引号按原样输出，保证 Markdown 代码块可用；
- 旧的 `;sheshidu` 等符号搜索保留兼容，但不再作为主要帮助入口。

## 候选窗口

- 每次新组合默认只显示一行；
- `=`/下箭头向下移动一行并展开，`-`/上箭头向上移动一行；
- 输入内容发生变化时恢复一行；
- 窗口宽度由当前可见候选和目标显示器工作区共同决定，不继承上一组合的过大宽度；
- 同一候选快照未变化时不重新布局、不闪烁、不跳动；
- 长组合串在标题区域内部水平滚动以保持文本光标可见，不用 `...` 替换；
- 候选文字永不使用省略号。候选过长时减少每行候选数，并在屏幕范围内完整显示；
- 优先锚定 TSF 文本光标，应用不提供文本位置时才退回系统插入点或鼠标附近；
- 所有尺寸按目标显示器 DPI 计算，字体使用 ClearType；
- 默认每行 6 项，用户设置仍可选择 5–9 项。

## 测试边界

- 覆盖中文、英文、程序员三种符号模式的所有主键与 Shift 组合；
- 覆盖搜狗/微信括号风格、成对单双引号复位；
- 覆盖符号命令别名、未知命令、退格、Esc、单/双/三反引号和 Markdown 文本；
- 覆盖默认一行、逐行展开/收回、新组合折叠、长候选完整显示和不同 DPI/工作区约束；
- Host 核心测试与 Windows 源码回归必须同时通过。
