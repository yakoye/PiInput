# PiInput 候选质量、图标与本地候选控制设计

## 范围

本轮只修复四类已复现问题：Windows 语言栏图标未刷新、中文组合候选排序不合理、候选文字视觉上未垂直居中，以及缺少“固定首位/删除该词”的本地控制。

## 设计

- 安装升级时刷新已有 TSF Profile 元数据，继续使用稳定 CLSID、稳定 Profile GUID 和稳定入口 DLL，仅更新 Windows 缓存的图标与描述。
- 候选窗使用中文 UI 字体和显式文本基线计算，不依赖 `Segoe UI` 的 CJK 字体回退。
- 解码器对句中语气词增加确定性惩罚，对 Unicode 扩展区生僻字增加轻度降权；缺失的常用整词进入可分发基础词库。
- 候选右键菜单提供“固定首位”和“删除该词”。两种状态写入用户模型；固定优先级高于普通学习，删除采用屏蔽标记且可由以后设置界面恢复。
- 所有操作使用候选唯一 ID 与当前 generation，拒绝过期候选，防止候选刷新后误操作别的词。

## 验收

- 升级安装命令显式刷新 Profile，再加入当前用户键盘列表并验证状态。
- `你把我的图标` 排在 `你吧我的图标` 之前；`候选框` 是首选，扩展区生僻字不进入前排。
- 20–72 DIP 行高下文字均按实测字体高度垂直居中。
- 固定后候选立即成为首位并跨进程保存；删除后立即消失并跨进程保存。
