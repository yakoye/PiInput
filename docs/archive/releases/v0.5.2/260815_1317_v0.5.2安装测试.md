# PiInput v0.5.2 安装、使用与测试

## 一、安装

1. 完整解压 `PiInput-v0.5.2-dev-windows-x64.zip`，不要在压缩包预览窗口中直接运行；
2. 双击最外层的 `PiInput-Install.exe`；
3. Windows 弹出管理员确认时选择“是”；
4. 安装完成后，按 `Win + Space` 选择“PiInput 中文输入法（开发版）”；
5. 安装器不自动切换当前输入法，因此没有立即出现 PiInput 属于正常现象。

升级不再替换各应用加载的永久入口 DLL。ChatGPT、Chrome、VS Code、Notepad++ 等已经打开的程序可以继续运行；独立的 PiInput Host 会切换到新版本。

## 二、日常使用

- 默认方案：小鹤双拼；可在候选栏尾部“设置”中改为全拼；
- `Space`：上屏当前选中的候选；
- `1`～`9`：选择当前行对应候选；
- `=` / `↓`：展开并移动到下一行；
- `-` / `↑`：移动到上一行；
- `←` / `→`：在候选间移动；
- `PageUp` / `PageDown`：翻页；
- 单独按下并松开 `Shift`：切换中文与英文；
- `Enter`：上屏原始输入；
- `Esc`：取消当前组合。

默认候选栏为 40 DIP 高、16 DIP 字体、单行横向显示。设置中可将字号调整为 10～28，将高度调整为 20～72；新组合开始时生效，不重新加载大词库。

## 三、快捷入口

- `;;f`、`；；f`、双反引号加 `f`：符号中心；
- `;;h`、`；；h`、双反引号加 `h`：输入法帮助；
- `;;u`、`；；u`、双反引号加 `u`：拆字模式；
- 单个反引号和三个反引号 Markdown 代码块保持正常输入；
- 候选栏尾部四格按钮也可打开“符号”和“设置”。

## 四、本版重点测试

小鹤双拼：

```text
mkt            → 明天（首选）
rug            → 如果、入股、乳沟……
xnhe           → 小河（首选）
yuwh / yvwh    → 欲望（首选）
hlheruhdlq     → 黄河入海流（首选）
biruwoycuibuv  → 候选中包含“比如我要是不知道”
```

全拼：

```text
huangheruhailiu → 黄河入海流（首选）
jugelizi / jvgelizi → 举个例子
```

英文测试：单独按 Shift 后输入 `book`。默认关闭英文候选时直接输入英文；在设置文件启用英文候选后，`b`、`bo`、`boo`、`book` 会显示离线补全候选。

候选框定位测试：在主显示器和副显示器的左上、上、右上、左、右、左下、下、右下八个区域分别输入。顶部和中部优先显示在光标下方；底部空间不足时应完整翻转到光标上方，不能跨到错误屏幕或被任务栏截断。

三组长文本的搜狗/PiInput 对照、代表性首选排名和已知差距见 `docs/三组文本与八向边界对照测试_2026-08-15.md`。

## 五、词库与用户数据

安装包自带编译后的离线基础词库，普通使用不需要携带 `.scel`。开发者或用户新增词库时，把 `.scel` 放在项目工作区同级的 `dicts` 目录，再运行词库构建脚本；源码更新不会删除该目录。

用户设置和学习数据保存在：

```text
%LOCALAPPDATA%\PiInput\UserData
```

## 六、诊断与卸载

运行包内 `bin\piinput-diagnostics.exe --status --json` 可查看永久入口、当前 Host、协议和 Profile 的真实状态。

卸载可使用 Windows“设置 → 应用 → 已安装的应用”，或双击 `PiInput-Uninstall.exe`。默认保留用户词库与设置；只有明确选择删除用户数据时才会清除。

## 七、当前边界

- 当前为 Windows x64 开发测试版，尚未正式签名；
- 排序是纯离线、确定性的传统算法，不使用 AI 或云联想；
- `biruwoycuibuv` 已能找到“比如我要是不知道”，但在当前无二元语言模型的条件下不保证首选；
- 通用词库与真实长句首选仍将继续根据回归语料改进，不通过手工硬编码每个句子。
