# 三个长文本打字测试（v0.7.6）

v0.7.6 改了 Host 等待按键连接的方式：等待放到工作线程，主线程同时等待连接与窗口消息。按键路径本身（读、解码、查询、编码、写）没有改动，但「等待下一次按键」这一步换了实现，因此逐键回放是这项改动最直接的门禁。

候选窗定位也有改动（过矮的插入点补足到一行文字高），长文本回放同时覆盖它。

## 结果

```text
piinput-typing-latency                    Passed
piinput-keystroke-latency                 Passed   key_p95_us=171~175  key_max_us=234~245
piinput-external-incremental-performance  Passed
piinput-external-long-full-performance    Passed
piinput-host-process                      Passed   含空闲点击与工具栏响应
piinput-candidate-presenter               Passed   含八向边界与过矮插入点
```

完整 Release CTest 60/60 通过，记录在 `VERIFICATION_v0.7.6.md`。

`piinput-keystroke-latency` 直接测引擎、不经过 Host 管道，它证明的是引擎未受影响；管道改动本身由 `piinput-host-process` 的逐键回放与请求延迟门禁（6ms P95 / 12ms max）守住。
