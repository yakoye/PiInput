# PiInput v0.7.3 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.7.3-windows-x64.zip`。
2. 双击最外层 `PiInput-Install.exe`。
3. 接受 Windows 权限提示。
4. 完全关闭并重新打开要测试的应用。
5. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版重点测试

本版只做一件事：让候选跟着每一次按键走。请重点看**打字过程中**的候选，而不是打完之后。

### 小鹤双拼：打到一半的词

依次按下每一个键，每敲一键都看一眼候选行：

```text
xp        →  写 些 谢 …
xpzd      →  卸载 写在 …
xpzdw     →  卸载完 卸载万 卸载晚 卸载 写在      ← 以前这里开始不动
xpzdwj    →  卸载完 卸载万 卸载 写在 些
xpzdwji   →  卸载完成 写在完成 卸载玩车 卸载
xpzdwjig  →  卸载完成 写在完成 卸载 写在
```

判断标准：第 5、6、7 键**每一键候选都要变**。以前这三键候选一字不动，直到第 8 键才跳出「卸载完成」。

### 全拼：每敲一个字母都要变

切到全拼，逐字母输入 `jintianwanshang`：

```text
jint             →  今天 津贴 尽头
jinti            →  今天 津贴 紧贴
jintia           →  今天 金条 禁条        ← 以前是「浸提啊 浸提阿」
jintian          →  今天 金田 进
jintianwan       →  今天完 今天万 今天晚
jintianwans      →  今天晚上 今天完善 今天玩耍
jintianwansha    →  今天晚上 今天完善 今天万山
jintianwanshang  →  今天晚上 今天 金田
```

判断标准：「今天」从第 4 个字母起一直在首位，中途不能掉。

再单独确认这几条，它们以前都会塌回上一个词：

```text
xieza          →  卸载 写在          （以前：些 血 谢 写）
wanchen        →  完成 玩成          （以前：完 万 晚 玩）
xiezaiwanchen  →  卸载完成 写在完成  （以前：卸载 写在 些 血）
woxian         →  我想 我先 我向     （以前：我先 我县 我）
woxianza       →  我现在 我先在      （以前：我先咋 我先砸，「我现在」在第 8）
```

### 拼接规则没有放开到乱拼

以下三条必须仍然成立：

- 全拼 `kadun` 或小鹤 `kady`，首位是「卡顿」，**不能出现「卡吨」「卡炖」「卡蹲」**。两个单字凑出来的词一律不给。
- 全拼 `woaini` → 「我爱你 我爱 我」，`nihaoma` → 「你好吗 你号码 你好」。词库里有整词时不额外拼接，候选行要干净。
- 全拼 `zhonghuarenmin` 首位是「中华人民」，不是「种花人民」。

### 双拼没有被全拼的改动波及

```text
xnhe    →  小河 小盒 小鹤
gjjt    →  感觉
jisrji  →  计算机
mkt     →  明天
```

`xnhe` 里**不能出现「小黑」**——双拼打不出 `hei`，出现就是错的。

### 打字流畅度

连续打一段长文本，逐键不应有卡顿感。参考数字：单键 p95 约 0.2 毫秒，长输入单次查询 p95 约 0.05 毫秒。
