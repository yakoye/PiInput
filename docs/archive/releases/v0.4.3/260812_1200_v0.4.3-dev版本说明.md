# PiInput v0.4.3-dev 版本说明

本版集中解决新窗口首次输入卡慢、首键丢失、候选窗跨屏缩放模糊和定位偏移，同时增强独立 `PiInput-Test.exe`。不改变系统 TSF 安装身份。

## 新增

- 增加“中文候选 / 英文候选”模式切换；
- 英文模式复用正式离线英文词库、补全偏好、用户词和学习排序；
- 输入一个字母即可显示原始输入与多个英文补全候选；
- 顶部测试文本区支持自由输入、粘贴、选择、删除和换行；
- 中文、英文和符号候选写入当前文本插入点；
- 英文候选提交后自动补空格，便于连续句子测试；
- 状态栏显示本地英文词条加载数量。

## 重大修复

- Host 在加载词库前取得跨进程单实例锁，多个程序同时首次输入也只能有一个进程展开词库；
- 安装器/登录启动的常驻 Host 继续供所有程序共享，新窗口不重新读取词库；
- Host 对外可用前预热 26 个首字母候选路径，消除第一次 `w`、`d` 等前缀的冷查询抖动；
- 默认词库切换为 `resident-hot-v1`：完整低频单字表和 41 万发音词表保留在本地，但不再进入每个 Host 的常驻索引；
- Stable Shim 的后台连接冷启动等待由 500 ms 提升为有界 5 s，正常实测约 1 s 内就绪，不再因超时丢失首键；
- Host 尚在握手时，首个中文字母进入请求队列，不再漏到应用里成为英文字母；
- 候选窗先移动到目标文本光标所在显示器，再读取该显示器 DPI、重建 ClearType 字体和计算尺寸；
- 光标间距在 125%/200% 缩放下分别验证为 5/8 物理像素，候选窗保持默认单行并约束在目标屏工作区。

## 保持不变

- 测试台不加载 `PiInputTSF.dll`，不会占用系统输入法入口；
- 测试台不安装、不注册、不激活 PiInput；
- 系统输入法继续使用独立常驻 Host 与稳定 Shim；
- 不增加 AI、云联想或联网热路径。

## 本机实测基线

优化前使用 501,935 条、16.7 MB 的扩展词库时，核心加载约 416 ms，Host 冷启动及预热约 0.9 秒。默认热词库瘦身后为 101,469 条、4.00 MB：核心加载约 96 ms，Host 冷启动及预热约 384 ms，首个独立客户端约 24 ms，第二个新客户端约 16 ms；`段落句子`、`明天`、`小河`、`yuwh/yvwh → 欲望` 均在 500 ms 进程级上限内命中。10,000 次 `wo` 热查询 P95 约 38 微秒，3500/7000 汉字在全拼和小鹤下均为 100% 覆盖。
