# 三个长文本打字测试（v0.7.9）

v0.7.9 把输入指示器的按钮从通知区域图标改为 TSF 语言栏项。语言栏活在 TSF DLL 内，与按键处理同一个进程，因此逐键回放同时验证了它没有干扰输入路径。

## 结果

```text
piinput-external-long-full-performance    Passed

```

完整 Release CTest 60/60 通过，记录在 `VERIFICATION_v0.7.9.md`。
