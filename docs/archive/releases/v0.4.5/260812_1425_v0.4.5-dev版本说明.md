# PiInput v0.4.5-dev 版本说明

本版继续冻结功能范围，只修复候选窗口稳定性、窗口切换恢复和确认上屏可靠性。

## 修复

- 同一次组合输入期间固定候选框位置和宽度，普通按键不再移动红框区域；
- 默认一行候选保持固定高度，只有 `=`、`-`、上/下方向键改变行数时才调整高度；
- 首次鼠标降级定位可被第一个真实 TSF 文本光标校正一次，随后锁定；
- 切换应用会重置上一会话的几何锁，防止新窗口沿用旧窗口候选位置；
- 失焦时只隐藏对应会话，重新获焦时取得当前文档真实 TSF Context 并恢复候选；
- 空格和 Enter 提交失败不再清空输入；同步写入不被宿主允许时自动回退到异步 TSF 编辑会话；
- 异步写入只有实际完成后才接受清空快照，失败时恢复原拼音和候选；
- 保留 v0.3.8 基线使用的 Segoe UI 18px、ClearType、30px 行高和 4px 文本光标间距。

## 不变

- 第一页默认一行 6 个候选；
- `=`/下方向键展开或进入真实分段取字；
- `-`/上方向键返回；
- 左右方向键移动候选；
- 不加入 AI、云联想、语音或网络热路径。
