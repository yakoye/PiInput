# PiInput v0.6.0-dev 安装、使用与测试

## 安装

1. 解压 `PiInput-v0.6.0-dev-windows-x64.zip`。
2. 双击 `PiInput-Install.exe`。
3. 接受 Windows 管理员权限提示。
4. 完全关闭并重新打开用于测试的编辑器。
5. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版测试

请在 Notepad++ 中不间断输入：

```text
我，他们。我们明天，去哪里？明天、后天！
```

重点观察：

- 每次按键后组合文字或候选是否立即变化；
- 标点后继续输入是否停顿；
- 是否还会约五秒没有反应，然后一次出现多个词；
- 最终文字是否完整且顺序正确。

## 卸载

在 Windows“已安装的应用”中卸载 PiInput，或运行安装目录中的 `PiInput-Uninstall.exe`。
