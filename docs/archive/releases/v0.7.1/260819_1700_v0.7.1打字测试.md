# 三个长文本打字测试（v0.7.1）

v0.7.1 沿用真实命名管道逐键回放门禁，覆盖 `tests/data/real_world_text_corpus.txt` 中三个长文本、翻行、数字选字、空格提交与标点提交。

本版换用 Rime Ice 公共词库（891,195 条），候选生成路径也从有预算上限的前缀扫描改成音节枚举加精确查询。逐键回放因此同时是这两项改动的性能门禁：候选跨度被限制在“已输入完整音节数 + 1”以内，补全结果按词频重新排序，两者都在按键热路径上。

完整 Release CTest 的 `piinput-typing-latency`、`piinput-keystroke-latency` 和 `piinput-external-incremental-performance` 结果记录在 `VERIFICATION_v0.7.1.md`。

该自动回放覆盖真实 Host、真实协议和真实引擎；目标应用自己的 TSF 行为由用户在 Notepad++ 等真实应用中补充验证。结尾半个拼音的分段提交和首次 `3.` 的小数点判定都依赖 Shim 在真实应用里的按键顺序，必须由用户真机确认。
