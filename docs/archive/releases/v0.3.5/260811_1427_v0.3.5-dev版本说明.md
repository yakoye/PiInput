# PiInput v0.3.5-dev 版本说明

本版继续冻结功能范围，只完善全拼、小鹤双拼、基础词库、候选窗口、TSF 稳定性和安装体验。

## 主要变化

- 将用户确认的 406 个小鹤双拼码纳入阻断测试；
- 小鹤以 `yuwh` 为“欲望”的规范输入，同时按设置兼容 `yvwh`；
- 外部 3500 常用汉字和 7000 通用汉字加入全拼、小鹤双向检索测试，覆盖率均为 100%；
- 基础单字构建补充完整 `pinyin-data/pinyin.txt` 低权重兜底；
- 不支持或损坏的 SCEL 单独记录并跳过，不再使整套词库构建失败；
- 候选窗标题去除“全拼”“小鹤双拼”标签，只显示当前编码；
- TSF 编辑会话失败时恢复中文组合快照，不提前清空输入、候选或学习状态；
- 中文候选与标点合并成一次提交，避免半提交；
- 安装器只注册到键盘列表，不自动激活 PiInput，不关闭用户应用；
- 安装后的 Profile 状态检查采用有限重试，避免 Windows 输入服务短暂未刷新导致第一次安装失败；
- 仍被应用占用的旧版本运行文件登记为重启后删除；
- 继续提供发布包根目录的 `PiInput-Test.exe`，优先用于不加载 TSF DLL 的独立测试。

## 安全说明

旧 PiInput 注册在本版安装前必须先完全注销。安装完成后，PiInput 不会自动成为当前输入法；用户只在准备测试的新窗口中通过 `Win + Space` 主动选择。尚未输入字母时不会加载大型中文词库，也不会显示候选窗。

## 本版仍不包含

- AI、语音、云端实时联想；
- 32 位或 ARM64 TSF；
- 正式代码签名；
- 图形化设置程序；
- 跨设备同步。
