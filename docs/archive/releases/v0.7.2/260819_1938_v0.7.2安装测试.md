# PiInput v0.7.2 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.7.2-windows-x64.zip`。
2. 双击最外层 `PiInput-Install.exe`。
3. 接受 Windows 权限提示。
4. 完全关闭并重新打开要测试的应用。
5. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版重点测试

### 打一串词能拼出整句

小鹤双拼下依次输入，首位应该是括号里的整句：

```text
bwffyshu     →  备份用户
xpzduuru     →  卸载输入
dnyslmffxi   →  调用链分析
```

以前这三种输入首位只有「备份」「卸载」「调用」，得分好几次上屏。

同时确认这三条：

- 真实整词仍然压过拼接。全拼输入 `zhonghuarenmin`，首位必须是「中华人民」，不是「种花人民」。
- 拼接最多两条，第三条起必须是普通词。
- 全是单字的输入不会被拼成句子。

### 全拼结尾带半个音节

切到全拼后依次输入，首位应该是括号里的词：

```text
nihaob      →  你好
xihuanb     →  喜欢表 / 喜欢
woxianzaib  →  我现在
zhongguor   →  中国人
beijingd    →  北京的
```

以前 `nihaob` 只给「你 尼 泥」，`xihuanb` 给「西湖 洗护」，`zhongguor` 一个候选都没有。

### 小鹤未回归

v0.7.1 修的四项要确认还在：

```text
woxmzdb  →  空格取「我现在」，再取「不」，上屏「我现在不」
wovidcl  →  空格取「我知道」，再取「了」，上屏「我知道了」
bjg      →  办公 半个 办个（不出现「办公室自动化」）
b        →  把 被 不 本（覆盖多个音节，不只是 ba）
```

新开窗口后第一次输入 `3.`，应得到 `3.` 而不是 `3。`。

## 卸载

在 Windows「已安装的应用」中卸载 PiInput，或运行安装目录中的 `PiInput-Uninstall.exe`。
