# PiInput v0.7.10 验证记录

## 需求

切换中英时在光标处给一个短暂提示，类似 macOS 与小狼毫的做法。显示内容定为**中 / a / A**：中文用「中」，英文用 `a`，大写锁定开时用 `A`。

用大小写字母而不是「英」，是因为大写锁定是键盘上看不出来的状态，很多笔记本没有指示灯，而它恰恰最容易被忘记。字母本身就说明了下一次按键会打出什么。

## 提示的触发范围

只有**会一直保持的状态**才提示：Shift 切换、点图标切换、按 CapsLock。

按住 Shift 打大写字母不提示。它是瞬时的，手指按着就有感知，松开即恢复；输入 `Hello` 时每个大写字母弹一次会非常吵。现有的 `ShiftToggleState` 已经把「单击 Shift」和「按住 Shift 打字」分开（后者被 `on_other_key_down` 取消），因此只在真正发生切换时提示是天然成立的。

## 实现

新增 `platform/windows/tsf/mode_indicator.{h,cpp}`，放在 TSF 端而非 Host 端：语言模式与大写锁定状态都在文本服务手里，光标位置也是现成的（`system_caret_rect`），不需要新增跨进程协议。

窗口是 `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW` 的弹出窗，`SetWindowRgn` 裁圆角，`WM_TIMER` 到点隐藏。鼠标穿透，点它等于点到下面的正文；不激活，弹出时不会把光标从应用里抢走。

位置放在**光标上方**：候选框在下方，两者本来就会在中途按 CapsLock 时叠在一起。上方放不下时翻到下方，并钳制在显示器工作区内。

两处渲染细节是看图改的：

- 不透明度从 236 提到 250。236 时底下的正文会透上来，在内容较密的行上反而看不清；
- 字体质量从 `CLEARTYPE_QUALITY` 换成 `ANTIALIASED_QUALITY`。分层窗口上的次像素渲染会给字形描上橙蓝彩边，因为该滤镜假定背景不透明。

## 顺带修掉的三个缺陷

**任务栏「中/英」停在旧状态。** `bind_context()` 绑定新上下文时把 `english_mode_` 重置为默认语言，从 Host 同步模式时也直接赋值，两处都没有刷新语言栏。按 Shift 切到英文后再切换应用或输入法，内部已回到中文而图标仍显示「英」——表现就是「默认设了中文，每次切过来还是英文」。现在统一走 `set_english_mode()`，值变则必刷新。

**默认语言没有作用到前端。** `default_language` 原先只有 Host 读取，TSF 一律按中文起步。新增 `default_language_is_english()`，激活与绑定上下文时都按它初始化。

**暗色任务栏上图标可能隐形。** `system_uses_dark_theme()` 在注册表读取失败时返回「亮色」，于是把「中」画成黑色。Windows 11 默认暗色任务栏，黑字画上去等于看不见——表现是图标消失而不是颜色不对。改为失败时按暗色处理，画白字；白字在深色和中间色调上都可见，是更安全的一侧。

## 顺带清理

`lang_bar_item.h` 中一处 `private:` / `public:` / `private:` 的畸形访问修饰符序列已清理；`system_uses_dark_theme()` 移出匿名命名空间并在头文件声明，供提示窗复用，避免重复读注册表的代码。

## `piinput-host-process` 冷启动门槛（已查明，未修）

该测试断言冷启动在 3000 ms 内完成。连跑四次的实测结果：

```text
第 1 次  失败  3272 ms
第 2 次  通过
第 3 次  失败  3314 ms
第 4 次  失败  3072 ms
```

**正好压在门槛线上**，不是稳定超线，也不是偶发抖动——四次里过一次。

原因是测试用的词库规模：`PIINPUT_TESTDATA_DIR` 存在时，测试改用 `dicts/cache/piinput-base.lex`，
该文件在 2026-08-19 重新生成后已达 **38 MB**（随包词库远小于此）。单独测量该词库的冷启动为 3251 ms，
与测试内的读数一致。

本次改动全部在 TSF DLL（shim）内，Host 除版本号外未动，不在启动路径上。本轮会话早期该测试通过过两次，
之后稳定卡线，与改动先后无关——是同一份 Host 在同一份大词库上的正常波动。

**未调整门槛**：性能闸门是用来挡回归的，词库长大了就把线往上抬，等于把闸门关掉。
是接受更慢的冷启动、还是优化大词库的加载，应由项目决定，不该在一次功能提交里顺手改掉。

其余 60 项全部通过。
