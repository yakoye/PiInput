# PiInput v0.7.10 版本说明

这一版加了切换模式时的光标提示窗，并修掉了三个和「中/英」状态显示有关的缺陷。

## 新增：光标处的模式提示窗

切换中英时，光标旁边会浮出一个小方块，告诉你现在是什么模式，2 秒后自动消失。

| 状态 | 显示 |
| --- | --- |
| 中文 | 中 |
| 英文，大写锁定关 | a |
| 大写锁定开 | A |

用 `A` / `a` 而不是「英」，是因为大写锁定是键盘上看不出来的状态——很多笔记本没有指示灯，而它恰恰是最容易忘记开着的那一个。用大小写字母本身来表示，不需要再解释。

三种情况会弹出提示：

- 按 Shift 切换中英
- 点任务栏上的「中」图标切换
- 按 CapsLock

**按住 Shift 打大写字母不会弹提示。** 它是瞬时的，手指按着就知道在打大写，松开就没了；而输入 `Hello` 这种每个大写字母弹一次会非常吵。只有大写锁定这类会一直保持的状态才需要提示。

提示窗出现在**光标上方**，因为候选框在下方，两者不会互相遮挡。屏幕顶端放不下时会自动翻到光标下方，靠近屏幕边缘时会收回工作区内。窗口鼠标穿透，点它等于点到下面的正文。

中文模式下按 CapsLock 显示的仍然是「中」。因为在中文模式下大写锁定不产生大写字母，字母照样进拼音解码。显示 `A` 会是对下一次按键结果的谎报。

## 修复：任务栏「中/英」停在旧状态

按 Shift 切到英文后，切换应用或切换输入法，任务栏图标会一直停在「英」，而实际上内部已经回到中文。看上去就是「默认设了中文，每次切过来还是英文」。

原因是绑定新输入上下文时把模式重置成了默认语言，却没有同步刷新任务栏图标；从后台进程同步模式时也是同样的问题。现在改模式只有一条路径，改完必定刷新图标。

## 修复：默认语言设置没有作用到图标

`settings.ini` 里的 `default_language` 以前只有后台进程读，前端一律按中文起步。设成 `english` 时，图标显示「中」而实际打出英文。现在两边读同一个设置，从第一次按键起就一致。

```ini
[general]
default_language=chinese   ; 或 english
```

## 修复：暗色任务栏上图标可能看不见

读不到系统主题时，以前按亮色处理，把「中」画成黑色。Windows 11 默认是暗色任务栏，黑字画在上面等于隐形——看起来就是图标没了，而不是颜色不对。现在读不到时按暗色处理，画白字。白字在深色和中间色调上都看得见，是更安全的一侧。

正常情况下主题检测本身没有变：亮色主题黑字，暗色主题白字，背景透明。

## 升级方式

覆盖安装即可，不需要重启系统，也不需要注销。安装程序会替换 `bin` 下的程序文件，用户词库和设置不受影响。
