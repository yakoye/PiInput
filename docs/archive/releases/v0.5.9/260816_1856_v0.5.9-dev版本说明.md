# PiInput v0.5.9-dev 版本说明

本版只修复 Windows 真实输入链路中的重大时序问题，不修改词库内容和候选排序。

## 修复的问题

快速输入“中文，中文。”、“符号+中文+符号+中文”时，前一个标点触发的 TSF 最终提交可能仍在等待应用完成，后一个按键已经进入 Host。旧实现只有一个待提交槽位，第二次提交会覆盖第一次提交状态，并清除前一次更新屏障，表现为：

- 遇到标点后卡住；
- 后续中文没有候选或无法上屏；
- 个别程序切换回来后组合状态异常；
- 慢速逐键正常，真人连续输入容易失败。

## 新的提交屏障

- TSF 最终提交未完成时，后续按键按原顺序进入内存队列；
- 最终提交成功或失败后，每次只放行一个排队按键；
- 普通更新回复后继续放行下一个按键；
- 排队中的第二个标点会建立新的最终提交屏障，不能覆盖前一个提交；
- 切换文本上下文、外部终止组合、停用输入法时清空旧队列，避免把旧窗口按键带到新窗口；
- 正常无提交边界的输入仍走原异步快速路径。

## 回归覆盖

新增快速双标点时序测试，覆盖：

```text
中文 → ， → 中文 → 。
符号 → 中文 → 符号 → 中文
```

并继续执行核心、Host 进程、TSF 源码与完整 Release 回归。
