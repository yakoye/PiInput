# PiInput v0.5.5-dev 版本说明

本版只完善候选分页、本地用户造词、学习排序和持久化，不增加 AI、云联想、语音或新输入方案。

## 主要变化

- `=` / `↓` 进入下一候选行，`-` / `↑` 返回上一行；每次换行都选中该行第一项，首尾不循环。
- 完整真实词语全部展示后才进入分段取字；分段页优先长真实词段，最后使用单字兜底。
- 分段选择保留在组合区，全部拼音解决后统一上屏。
- 用户词只有在目标程序确认 TSF 上屏成功后才学习；失败、取消、原始字母和未完成输入不学习。
- 一次学习进入第一行但不强制第一，两次向前三移动，三次及以后可以竞争首选。
- 普通学习词最多占用第一行两个保留位置，避免学习数据淹没基础候选。
- 全拼和小鹤双拼共享标准拼音用户词。
- 候选右键支持固定首位、取消固定和删除该词；删除后后续候选立即左移补位。
- 用户模型改为按标准拼音索引，支持旧 4～6 列和新 7 列格式，损坏行隔离报告。
- Host 在内存中共享学习结果，跨应用的新输入立即可见，已经显示的旧候选不跳动。
- 用户模型以约 1.5 秒防抖后台批量保存，使用唯一临时文件和原子替换；按键热路径不写磁盘。
- Host 协议升级到 v3，由 TSF shim 在编辑会话真正完成后发送提交结果。
- 修复实际 Host 会话没有把每行候选数和拼音设置传给引擎的问题。

## 数据兼容

用户数据继续位于：

```text
%LOCALAPPDATA%\PiInput\UserData
```

升级默认保留设置、用户词、固定词和屏蔽词。新模型文件仍为 `user_model.tsv`，旧格式会自动读取。

## 范围外

- 不处理非标准 SCEL 新格式；
- 不修改边界覆盖策略；
- 不用向生产词库手工补“丝滑”、姓名或测试句完成验收；
- 不推送远程仓库。
