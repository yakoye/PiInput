# PiInput v0.5.5 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.5.5-dev-windows-x64.zip`，不要在压缩包预览窗口内运行。
2. 双击根目录 `PiInput-Install.exe`。
3. Windows 弹出管理员确认时选择“是”。
4. 安装完成后，在要测试的程序中按 `Win + Space`，选择“PiInput 中文输入法（开发版）”。

普通升级不需要关闭所有应用：永久 TSF 入口保持不变，只切换独立 Host。若是首次安装或系统输入服务尚未刷新，重新打开目标程序；安装器不会强制结束正在编辑的软件。

## 基本输入

- 默认小鹤双拼；设置中可改为全拼。
- `Space`：上屏当前高亮候选。
- `1`～`9`：选择当前行对应候选。
- `=` / `↓`：下一行，选中第一项。
- `-` / `↑`：上一行，选中第一项。
- `←` / `→`：当前行内移动。
- `Shift`：中文/英文切换。
- `Enter`：上屏原始字母。
- `Esc`：取消组合并清除本次字母。

## 缺词时怎么输入和学习

先浏览完整词语页。全部真实词语看完后继续按 `=`，PiInput 进入分段取字：

1. 优先选择能覆盖更多拼音的真实词段；
2. 找不到词段时选择单字；
3. 已选内容保留在组合区；
4. 继续为剩余拼音选字；
5. 全部完成后统一上屏一次；
6. 上屏成功后，这个两字及以上组合成为本地用户词。

下次输入相同标准拼音时，一次学习会进入第一行；第二、第三次会逐步前移。全拼和小鹤输入共享学习结果。

## 固定和删除候选

在候选上单击鼠标右键：

- **固定首位**：该拼音下始终放第一；
- **取消固定**：保留学习记录，恢复普通排序；
- **删除该词**：立即从候选中移除，后续候选左移补位。

删除误学词不会改写基础词库，而是在本地保存精确到“标准拼音 + 文字”的屏蔽记录。其他读音不受影响。

## 设置

打开候选栏右侧四格按钮，选择“设置”。可设置全拼/小鹤、默认中文/英文、每行候选数、字号和候选栏高度。

手工配置文件位于：

```text
%LOCALAPPDATA%\PiInput\UserData\settings.ini
```

关闭中文学习：

```ini
[pinyin]
user_learning=false
```

## 建议验收

1. 连续按 `=` 三次，确认每次进入下一行且高亮第一项；再按 `-` 返回。
2. 用词段和单字组成一个基础词库没有的两字或三字词，成功上屏。
3. 重新输入，确认新词位于第一行但不一定第一。
4. 在另一个程序重新输入，确认新词立即可见；原窗口已经显示的候选不能跳动。
5. 再成功选择两次，观察逐步前移。
6. 右键固定、取消固定、删除，确认行为和候选左移。
7. 失败提交或按 Esc 后重新输入，确认没有误学。

## 卸载

双击根目录 `PiInput-Uninstall.exe`，或从 Windows“设置 → 应用 → 已安装的应用”卸载。默认保留用户数据；只有明确勾选删除用户数据时才移除 `%LOCALAPPDATA%\PiInput\UserData`。

## 诊断

运行：

```text
bin\piinput-diagnostics.exe --status --json
```

应显示 Host 协议版本 `3` 和当前实际运行的 build ID。完整说明见 `安装与使用指南.md`。
