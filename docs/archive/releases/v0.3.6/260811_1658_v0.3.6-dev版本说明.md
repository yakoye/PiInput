# PiInput v0.3.6-dev 版本说明

## 本版重点

- 选择性合并 THUOCL 诗词和成语，并生成读音来源质量报告；
- 完整词库长词优先于逐字拼接候选；
- `hlheruhdlq` 和 `huangheruhailiu` 首选“黄河入海流”；
- 普通候选耗尽后，`=` / `↓` 进入分段取字；
- 分段选择保留在组合区，支持逐段撤销，完成后一次性上屏；
- 新增中文词条和标准拼音的索引化词库查询；
- 为所有候选保留完整词条、句子拼接、前缀补全和单字兜底证据；
- 加强全拼边界优先级，避免 `yao` 被错误切成 `ya'o`、`chao` 被切成 `cha'o`；
- 新增三段真实长文本的全拼、小鹤和逐字兜底回归；
- 分段候选固定保留足够的单字位置，避免长词候选挤掉合法单字；
- 英文候选仍默认关闭；开启后，Shift 英文状态会按前缀自动显示本地候选。
- Windows 输入法切换面板和任务栏改用独立的紫色 `π` 图标，不再回退成“简体”占位方块。

## 词库查询

双击：

```text
query-dictionary.cmd
```

可以输入中文词语或带单引号的标准拼音。默认查询当前用户安装的 `piinput-imported.lex`，普通输入启动不会为反查功能预建额外索引。

## 分段取字按键

```text
= / ↓       下一可靠候选行；可靠候选耗尽后进入分段取字
- / ↑       上一行；分段首行返回普通候选
1～9/Space  选择当前段，完成全部音节后统一上屏
Backspace   撤销最近选择的一段
Esc         先退出分段模式，再取消整个组合
```

## 保持不变

- 纯离线，无 AI、语音、广告和云端实时联想；
- 候选窗首次只显示一行；
- 大型词库保存在源码外部 `dicts` 目录；
- 本版不自动安装、不自动切换输入法，用户使用发布包自行安装测试。
