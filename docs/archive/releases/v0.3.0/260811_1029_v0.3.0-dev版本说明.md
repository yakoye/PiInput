# PiInput v0.3.0-dev 版本说明

## 重点变化

- 产品、Windows 产物、运行目录和命名空间统一为 PiInput；
- 小鹤双拼和全拼支持任意长度未完成编码候选；
- `u/v` 兼容、零声母、隔音符和连续长句切分纳入回归；
- 候选窗改为横向多行网格，数字键、`-`、`=`、方向键和翻页行为可配置；
- 单独按 `Shift` 切换中英文；
- 中文标点默认输出全角中文符号，全部符号表和键盘标点纳入测试；
- 可选离线英文候选默认关闭，支持本地用户词和学习；
- 英文词库更新采用双目标事务，失败时完整回滚；
- 多个应用的英文学习以增量合并，避免选词次数互相覆盖；
- TSF 编辑失败不再提前清空输入，候选与标点合并为单次提交；
- 原生 `PiInput-Install.exe` 支持根目录双击、版本并存、旧数据迁移、冲突保留和失败回滚；
- 被应用占用的旧 DLL 安排在重启后删除，不强制关闭用户应用；
- 新增中文《安装与使用指南》和 Windows x64 用户发布 ZIP。

## 主要阻断测试

- `接触`、`词汇`、`感觉`、`现在`、`中国`；
- `mkt → 明天`、`rug → 如果` 等未完成编码；
- `jugelizi` 与 `jvgelizi → 举个例子`；
- 407 个标准全拼音节和 786 条结构化语料；
- 用户提供的日常、新闻、儿童故事、专业技术和长句文本；
- 真实 SCEL、外部大词库性能、候选稳定性；
- 全部内置符号、中文/英文/程序员标点；
- 安装布局、迁移、回滚、品牌和 SHA-256 完整性。

## 已知边界

- Windows x64 开发测试版，尚未正式签名；
- 32 位宿主和 ARM64 尚未覆盖；
- 完整设置图形界面尚未实现，当前使用 `settings.ini`；
- 通用词库和候选排序仍需用户真实使用反馈继续完善；
- 不包含 AI、语音、广告、资讯、云联想和同步功能。
