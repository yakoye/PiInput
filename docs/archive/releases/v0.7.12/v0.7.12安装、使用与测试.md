# PiInput v0.7.12 安装、使用与测试

## 安装

双击最外层 `PiInput-Install.exe`，不需要先卸载。装完后**重新打开要测试的程序**，再用 `Win+Space` 切到 PiInput。

## 本版重点测试

### 一、单音节输入的首选（唯一改动）

切到**全拼**，逐个打下面的音节，看第一个候选：

| 输入 | 首选应为 | 改前是 |
| --- | --- | --- |
| `xie` | 些 | 西鄂 |
| `xian` | 先 | 西安 |

`xian` 再多看几位：前面应该是一串常用单字（先 现 显 线 险 仙 咸 鲜…），**「西安」仍在第一页**，大约第 18 位。它没有被删掉，只是回到了自己词频该在的位置。

### 二、确认「词优先于字」没被改坏

这条规则在同一种切分内部必须保留：

| 输入 | 首选应为 | 单字应在其后 |
| --- | --- | --- |
| `nihao` | 你好 | 你、尼、泥 |
| `women` | 我们 | 我、握、窝 |
| `mingtian` | 明天 | 明、名、命 |
| `beijing` | 北京 | 被 |
| `gongzuo` | 工作 | 公、工 |

如果这里出现单字排在词组前面，就是改坏了。

### 三、回归确认

以下应与 v0.7.10 完全一致：

```text
zhongguo    中国
ceshi       测试
pingguo     苹果
wenti       问题
shijian     时间
shenme      什么
zhidao      知道
fangfa      方法
mk / dddyn / sdsf     词组之后有单字
srf / sruf / shrfa    首选都是「输入法」
```

界面部分与 v0.7.10 一致，快速过一遍即可：

```text
Shift 切换            光标旁出现 中 / a
CapsLock              光标旁出现 A
按住 Shift 打 Hello   全程无提示
任务栏中/英           切换应用后与实际语言一致
左键点图标            中英切换
右键点图标            弹出菜单
```

版本确认：

```text
%LOCALAPPDATA%\PiInput\bin\PiInputHost.exe --build-id
```

应输出以 `0.7.12` 开头的构建标识。正式构建会附带提交号；未提交改动的开发构建还会带 `-dirty`。

## 关于「西安」的位置

如果你经常打 `xian` 要「西安」，现在需要往后翻一点。这是有意的：改前「西安」「西岸」「锡安」三个词占住前三位，把「先」「现」挤到第四第五，而后两者的词频高出前者一到两个数量级。

选过一次之后，用户学习会把「西安」提到前面——这条路径不受本次改动影响。

## 本次重点实测：新窗口的默认语言

这一条是为了验证「从其他输入法切过来是英文」到底修没修掉。

先确认配置：

```ini
[general]
default_language=chinese
```

然后按下面这个顺序走一遍，重点是**开关窗口**——旧的缺陷要靠进程号被回收才会现形：

1. 打开记事本，切到 PiInput，按 Shift 切成英文，随便打几个字母；
2. **关掉记事本**；
3. 再开几个程序（浏览器、资源管理器、编辑器都行），各自点一下输入框；
4. 重新打开记事本，点进输入框。

**第 4 步应该是中文。** 修复前，如果新记事本恰好拿到了旧记事本的进程号，
它会直接继承那个已经关掉的窗口留下的英文状态。

反复几次，多开关几个程序，命中概率更高。任务栏图标和实际打出的字应当始终一致。

如果还是会出现英文，麻烦记一下：出现时是刚开的窗口还是用了一会儿的窗口，
以及此前有没有按过 Shift。这两点能区分是会话继承还是别的原因。

## 长时间运行

这一版还给宿主的会话加了上限（64 个，按最近最少使用回收）。
之前每切换一次输入焦点就留下一个永不释放的会话。
正常用一天后，宿主的内存占用应当保持平稳，不再随使用时长单调上涨。

## 重点实测：Ctrl+Shift 切换输入法

这一条是本次修复的核心，请务必测：

1. 在任意输入框里，**连续按 Ctrl+Shift 十几次**（这是 Windows 切换输入法的快捷键）；
2. 每次轮到 PiInput 时，看任务栏图标——**应当始终是「中」**；
3. 随便打几个字确认，出来的应该是中文候选，不是英文字母。

修复前，Ctrl+Shift 里的 Shift 会被 PiInput 当成中英切换键，切一次就变一次英文。

同时确认单击 Shift **仍然能正常切换中英**——这个功能不能被误伤。

## 重点实测：切走再切回来保持状态

```text
在 PiInput 里按 Shift 切成英文
  → Ctrl+Shift 切到别的输入法
  → 再切回 PiInput
  → 应该还是英文

切成中文，同样切走再切回来
  → 应该还是中文
```

`settings.ini` 里的 `default_language` 现在只决定「开机后第一次用」从哪里起步，
之后以你最后一次的选择为准。

## 实测：符号、时间、日期

在中文状态下直接打这些，符号或日期时间应出现在**第 2 位**，首选仍是词典的词：

```text
pai → π        qiuhe → ∑      shang → ↑      xia → ↓
zuo → ← ☜      you → → ☞      duihao → √     taiji → ☯
wendu → ℃ ℉    xuhao → ①②③   sanjiao → △▲▼  xingzuo → ♈♉♊
shijian → 当前时间的六种写法
riqi   → 当前日期的七种写法（含农历）
```

重点确认三条：

1. **首选没有被顶掉**——打 `pai` 第一个仍是「派」，打 `shijian` 第一个仍是「时间」；
2. **双拼同样有**——切到双拼后打对应按键（小鹤「时间」是 `uijm`，「派」是 `pd`），结果应一致；
3. **农历对不对**——`riqi` 最后一条对照手机日历看一眼。

## 实测：日期时间二级列表

```text
打 shijian → 第 2 位是 17:36:00 这样的短时间
  按 2      → 展开六种时间格式
  再按数字   → 选中的那个上屏
  或按 Esc  → 退出列表回到「事件 实践 世间…」，输入内容还在

打 riqi   → 第 2 位是 2026年8月21日
  按 2      → 展开七种日期格式，最后一条是农历
```

确认两点：展开时显示的时间应是**按下那一刻**的；Esc 只退列表、不取消输入。

## 实测：翻页到端

打一个候选多的词，一路按 `=` 到底再多按几次——应停在最后一行，
**不能**把 `=` 打进正文。再一路按 `-` 到顶，最后应**收回成一行**。

## 实测：日期时间入口

```text
shijian → 第 2 位是 🕗时间，按 2 展开六种时间格式（竖排）
riqi    → 第 2 位是 📅日期，按 2 展开七种日期格式（含农历）
```

展开时显示的时间应是**按下那一刻**的；Esc 只退列表、不取消输入。

## 实测：生僻字

词库单字从 8,182 增加到 40,596。试几个原本打不出来的：

```text
ri     → 日 驲 㒲 䒤 囸 氜
nv     → 女 钕 恧 衄 女人 女性 …
```

**重点确认常用字没被挤掉**：`nihao` 首选仍是「你好」，`zhongguo` 仍是「中国」，
`de` 仍是「的」。生僻字应当排在常用字之后，绝不能抢在前面。

词库已在本机重建到 `%LOCALAPPDATA%\PiInput\UserData\lexicons\piinput-imported.lex`，
装新包不会覆盖它。

## 实测：`-` 到顶不收走候选

一路按 `-` 到收成一行，再多按几次——**那一排候选应始终在**，
不能上屏、不能插入短横线、不能让候选框消失。

## 实测：回车

```text
打 wo，直接回车           → 上屏 wo（字母本身）
打 wo，按方向键选第二个再回车 → 上屏那个候选
shijian → 按 2 展开 → 直接回车 → 上屏列表第一项
```

## 实测：`=` 一路到底

打一个候选很多的词（如 `nihao`），按住 `=` 一直翻。
翻到最后一行后**继续按**——候选应稳定停在最后一行，
不能收起、不能跳回开头、更不能再翻一遍。
