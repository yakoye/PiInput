# PiInput v0.4.6-dev 版本说明

本版不增加 AI、云联想或新输入方案，只修复多窗口输入可靠性、候选显示、Shift 和混合标点。

## 修复

- 修复 Notepad++ 等多标签程序把旧标签页未提交拼音带进新标签页的问题；
- 每个 TSF 文本 Context 使用独立 Host 会话，迟到的旧回复不能覆盖或卡住新窗口；
- 首次同步编辑暂时不被宿主允许时，自动使用异步编辑会话完成组合文本和候选更新；
- Shift 回调没有直接提供 Context 时，改用当前焦点 Context 完成中英文切换；
- 候选窗在新 Context 中等待真实 caret 查询结果，不再先显示在鼠标处再跳到插入点；
- 同一组合期间固定候选窗锚点，内容相同时不重复绘制，宽度只增不减；
- 短词保持一行 6 项，中等句子自动使用 2 列，长句使用 1 列并显示完整内容；
- 中文状态下 `--`、`==`、`++` 保持 ASCII；Shift+- 继续输出中文破折号；
- 数字后的 `.` 使用 ASCII，支持 `1.`、`1.9` 等列表和小数输入。

## 兼容输入示例

```text
1.今天很不错。记住这个book_list——Bringup?
```

输入方式：中文状态直接输入数字和中文；单独按 Shift 切到英文，输入 `book_list`；再按 Shift 回中文输入破折号；再次切到英文输入 `Bringup?`。

## 不变

- 全拼、小鹤双拼、词库、分段取字和英文候选保持离线；
- 默认候选只有一行，`=`/下方向键才展开；
- 不在构建过程中安装或替换当前系统输入法，由用户自行安装发布包验证。
