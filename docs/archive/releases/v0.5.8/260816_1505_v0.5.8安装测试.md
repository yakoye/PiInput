# PiInput v0.5.8 安装、使用与测试

## 安装或升级

1. 完整解压 `PiInput-v0.5.8-dev-windows-x64.zip`；
2. 双击根目录的 `PiInput-Install.exe`；
3. Windows 管理员确认出现时选择“是”；
4. 安装完成后，关闭并重新打开准备测试的编辑器；
5. 按 `Win + Space`，选择“PiInput 中文输入法”。

已有 PiInput 时直接安装升级，不需要先卸载。用户设置、学习词和自定义数据继续保存在 `%LOCALAPPDATA%\PiInput\UserData`。

## 这版重点测试

先在 Notepad4、Notepad++ 或 Word 中分别测试：

```text
我们明天，去哪里？
这个是bug吧，你觉得？怎样
```

默认小鹤双拼可分段输入：

```text
womfmktm → 我们明天
qunali   → 去哪里
vegeui   → 这个是
nijtde   → 你觉得
zfyh     → 怎样
```

观察每个字母按下后组合区和候选是否连续更新，不应再出现周期性的 15～20 ms 停顿或整串候选落后。

## 常用按键

- `Space`：上屏当前候选；
- `1`～`9`：选择当前行候选；
- `=` / `↓`：展开并移动到下一行；
- `-` / `↑`：移动到上一行；
- `←` / `→`：在当前行移动；
- 单独按 `Shift`：切换中文和英文；
- `Enter`：上屏原始字母；
- `Esc`：取消组合。

## 设置与数据

- 设置入口：候选栏右侧菜单中的“设置”；
- 设置文件：`%LOCALAPPDATA%\PiInput\UserData\settings.ini`；
- 用户词和学习数据升级时保留；
- 发布包已经包含运行所需二进制词库，发给别人时不需要附带开发目录中的 `dicts`。

## 卸载

双击发布包根目录的 `PiInput-Uninstall.exe`，或从 Windows“设置 → 应用 → 已安装的应用”卸载。默认保留用户数据；只有明确选择删除用户数据时才会移除 `%LOCALAPPDATA%\PiInput\UserData`。
