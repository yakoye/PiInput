# PiInput v0.5.6-dev 版本说明

本版不扩展输入功能，专门修复 v0.5.5 Windows 实机验证暴露的三项可靠性问题。

## 修复

- 修复设置中切换全拼/小鹤后，已经打开的应用吞字母、候选不再出现的问题；
- 修复程序暂时拒绝同步 TSF 编辑时，旧的异步组合文本会覆盖新文本的问题；多次连续按键现在串行更新，只回画最新组合，例如 `ganjue` 不会停在 `gan`；
- 修复前一个候选仍在异步提交时，下一段输入可能先到达并随后被旧提交完成回调清空的问题；提交/取消现在建立最终编辑屏障，下一段组合只保留最新状态并在屏障释放后重放；
- 修复迟到的成功提交结果覆盖下一段已确认组合快照的问题；完成回调只允许接受与该提交对应的快照；
- 修复升级时永久 COM 入口可能再次指向某个版本目录 DLL，导致不同应用长期运行不同版本的问题；
- 稳定 Shim 被进程占用时，安装器先尝试把已加载副本改名留存，再把新版精确发布到固定入口；不能完成字节一致校验时明确失败，不再假装升级成功；
- 安装器等待旧 Host 完成排空，并要求健康响应的 build ID 与目标版本完全一致，禁止旧 Host 冒充升级成功；
- 诊断工具在查询 TSF Profile 前正确初始化 COM，不再把已注册输入法误报为未注册；
- 候选窗使用完整 TSF 文本光标矩形，在屏幕底部、Word 和多显示器工作区内正确向上翻转并留出边距。

## 保持不变

- 不增加 AI、云联想、语音或网络热路径；
- 默认小鹤双拼，全拼可在设置中选择；
- 用户词库、学习、固定和屏蔽数据继续保存在 `%LOCALAPPDATA%\\PiInput\\UserData`；
- Host 可并行升级，TSF Shim 保持一个固定路径；
- 候选输入未确认时位置和顺序不异步跳动。

## 新增回归门禁

- 设置热更新前后的 Host generation 必须严格递增；
- 热切换后连续输入完整 `ganjue`，每个按键都必须被 Host 接受并首选“感觉”；
- 多个被延迟的 TSF 组合编辑必须合并到最新状态，过期编辑不得回写应用；
- 提交和取消前必须清空旧更新队列；异步最终编辑完成前，下一段组合不得并发修改同一 TSF 上下文；
- 迟到的提交完成不得清空下一段已经确认的输入；
- Host 健康检查必须拒绝不匹配的 build ID；
- 稳定 Shim 刷新后必须在固定路径得到与发布包逐字节一致的新文件；
- 底边文本光标的候选窗必须位于光标上边缘之上；
- 版本元数据、发布清单、全量 CTest 和安装包完整性必须通过。
