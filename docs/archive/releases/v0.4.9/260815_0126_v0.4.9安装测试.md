# PiInput v0.4.9 安装、使用与测试

## 安装

1. 解压 `PiInput-v0.4.9-dev-windows-x64.zip`。
2. 双击 `PiInput-Install.exe`，在 UAC 中选择“是”。
3. 安装完成后重新打开要测试的应用，通过 `Win + Space` 选择 PiInput。

升级采用稳定入口 DLL 与独立 Host。安装器不会强制关闭应用；已打开应用可在重新打开后使用新入口行为。

## 中文符号

默认采用搜狗风格：

```text
·~！@#￥%……&*（）——+-=
【】、{}|
；‘’：“”
，。、《》？
```

用户设置位于：

```text
%LOCALAPPDATA%\PiInput\UserData\settings.ini
```

默认：

```ini
[punctuation]
mode=chinese
bracket_style=sogou
```

改为 `bracket_style=wechat` 后，`Shift+[`、`Shift+]` 输出 `「」`。

## 符号中心

- 输入 `;;f`：打开全部内置符号候选。
- 输入两个反引号后接 `f`：效果相同。
- 输入 `;sheshidu`：继续搜索并得到 `℃`。
- 单个反引号后按空格：输入 `·`。
- 三个反引号后按空格：原样输入 Markdown 代码块标记。

## 候选窗口

- 新组合默认一行；
- `=`/下箭头向下一行；
- `-`/上箭头向上一行；
- 左右箭头在当前行选择；
- 输入变化后恢复一行；
- 标题和候选不使用省略号替换文本；
- 优先跟随文本光标，应用不提供文本位置时才回退到系统插入点或鼠标附近。
- 不同应用和显示缩放下均以当前选择的真实插入点为主；组合范围只在选择位置不可用时回退，坐标会先统一为物理屏幕坐标。
- 顶部不再重复显示已经位于编辑区中的编码字母；默认单行外框高度为 48 DIP。
- 第一行会在 600 DIP 宽度预算内继续装入后续候选，保持原有排序并完整显示；确实放不下的候选仍通过 `=` 或下方向键展开查看。

## 建议验收

在 Notepad4、Notepad++、Word 中分别测试：

1. `wojintian`，确认候选默认一行；
2. 连续按 `=`，确认逐行展开；
3. 输入上面的全部中文符号；
4. 输入 `;;f` 和双反引号加 `f`；
5. 输入三个反引号并按空格；
6. 切换窗口后立即输入，确认候选靠近当前文本光标。
