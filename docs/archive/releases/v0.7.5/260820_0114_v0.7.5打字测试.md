# 三个长文本打字测试（v0.7.5）

v0.7.5 新增全拼简拼。简拼只在输入完全无法读作普通拼音时才参与，长文本回放全程是正常拼音，因此这项门禁同时是「简拼没有侵入正常输入路径」的证据。

## 结果

```text
piinput-typing-latency                    Passed
piinput-keystroke-latency                 Passed   key_p95_us=201  key_max_us=272
piinput-external-incremental-performance  Passed
piinput-external-long-full-performance    Passed
piinput-host-process                      Passed
```

完整 Release CTest 59/59 通过，结果记录在 `VERIFICATION_v0.7.5.md`。

简拼索引在第一次简拼查询时构建，约 300 毫秒，不进入逐键热路径。长文本回放不触发它。
