# PiInput v0.5.4-dev 版本说明

本版集中修复组合生命周期、右键菜单取消和弱候选显示问题。

- 修复截图、临时失焦、点击输入框后继续打字时原始字母被重复恢复的问题。
- 右键候选仍支持“固定首位”和“删除该词”。菜单打开后点击菜单外或按 `Esc`，取消当前未上屏组合并删除原始字母。
- 应用主动终止 TSF Composition 后，旧的异步回复不能再次恢复已经结束的拼音。
- `fdsafds` 等没有真实候选的输入不再显示空白候选框。
- 小鹤 `mktm` 保持“明天”为首选；按 `=` 后进入“明、名、命……”的当前音节单字选择。
- 普通失焦不再丢弃仍在进行的编辑请求，同一上下文不会重复 Resume。
