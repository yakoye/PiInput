# PiInput 安装与使用指南

适用版本：PiInput `v0.4.7-dev`（Windows x64 开发测试版）

## 一、安装

1. 将 `PiInput-v0.4.7-dev-windows-x64.zip` **完整解压**，不要直接在压缩包预览窗口中运行。
2. 双击解压目录最外层的 `PiInput-Install.exe`。
3. 安装器按当前普通用户安装，不需要管理员权限，也不应弹出 UAC。若 Windows 仍要求管理员凭据，请停止并确认使用的是本版安装器；否则 HKCU 和用户目录可能写入另一个管理员账户。
4. 安装器**不会自动切换或激活 PiInput**，也不会结束任何正在运行的程序。
5. 看到“PiInput 已安装完成”后点“确定”；安装器会同时打开用户配置目录和 `PiInput-Settings.exe` 设置窗口。
6. 关闭并重新打开一个用于测试的记事本。
7. 按 `Win + Space`，主动选择“PiInput 中文输入法”。

输入法在 Windows 切换面板和任务栏中使用紫色 `π` 图标，不再使用系统生成的“简体”文字方块。若升级后仍看到旧图标，关闭并重新打开 Windows 设置及测试程序；Windows 仍缓存时，注销当前账户一次即可刷新。

### 日常开发测试（推荐）

解压包根目录提供 `PiInput-Test.exe`。它是独立的输入测试台，不加载 TSF DLL，也不会让记事本、浏览器等程序占用待升级的 DLL。词库、全拼、小鹤双拼、候选和排序的日常验证优先在这里完成；只有最后一轮系统兼容测试才使用 `Win + Space`。

测试台顶部“测试文本”是标准多行编辑区，可以直接输入、粘贴、选择、删除和换行，也可以接收下方候选。下方模式选择：

- `中文候选`：继续选择全拼、小鹤双拼等方案并测试中文词库；
- `英文候选`：输入一个英文字母就开始补全，空格、Enter、数字键、上下键或双击选择；英文候选写入测试文本后自动补一个空格；
- `清空`：只清空测试文本，不删除词库、设置或学习数据。

测试台读取随包的 24,323 词英文词库、技术补充词和补全偏好；若本机存在 `%LOCALAPPDATA%\PiInput\UserData\english_downloaded.tsv`、`english_user.tsv`、`english_learning.tsv`，也会合并使用。它不会注册输入法或启动系统 Host。

PiInput 使用轻量 TSF 入口和独立、全局常驻的 `PiInputHost.exe`。词库只由 Host 加载一次，所有应用共用，不再由每个新打开的软件重新加载。普通升级只切换 Host，不覆盖各应用已加载的入口 DLL。详细原理见《稳定入口与无重启升级说明.md》。

本版修正了稳定入口的 Shift、候选方向键、分段组合文本和光标坐标，因此属于一次入口修订。安装器会逐字节比较入口：一致时完全不触碰；未占用时原子刷新；仍被旧程序占用时，把修订后的入口并行安装并更新 Windows 注册，新打开的程序立即使用新版，原有程序关闭后自然释放旧版。无需为了安装而结束所有应用或重启电脑。后续只更新 Host 的普通版本仍不改入口。

> `v0.3.2-dev` 已撤回：它在切换输入法时会在每个宿主进程同步展开完整词库，可能造成系统级卡顿。请不要再安装或继续使用该包。`v0.3.3-dev` 改为首次有效输入时延迟加载；`v0.3.4-dev` 完成新的 PiInput TSF 身份迁移；`v0.3.5-dev` 增加编辑会话失败回滚，并取消安装后的自动激活，避免安装动作影响当前应用和其他输入法。

`v0.3.6-dev` 增加诗词/成语精确命中、词库反查和分段取字。普通候选耗尽后按 `=`/`↓` 可逐段选择，最后统一上屏。

`v0.3.8-dev` 将随包英文词库从开发用的 43 词扩充到 24,323 个带词频的离线单词，并修复了双击 `query-dictionary.cmd` 时的命令解析问题。`v0.3.9-dev` 进一步加入按已输入前缀生效的稳定偏好排序、原生卸载器，并把 Windows 输入法图标改为读取 `PiInputTSF.dll` 内嵌的紫色 `π` 图标。

安装器采用版本并存目录，不会覆盖仍被记事本、资源管理器等程序占用的 DLL。若发现唯一一个结构符合旧输入法的本地运行目录，会自动迁移用户设置、词库和学习数据；冲突文件会保留为 `.legacy-import` 副本。被占用的旧 DLL 会安排在 Windows 重启后删除。

稳定入口与版本化 Host 的安装位置：

```text
%LOCALAPPDATA%\PiInput\Runtime\Shim\PiInputTSF.dll
%LOCALAPPDATA%\PiInput\Runtime\versions\<版本-构建号>\bin\PiInputHost.exe
```

用户数据位置：

```text
%LOCALAPPDATA%\PiInput\UserData
```

## 二、基本输入

默认输入方案是小鹤双拼。候选窗只显示正在输入的编码，不再显示“全拼”或“小鹤双拼”标签：

```text
gjjt  → 感觉
jpiu  → 接触
cihv  → 词汇
xmzd  → 现在
vsgo  → 中国
```

PiInput 支持未完成编码的增量候选，例如：

```text
mkt  → 明天等候选
rug  → 如果、入股等候选
```

完整合法音节即使没有整词，也会使用单字词库组合候选：

```text
xnhe    → 小河、啸合……
xnheul  → 小河双、小河爽……（可用 = / ↓ 继续查看）
```

全拼同样支持未完成音节和连续长句切分。`u`、`v` 混用默认兼容，例如 `jugelizi` 与 `jvgelizi` 都可匹配“举个例子”。

## 三、常用按键

| 按键 | 作用 |
|---|---|
| `Shift` 单独按下 | 切换中文/英文状态 |
| `Space` | 上屏当前候选 |
| `1`～`9` | 选择当前行对应候选 |
| `=` / `↓` | 下一行候选 |
| `-` / `↑` | 上一行候选 |
| `PageDown` / `PageUp` | 下一页/上一页 |
| `←` / `→` | 在当前候选行中移动高亮 |
| `Home` / `End` | 移到组合文本开头/结尾 |
| `Backspace` / `Delete` | 删除光标前/后的编码 |
| `Enter` | 上屏原始输入 |
| `Esc` | 取消本次输入 |

候选窗默认横向显示，每行 6 个，首次出现时只显示一行。按 `=`/`↓` 后，若仍有可靠词库候选则展开并逐行移动；若后面只剩低可信逐字拼接结果，则进入分段取字。分段选择的文字保留在组合区，所有音节解决后才统一上屏。`Backspace` 可撤销最近一段，在分段首行按 `-`/`↑` 返回普通候选。继续输入后生成的新候选会重新折叠为一行。数字键只选择当前活动行的候选。

候选窗优先显示在当前应用的文本插入光标下方，而不是鼠标停留位置。PiInput 通过 Windows TSF 读取当前选择范围的屏幕位置；只有极少数程序不提供文本光标几何位置时，才回退到鼠标附近。多显示器和负坐标显示器同样会按目标屏幕工作区自动约束位置。

完整说明与词库反查方法见 [词库查询与分段取字](词库查询与分段取字.md)。

## 四、中文标点和符号

中文状态默认输出中文标点：

```text
, . ? ! : ; ( ) [ ]
↓
， 。 ？ ！ ： ； （ ） 【 】
```

英文状态输出 ASCII 标点。中文状态下分号键不再兼作命令前缀，按一次 `;` 就直接上屏 `；`。符号中心通过候选工具栏、语言栏菜单、设置的快捷键或连续两个反引号后接 `f` 打开。符号表和全部键盘标点均纳入自动测试。

如果希望继续使用中文拼音和中文候选，但所有标点都按键盘原样输出，请打开设置的“标点符号”页，把“中文输入时的标点”选为“英文标点”。该选项不会切换到英文输入状态：`wo` 仍产生“我”等中文候选，而 `, . : ; / ? [ ] { }` 等全部输出 ASCII。它同时关闭句号、冒号和逗号的智能判定，因此不会出现部分符号仍被转换成中文的混合状态。要恢复上下文智能标点，选回“中文标点”。

旧版曾预留“程序员标点”，但它与“英文标点”的实际行为完全相同，本版已从设置中删除。旧配置会自动迁移为“英文标点”。

中文状态还提供三个不占用标点键的功能候选。下列编码的候选 2 固定为功能入口；按 `2` 后先清除当前组合，再启动对应程序，不会把入口名称上屏：

| 功能 | 可输入编码 | 候选 2 | 选择结果 |
|---|---|---|---|
| 符号 | `fh`、`fuhao`、`fuh`、`fuhc` | `Ω符号` | 打开 `yesymbol.exe` |
| 表情 | `bq`、`biaoqing`、`biaoq`、`bnqk`、`bnq` | `😜表情` | 打开 `yesymbol.exe` 的符号/表情工具 |
| 设置 | `shizhi`、`uevi`、`sz`、`shiz`、`uev` | `⚙️设置` | 打开 `PiInput-Settings.exe` |

其中全拼写法和小鹤双拼原始键码都可直接识别；即使某个原始键码不能按当前方案解析，功能入口仍保持在候选 2。若应用拒绝清除 TSF 组合，PiInput 会保留原输入并且不启动外部程序，避免切换焦点后留下半截字母。

为方便中英混排和程序输入，中文状态下 `--`、`==`、`++` 保持 ASCII。Shift+- 仍输出中文破折号 `——`。数字后的第一下句点立即保持 ASCII，因此 `1.`、`1.9` 可直接输入且继续输入文字不会被改写；紧接着再按一下句点得到中文 `。`，即 `1..` 上屏为 `1.。`。

## 五、修改设置

设置文件：

```text
%LOCALAPPDATA%\PiInput\UserData\settings.ini
```

推荐配置示例：

```ini
[general]
schema=flypy
hot_reload=true

[pinyin]
uv_compatibility=true
accept_u_colon=true
incomplete_candidates=true
user_learning=true
prefix_beam_width=32
prefix_scan_limit=4096

[candidates]
items_per_row=6
visible_rows=3
max_items=90
horizontal=true
equal_key=next_row
minus_key=previous_row
down_key=next_row
up_key=previous_row

[punctuation]
mode=chinese
bracket_style=sogou

[english]
enabled=false
builtin_dictionary=true
user_dictionary=true
user_learning=true
items_per_row=6
```

常用修改：

- 全拼：把 `schema=flypy` 改为 `schema=full`。
- 关闭 `u/v` 兼容：把 `uv_compatibility=true` 改为 `false`。
- 关闭未完成编码候选：把 `incomplete_candidates=true` 改为 `false`。
- 关闭中文用户学习：把 `[pinyin]` 中的 `user_learning=true` 改为 `false`。
- 开启英文候选：把 `[english]` 中的 `enabled=false` 改为 `true`。
- 中文候选配合全英文标点：把 `[punctuation]` 中的 `mode=chinese` 改为 `mode=english`；这只改变标点，不改变中英文输入状态。
- 修改每行候选数：调整 `items_per_row`，支持 5～9 等常用值。
- 修改展开后的候选行数：调整 `visible_rows`；初始窗口仍固定为一行。
- 默认括号：`bracket_style=sogou`，`Shift+[`、`Shift+]` 输出 `{}`。
- 直角括号：改为 `bracket_style=wechat`，对应输出 `「」`。配置值保持原名以兼容已有设置文件。

中文状态下连续输入两个反引号后接 `f`，可以打开内置符号候选。也可以使用候选工具栏、语言栏菜单或设置的符号面板快捷键。所有以分号开头的旧命令（包括 `;;f`、`;;h`、`;;u` 和 `;关键词`）均已取消，分号只承担标点本义。

单个反引号、Markdown 行内代码和三个反引号代码块始终保持 ASCII 原样；中文间隔号 `·` 从符号中心选择。三个反引号可原样提交为 Markdown 代码块标记，不会被当成命令。

保存文件后，新设置会在下一次开始输入时生效；已经显示的候选不会在输入内容不变时突然跳动。

## 六、候选翻行、用户造词和误学处理

候选默认只显示一行。输入内容不变时，翻行只移动选择，不会重新解码或改变候选顺序：

- `=` 或 `↓`：进入下一行，并选中该行第一个候选；
- `-` 或 `↑`：返回上一行，并选中该行第一个候选；
- `←` / `→`：只在当前行移动；
- `1`～`9`：选择当前活动行中对应序号；
- 到第一行或最后一行后停止，不循环，也不会把 `-`、`=` 输入正文。

PiInput 会先展示与完整拼音相关的真实词语。真实词语浏览完后继续按 `=`，才进入分段取字。分段页优先显示能消费更多音节的真实词段，最后才显示单字。已选文字保留在组合区，剩余拼音继续选字，全部完成后统一上屏。

用户词只在目标程序真正上屏成功后学习。Esc、Enter 原始字母、未完成尾音和提交失败都不会学习：

1. 第一次成功选择或组成：下次相同拼音进入第一行，但不强制首选；
2. 第二次成功选择：向第一行前部移动，通常进入前三；
3. 第三次及以后：可以竞争首选，但增长会逐渐变慢；
4. 全拼和小鹤先转换成相同标准拼音，因此共享同一用户词；
5. 一个窗口学习后，其他窗口的新输入立即可见；已经显示的旧候选不会后台跳动。

在候选文字上单击鼠标右键，可以选择：

- **固定首位**：该拼音下始终放在第一项；
- **取消固定**：保留学习次数，只恢复正常学习排序；
- **删除该词**：候选立即消失，后续候选向左补位。基础词不会从只读词库删除，而是在本地写入屏蔽记录。

用户模型位置：

```text
%LOCALAPPDATA%\PiInput\UserData\user_model.tsv
```

备份时复制该文件即可。不要在 PiInput 正在输入时手工修改它；Host 会在最后一次学习约 1.5 秒后批量、原子保存，正常退出或升级前也会强制保存。

## 七、英文候选

英文候选默认关闭。把 `[english]` 中的 `enabled=false` 改为 `enabled=true` 后，单独按 `Shift` 切换到英文状态，输入字母会像手机英文键盘一样自动显示完全离线的英文前缀候选：

```text
r     → r、right、really……
re    → re、really、remember……
rev   → rev、review、reverse……
reve  → reve、revile、reverse……
b     → b、but、because……
bo    → bo、both……
boo   → boo、book、boom……
book  → book、books、booked、booking……
```

原始输入固定在第一项，因此没有收录的名称或缩写也能直接选择。常用前缀使用独立、可测试的偏好排序；其他输入按用户学习、离线词频、补全长度和稳定 ID 排序。输入至少三个字母后，如果候选行仍有空位，才会追加少量近似候选。

- `Space` 或数字键选择候选；
- `Enter` 上屏原始英文；
- 标点或数字 `0` 会与当前候选一次性提交，不会拆成两次上屏；
- 用户选择次数保存在本地，不联网；
- 多个应用同时使用时，学习次数会合并，不相互覆盖。

可选扩展词库更新仍通过项目开发包中的 `update-dictionaries.cmd` 执行，输入法运行时不会联网。

## 八、卸载与重新安装

安装后可在 Windows“设置 → 应用 → 已安装的应用”中找到 PiInput 并卸载，也可以双击完整解压目录根部的 `PiInput-Uninstall.exe`。

- 默认保留 `%LOCALAPPDATA%\PiInput\UserData` 中的用户词库、设置和学习记录；
- 只有勾选“同时删除用户词库、设置和学习记录”才会完整删除用户数据；
- 卸载器不会强行结束记事本、浏览器或其他加载了输入法 DLL 的程序；
- 仍被占用的旧文件会安排在 Windows 下次重启时删除；
- 卸载后可直接重新运行 `PiInput-Install.exe`。

## 九、诊断当前版本

双击包内 `bin\piinput-diagnostics.exe`，或在终端运行：

```powershell
.\bin\piinput-diagnostics.exe --status --json
```

它会显示永久入口 DLL、当前 Host 和当前词库的路径与 SHA-256，同时给出协议版本、Windows Profile 状态以及实时 Host 的语义版本和提交级 build ID。以后判断“实际运行的是哪个构建”只看这里，不再逐个关闭应用或猜测进程中残留的旧 DLL。

## 十、首次测试建议

安装后依次测试：

```text
小鹤：gjjt → 感觉
小鹤：jpiu → 接触
小鹤：cihv → 词汇
诗句：hlheruhdlq → 黄河入海流（首选）
全拼：huangheruhailiu → 黄河入海流（首选）
增量：mkt → 明天
增量：rug → 如果
单字兜底：xnhe → 小河等候选
多音节兜底：xnheul → 不为空，可继续翻行选择
全拼：jvgelizi / jugelizi → 举个例子
中文标点：, . ? ! → ， 。 ？ ！
Shift：中文与英文来回切换
```

若 `Win + Space` 暂未显示 PiInput，先退出并重新登录 Windows；安装器不会强制关闭正在编辑的应用。

安装后 PiInput 不会自动成为当前输入法。若当前仍是搜狗、微信或微软拼音，这是正常现象；只在准备测试的应用中通过 `Win + Space` 主动选择 PiInput。

切换到 PiInput 后，在尚未输入字母时不应出现候选窗。安装器已经启动唯一的常驻 Host 并完成词库加载；新打开的软件直接复用它，首个字母不应再等待 5～10 秒。如果仅切换输入法就弹窗、持续卡顿或目标应用无响应，请立即切换到其他输入法并卸载当前开发版。

## 十一、开发版边界

- 当前交付为 Windows x64 开发测试版；
- 32 位宿主、ARM64、正式代码签名尚未完成；
- 通用词库仍需继续通过真实使用反馈优化；
- 密码、私密、数字密码和 PIN 输入域会完全透传，不显示候选，也不参与用户学习；
- 无 AI、无语音、无广告、无云端实时联想；
- 英文候选和词库下载均为可选、离线使用。
# 候选栏工具与外观设置

候选栏最右侧的四格按钮提供两个常用入口：

- “符号”：直接打开符号中心；
- “设置”：打开原生设置程序。

设置程序允许选择全拼或小鹤双拼、默认中文或英文，并可调整候选文字大小（10～28）和单行候选框高度（20～72）。候选文字在任意高度都保持上下居中。点击“应用”后，结束当前组合并开始下一次输入即可看到变化；Host 和大词库不会重启或重新加载。

鼠标停在字号或高度下拉框上滚动滚轮时，每格精确增加或减少 1。

最新步骤见 `v0.5.8安装、使用与测试.md`。
