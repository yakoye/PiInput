# PiInput 安装与使用指南

适用版本：PiInput `v0.3.0-dev`（Windows x64 开发测试版）

## 一、安装

1. 将 `PiInput-v0.3.0-dev-windows-x64.zip` **完整解压**，不要直接在压缩包预览窗口中运行。
2. 双击解压目录最外层的 `PiInput-Install.exe`。
3. Windows 弹出管理员权限确认时，选择“是”。安装器只使用这一次授权完成 TSF 输入法注册和旧运行目录清理。
4. 看到“PiInput 已安装完成”后，关闭并重新打开记事本、浏览器或聊天程序。
5. 按 `Win + Space`，选择“PiInput 中文输入法（开发版）”。

安装器采用版本并存目录，不会覆盖仍被记事本、资源管理器等程序占用的 DLL。若发现唯一一个结构符合旧输入法的本地运行目录，会自动迁移用户设置、词库和学习数据；冲突文件会保留为 `.legacy-import` 副本。被占用的旧 DLL 会安排在 Windows 重启后删除。

安装位置：

```text
%LOCALAPPDATA%\PiInput\Dev\versions\<版本-构建号>
```

用户数据位置：

```text
%LOCALAPPDATA%\PiInput\UserData
```

## 二、基本输入

默认输入方案是小鹤双拼：

```text
gjjt  → 感觉
jpiu  → 接触
cihv  → 词汇
xmzd  → 现在
vsgo  → 中国
```

PiInput 支持未完成编码的增量候选，例如：

```text
mkt  → 明天等候选
rug  → 如果、入股等候选
```

全拼同样支持未完成音节和连续长句切分。`u`、`v` 混用默认兼容，例如 `jugelizi` 与 `jvgelizi` 都可匹配“举个例子”。

## 三、常用按键

| 按键 | 作用 |
|---|---|
| `Shift` 单独按下 | 切换中文/英文状态 |
| `Space` | 上屏当前候选 |
| `1`～`9` | 选择当前行对应候选 |
| `=` / `↓` | 下一行候选 |
| `-` / `↑` | 上一行候选 |
| `PageDown` / `PageUp` | 下一页/上一页 |
| `←` / `→` | 移动组合文本光标 |
| `Home` / `End` | 移到组合文本开头/结尾 |
| `Backspace` / `Delete` | 删除光标前/后的编码 |
| `Enter` | 上屏原始输入 |
| `Esc` | 取消本次输入 |

候选窗默认横向显示，每行 6 个、显示 3 行；数字键只选择当前活动行的候选。

## 四、中文标点和符号

中文状态默认输出中文标点：

```text
, . ? ! : ; ( ) [ ]
↓
， 。 ？ ！ ： ； （ ） 【 】
```

英文状态输出 ASCII 标点。符号搜索继续使用 PiInput 内置的离线符号表，例如输入 `;sheshidu` 可检索 `℃`。符号表和全部键盘标点均纳入自动测试。

## 五、修改设置

设置文件：

```text
%LOCALAPPDATA%\PiInput\UserData\settings.ini
```

推荐配置示例：

```ini
[general]
schema=flypy
hot_reload=true

[pinyin]
uv_compatibility=true
accept_u_colon=true
incomplete_candidates=true
prefix_beam_width=32
prefix_scan_limit=4096

[candidates]
items_per_row=6
visible_rows=3
max_items=90
horizontal=true
equal_key=next_row
minus_key=previous_row
down_key=next_row
up_key=previous_row

[punctuation]
mode=chinese

[english]
enabled=false
builtin_dictionary=true
user_dictionary=true
user_learning=true
items_per_row=6
```

常用修改：

- 全拼：把 `schema=flypy` 改为 `schema=full`。
- 关闭 `u/v` 兼容：把 `uv_compatibility=true` 改为 `false`。
- 关闭未完成编码候选：把 `incomplete_candidates=true` 改为 `false`。
- 开启英文候选：把 `[english]` 中的 `enabled=false` 改为 `true`。
- 修改每行候选数：调整 `items_per_row`，支持 5～9 等常用值。
- 修改候选行数：调整 `visible_rows`。

保存文件后，新设置会在下一次开始输入时生效；已经显示的候选不会在输入内容不变时突然跳动。

## 六、英文候选

英文候选默认关闭。开启后，在英文状态输入字母会显示完全离线的英文前缀候选：

- `Space` 或数字键选择候选；
- `Enter` 上屏原始英文；
- 标点或数字 `0` 会与当前候选一次性提交，不会拆成两次上屏；
- 用户选择次数保存在本地，不联网；
- 多个应用同时使用时，学习次数会合并，不相互覆盖。

可选扩展词库更新仍通过项目开发包中的 `update-dictionaries.cmd` 执行，输入法运行时不会联网。

## 七、首次测试建议

安装后依次测试：

```text
小鹤：gjjt → 感觉
小鹤：jpiu → 接触
小鹤：cihv → 词汇
增量：mkt → 明天
增量：rug → 如果
全拼：jvgelizi / jugelizi → 举个例子
中文标点：, . ? ! → ， 。 ？ ！
Shift：中文与英文来回切换
```

若 `Win + Space` 暂未显示 PiInput，先退出并重新登录 Windows；安装器不会强制关闭正在编辑的应用。

## 八、开发版边界

- 当前交付为 Windows x64 开发测试版；
- 32 位宿主、ARM64、正式代码签名尚未完成；
- 通用词库仍需继续通过真实使用反馈优化；
- 无 AI、无语音、无广告、无云端实时联想；
- 英文候选和词库下载均为可选、离线使用。
