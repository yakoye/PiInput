# 标点与符号系统

## 目标

Windows 自带符号面板入口和检索速度不适合高频输入。LiteIME 需要自己的快速符号系统，并与普通候选栏统一。

## 第一层：直接标点

### 中文模式

```text
, → ，
. → 。
? → ？
! → ！
: → ：
; → ；
( → （
) → ）
```

### 英文模式

原样输出 ASCII。

### 混合/程序员模式

中文仍可输入，但代码符号保持 ASCII，例如：

```text
, . : ; ! ?
() [] {} <>
/ \\ | _ - + = *
```

需要支持：

- 临时英文标点；
- 快速切换；
- 应用级记忆；
- Visual Studio、VS Code 和终端等应用的合理默认值；
- 用户覆盖默认规则。

## 第二层：符号搜索

用户可通过中文、拼音、双拼或英文别名检索：

```text
jiantou / 箭头 / arrow → ← ↑ → ↓ ↔ ⇒
du / 度 / degree        → ° ℃ ℉
banquan / 版权           → © ® ™
dui / 对                 → ✓ ✔ ☑
```

结果出现在普通候选快照中，支持数字键和空格选择。

## 第三层：完整符号面板

分类：

- 最近使用；
- 收藏；
- 常规标点；
- 中文标点；
- 英文标点；
- 货币；
- 数学；
- 箭头；
- 单位；
- 拉丁扩展；
- 希腊字母；
- 序号与圈号；
- 版权与商标；
- 制表与框线；
- 技术与编程；
- 用户自定义。

键盘操作：

- 方向键移动；
- 数字键选择；
- Enter 上屏；
- Tab 切分类；
- 直接输入搜索；
- Esc 关闭；
- 快捷收藏；
- 不依赖鼠标。

## 数据模型

```text
SymbolEntry
  symbol
  category_id
  display_name
  pinyin_aliases
  english_aliases
  priority
  flags
```

静态符号编译为 `symbols.lex`。最近、收藏和用户别名存放在用户数据中，并预留同步 ID。

## v0.1.4-dev TSF 接入状态

TSF 最小输入链路已经把分号符号搜索接入候选窗口：空输入状态输入 `;` 后继续输入中文拼音或英文别名，例如 `;sheshidu`。按空格或数字键提交符号。

中文、英文和程序员标点转换核心虽然已经存在，但尚未接入 TSF 按键状态机。完整符号面板、最近、收藏、自定义和分类浏览仍是后续任务。

## v0.2.0-dev 标点接入状态

中文模式的可打印标点已经进入 TSF 按键状态机，并由同一个 `PunctuationTransformer` 处理。覆盖键盘主区所有 ASCII 标点：

```text
`~  1! 2@ 3# 4$ 5% 6^ 7& 8* 9( 0)
-_  =+  [{  ]}  \\|  ;:  '\"  ,<  .>  /?
```

主要中文映射包括：

```text
,→，  .→。  /→、  ?→？  ;→；  :→：
'→‘/’  "→“/”  [→【  ]→】  <→《  >→》
(→（  )→）  -→－  _→——  =→＝  +→＋
`→·  ~→～  $→￥  ^→……  *→×
```

英文模式和程序员模式原样提交实际 ASCII 字符。测试数据位于 `tests/data/punctuation_cases.tsv`，同时检查核心映射和 Windows TSF 源码接入。

直接输入 `;` 现在必须得到中文分号 `；`，因此旧的 TSF `;sheshidu` 快速符号入口不再占用分号。符号检索引擎和预览能力仍保留，但系统输入法中的新触发键必须后续做成可配置项；本版不为此扩展新功能。
