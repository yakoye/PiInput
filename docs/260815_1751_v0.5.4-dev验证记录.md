# PiInput v0.5.4-dev 验证记录

验证环境：Windows x64、Visual Studio 18 2026、MSVC 19.51、Windows SDK 10.0.26100.0。

## 自动验证

- Release 全目标构建：通过。
- CTest：53/53 通过，0 失败。
- 3500 常用汉字：全拼 3500/3500，小鹤 3500/3500。
- 7000 通用汉字：全拼 7000/7000，小鹤 7000/7000。
- 真实 SCEL、外部词库、段落输入和增量性能门禁：通过。
- 发布文件 SHA-256 清单、版本元数据、PowerShell/JSON 语法和源码差异检查：通过。

## 本版专项回归

- 外部终止组合后，本地 raw、composition text 和 caret 立即清空。
- 终止前已经发出的晚到 Host 回复不能复活旧组合。
- 普通失焦不释放在途编辑请求；同一文本上下文仅在真实断线后 Resume。
- Host 右键菜单取消只影响对应进程与会话；同会话号的其他进程不受影响。
- `Esc` 或候选右键菜单外部点击会关闭候选并清除未上屏字母。
- `fdsafds` 等无真实候选输入不显示空白候选框。
- 小鹤 `mktm` 首选“明天”，按 `=` 后进入“明”等单字选择。
- 候选右键固定首位、删除该词和用户模型保存继续通过。

## 人工验收建议

自动测试无法替代目标应用真实焦点行为。安装后建议在 Notepad4、Notepad++、Word、Chrome 与 Codex 各执行一次：输入一段拼音，截图或点击输入框其他位置，再回来继续输入；不得重复原始字母。右键候选后按 `Esc` 和点击菜单外各验证一次，组合字母应立即消失。

本记录不声称已替用户点击 UAC 或在其当前桌面完成系统安装。
