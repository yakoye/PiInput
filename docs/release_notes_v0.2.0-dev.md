# LiteIME v0.2.0-dev 版本说明

## 范围

本版本继续冻结外围功能，只完善全拼、小鹤双拼、基础词库、候选检索、中文标点、Windows 开发安装和测试机制。没有增加 AI、云联想、语音或新的输入方案。

## 增量候选

- 小鹤双拼支持最后一个未完成编码的候选；
- `mkt` 可得到“明天、明天上午、命题逻辑”等候选；
- `rug` 可得到“如果、入股、乳沟、如歌、如故、入关”等候选；
- 全拼最后一个音节前缀同样可检索，如 `mingt`；
- 精确解析仍优先，只有完整切分为空时才进入前缀检索；
- 文本词库保留排序后的拼音键索引，二进制词库复用已有有序索引，不逐条全库扫描；
- 前缀扫描和结果数量均有上限，输出顺序使用固定规则，不会异步跳变。

## 中文标点

- 中文模式的键盘 ASCII 标点全部经过 `PunctuationTransformer`；
- 覆盖数字行 Shift 符号、括号、引号、书名号、斜杠、连接符等；
- 英文和程序员模式保持实际 ASCII；
- 组合状态输入标点时先提交当前候选，再提交标点；
- `-`、`=` 在组合状态继续作为候选翻页键；
- 旧 `;sheshidu` TSF 快速符号入口不再占用中文分号，新的可配置触发键留待后续。

## Windows 开发安装器

- 新增 `LiteIME-Install.exe`；
- 每次安装创建 `%LOCALAPPDATA%\LiteIME\Dev\versions\<版本-构建号>`；
- 先复制完整新版本，再切换当前用户 COM 注册路径；
- 不覆盖已被应用加载的旧 `LiteImeTSF.dll`，不强制关闭用户应用；
- 注册或验证失败时回滚原 COM 路径；
- `current.txt` 原子指向当前版本；
- 未被占用的旧版本自动清理，被占用版本保留到下一次；
- 用户词库和学习数据不在版本目录中，升级时保持不变；
- `setup-dev.ps1` 已改用该安装器，不再走固定 DLL 覆盖流程。

当前安装器是开发版并存安装器，使用相邻 `dist/windows-x64/bin` 与 `data` 作为载荷；面向公开发布的签名单文件安装包仍是后续工作。

## 测试语料

- 纳入 `lite-ime-test-corpus-v0.2.0.zip` 的完整内容；
- 固定校验 SHA-256、407 个标准全拼音节、451 个唯一结构化 ID 和总计 786 条结构化用例；
- 包含全拼、小鹤、零声母、长句、隔音符、专业词、ASCII、Unicode、Emoji 和状态机数据；
- 当前已实现能力进入发布门禁，纠错、模糊音、V/U 模式和更完整语言模型用例保留为未来诊断项，不伪装成已完成。

## 既有候选交互

- 候选横向单行显示；
- 单音节默认每页 9 项，词语默认每页 6 项，可在 1～9 范围配置；
- `-`/`=` 和 PageUp/PageDown 翻页；
- 单独 Shift 切换中英文；
- 已确认 `接触`、`词汇`、`感觉`、`现在`、`中国` 等回归词。
