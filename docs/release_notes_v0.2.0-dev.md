# LiteIME v0.2.0-dev 版本说明

## 候选交互与常用词完善（2026-07-19）

- 修复无词频短语数据覆盖 Rime 真实词频的问题；`接触`、`词汇` 在当前基础词库中均为首候选；
- 候选窗口改为横向单行显示；
- 单音节默认 9 项、词语默认 6 项，范围 1～9 可配置；
- 支持 `-` 上一页、`=` 下一页，并保留 PageUp/PageDown；
- 单独 Shift 切换中英文，Shift 修饰其他按键时不误切换；
- 候选池从 10 项提升到 90 项；
- 新增常用词、长句、分页、状态机和真实文本语料测试；
- 词库构建缓存纳入构建器哈希，代码改变后不会错误复用旧 `.lex`；
- Windows 验证会比较已注册 DLL 与当前 Release 构建的 SHA-256，防止旧 DLL 冒充新版。
- 已完成过 TSF 注册的开发机可双击 `refresh-installed-dev.cmd` 更新 DLL，不重复修改机器级注册；脚本只列出占用的文档应用，不会强制关闭它们，替换时会自动重启 Explorer 和 ctfmon。

## 范围

本版本没有增加产品功能，只完善小鹤双拼、全拼、基础词库、候选排序、查询性能和自动化测试。

## 主要改动

- 小鹤零声母按 `aa/ai/an/ah/ao/ee/ei/en/eg/er/oo/ou` 规则实现；
- 自动验证全部 413 个标准普通话音节存在小鹤编码；
- 新增用户指定的 32 个口诀字及常用组合、全拼同词表测试；
- 基础开发词库补齐测试字词，正式本地词库由开源数据自动构建；
- 新增多格式词库构建器和双击更新入口；
- 词库源、大型生成物和用户 SCEL 保存在源码外部；
- 候选改用对数词频、完整词奖励和稳定同分键；
- 新增大词库外部测试和 P95/P99 性能门槛。

## 兼容说明

`.lex` 文件格式未改变。现有 TSF 注册、用户学习文件和本地 SCEL 均可继续使用。更新引擎后重新切换输入法或重开应用以加载新 DLL 和词库。
