# PiInput v0.4.3 安装、使用与测试

## 安装

1. 完整解压 `PiInput-v0.4.3-dev-windows-x64.zip`；
2. 双击根目录 `PiInput-Install.exe`；
3. 接受一次 Windows 管理员权限确认；
4. 安装完成后打开新的测试程序，按 `Win + Space` 选择 PiInput。

安装器会启动当前用户唯一的常驻 `PiInputHost.exe`。完整词库只在这个 Host 中加载和预热一次；记事本、浏览器、Codex 等程序只加载轻量稳定入口并连接 Host，不分别加载词库。

## 不安装先测试

双击包根目录 `PiInput-Test.exe`。它不注册输入法，也不占用 TSF DLL：

- 顶部多行文本框可像记事本一样自由输入、粘贴、换行；
- 选择“中文候选”可测试全拼或小鹤双拼；
- 选择“英文候选”后，一个字母开始显示多个离线补全；
- Space、Enter、数字键、方向键或双击可以选择候选。

## 中文基本操作

- 单独按 `Shift`：中文/英文切换；
- `Space`：上屏当前候选；
- `1`～`9`：选择当前行候选；
- `=` / `↓`：下一行或进入分段取字；
- `-` / `↑`：上一行；
- `←` / `→`：在当前行移动候选；
- `Enter`：上屏原始输入；
- `Esc`：取消。

候选初始只显示一行。只有按 `=` 或下箭头后才展开配置的多行。候选窗优先出现在当前文本插入光标下方；程序不提供文本位置时才回退到鼠标附近。

## 首轮测试

默认小鹤双拼：

```text
gjjt      → 感觉
jpiu      → 接触
cihv      → 词汇
mktm      → 明天
xnhe      → 小河
yuwh/yvwh → 欲望
drlojuzi  → 段落句子
```

测试新窗口性能时，请先确认任务管理器中只有一个 `PiInputHost.exe`。连续打开两个不同文本程序，第一键和候选都应立即响应；任何程序都不应单独重新加载完整词库。

## 卸载

使用 Windows“设置 → 应用 → 已安装的应用 → PiInput → 卸载”，或双击包根目录 `PiInput-Uninstall.exe`。默认保留用户设置和学习数据；卸载器不会强制结束正在编辑的程序。
