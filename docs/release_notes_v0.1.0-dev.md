# LiteIME v0.1.0-dev 版本说明

发布日期：2026-07-17

## 版本定位

这是 LiteIME 的第一个开发基线，重点不是安装为 Windows 输入法，而是确定长期架构、开发约束和词库工具链。

## 新增

- 建立 C++20 + CMake 工程；
- 建立跨平台核心目录；
- 实现 SCEL 解析器；
- 支持常见 `0x44`、`0x45` SCEL 数据区；
- 解析标题、分类、描述、样例、拼音表、词条和权重；
- 新增 SCEL 转 TSV、JSONL、TXT 工具；
- 新增开发期 TSV 精确拼音查询；
- 支持 Windows 中文路径参数；
- 新增 Visual Studio 2022 构建脚本；
- 新增自动测试；
- 为用户提供的两个真实 SCEL 文件增加回归测试；
- 建立完整 Markdown 文档和新会话续接规范。

## 已验证样本

- 电子词汇大全：5,596 条；
- 计算机词汇大全：10,300 条；
- 两者拼音表均为 413 项；
- 解析光标精确到达文件末尾，没有遗留未解析数据。

## 当前限制

- 不是可安装输入法；
- 没有 TSF DLL；
- 当前 TSV 只是开发中间格式；
- 查询器只支持带 `'` 的标准拼音精确查询；
- 尚未实现全拼切分；
- 尚未实现小鹤及其他双拼；
- 尚未实现句子解码和用户学习；
- 尚未实现符号面板和同步。

## 兼容性

- 源码目标：C++20；
- Windows 构建：Visual Studio 2022；
- 当前不引入第三方运行时库；
- Windows 工具使用静态 MSVC 运行库配置。
