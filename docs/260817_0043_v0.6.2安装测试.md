# PiInput v0.6.2-dev 安装、使用与测试

## 安装

1. 解压 `PiInput-v0.6.2-dev-windows-x64.zip`。
2. 双击 `PiInput-Install.exe`。
3. 接受 Windows 管理员权限提示。
4. 完全关闭并重新打开用于测试的编辑器。
5. 按 `Win + Space` 选择 `PiInput 中文输入法`。

## 本版测试

### 一、英文直输速度

按一下 Shift 切到英文，连续输入：

```text
the quick brown fox jumps over a lazy dog
```

重点观察每个字母是否立即出现，是否还有切到英文后特别迟滞的感觉。再按一下 Shift 切回中文，确认中文输入正常。

### 二、按 `=` 之后整词候选是否保留

输入 `kady`，先看第一行的整词候选，然后按一次 `=`。

期望：第一行整词候选原样保留，逐字候选出现在它下方，而不是把整行顶替掉。

### 三、「卡顿」首选

输入 `kady`（小鹤）或 `kadun`（全拼），首选应为「卡顿」。此前该词不在词库中，候选只能由单字拼出，首选是「卡吨」。

输入 `buquan`（全拼），首选应为「补全」。

### 四、连续中文输入

```text
我，他们。我们明天，去哪里？明天、后天！打后天。
```

标点之后继续输入文字时，组合区与候选应立即跟上。

## 卸载

在 Windows“已安装的应用”中卸载 PiInput，或运行安装目录中的 `PiInput-Uninstall.exe`。
