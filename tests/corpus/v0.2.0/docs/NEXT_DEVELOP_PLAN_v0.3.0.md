# 下一阶段开发计划：v0.3.0

## 目标

建立统一的多双拼方案描述和生成框架，使同一套音节、词语、长句、纠错和语言模型语料可以自动转换为不同双拼编码。

## 任务

1. 新增自然码双拼配置；
2. 新增微软双拼配置；
3. 新增搜狗双拼配置；
4. 新增智能 ABC、紫光和拼音加加配置；
5. 定义统一 `double_pinyin_scheme.schema.json`；
6. 将零声母、特殊韵母和自定义键位规则从脚本中完全数据化；
7. 为每种方案生成全音节覆盖、基础词、长句和纠错用例；
8. 增加编码冲突、非法组合和反向解码校验；
9. 支持用户导入自定义双拼方案；
10. 生成不同双拼方案的键位对照表和人工测试文本。

## 完成标准

- 所有方案共用同一生成器；
- 方案配置不得复制业务测试语料；
- 每个合法音节在每个方案中都能得到明确编码或明确标记为不支持；
- 零声母规则可以由配置表达；
- 生成结果可反向校验；
- v0.1.0 和 v0.2.0 的测试 ID 与数据含义保持兼容。
