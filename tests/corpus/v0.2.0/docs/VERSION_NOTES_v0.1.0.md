# v0.1.0 版本说明

## 新增

- 建立 Lite IME 测试语料的目录和版本结构；
- 新增全拼基础音节覆盖集；
- 新增小鹤双拼完整映射和零声母规则；
- 新增高频词、长句、专业词、歧义和 Unicode 语料；
- 新增状态机、字符和键盘测试用例；
- 新增双拼生成、容错生成和数据校验脚本；
- 新增人工可复制的 Markdown/TXT 测试文件。

## 重要调整

平台兼容性阶段调整为 v0.5.0；原 v0.3.0、v0.4.0、v0.5.0 分别前移为 v0.2.0、v0.3.0、v0.4.0。

## 已知限制

- 尚未连接 Lite IME 的自动化测试接口；
- 候选排名与延迟目前以记录为主；
- v0.5.0 前不对具体 Windows/macOS 物理键映射作完整断言；
- 稀有和非标准音节不纳入基础通过率。
