# v0.2.0 版本说明

## 新增

- 新增长句测试语料和候选质量字段；
- 新增 24 组上下文消歧对照语料；
- 新增切分歧义专项语料；
- 新增 PCIe/Firmware、Software/OS、Input Method 专业词表；
- 新增全拼与小鹤双拼纠错种子和自动派生用例；
- 新增模糊音 ON/OFF 成对测试；
- 新增用户词频学习、删除、重置、隐私和损坏恢复测试；
- 新增候选结果模板和 Top-K、CER、延迟评估工具；
- 新增一键生成、校验、清单和压缩包构建脚本。

## 兼容性

- 保留 v0.1.0 的稳定测试 ID 和基础语料；
- 小鹤双拼仍以 `schemes/xiaohe.json` 为唯一映射来源；
- 平台兼容性继续固定为 v0.5.0。

## 已知限制

- 尚未接入 PiInput 的真实候选接口；
- 样例评估报告仅用于验证工具链；
- 双拼模糊音行为暂按产品策略记录，不设统一通过阈值；
- 性能基线需要在测试硬件和平台确定后建立。
