# v0.2.0 测试计划

## 1. 长句与语言模型

- 连续输入完整拼音串，不插入空格；
- 记录目标整句是否为 Top-1、是否进入 Top-5；
- 记录目标排名、最终上屏文本和字符错误率；
- 对上下文消歧用例按 pair_id 成组执行；
- 同一歧义编码在不同上下文中应产生合理的排名变化。

## 2. 专业词库

- 分别统计 PCIe/Firmware、Software/OS 和 Input Method 三个领域；
- 目标词至少应可达；推荐排名阈值写入用例但不作为所有产品的绝对标准；
- 对“固件/古剑、中断/终端、地址/地质”等专业与日常同音词进行上下文对照。

## 3. 容错纠错

每个种子生成四类一次编辑错误：

- 相邻键替换；
- 漏键；
- 重复键；
- 相邻键交换。

关闭纠错时：不得崩溃、死锁、丢键或无法清空组合串。开启纠错时：记录目标候选可达性和排名，不要求所有错码必须首选命中。

## 4. 模糊音

- 每组同时执行 OFF 和 ON；
- OFF 时保持严格区分；
- ON 时目标词应可达并记录排名；
- 本版核心用例面向全拼，双拼模糊音留作产品策略扩展。

## 5. 用户学习

- 记录初始排名和重复选择后的排名；
- 检查重启持久化、删除用户词和恢复默认；
- 检查错误选择后的可恢复性；
- 密码框、隐私模式和损坏用户词典必须安全处理。

## 6. 指标

- Top-1 accuracy；
- Top-5 accuracy；
- target rank；
- exact match rate；
- character error rate；
- candidate latency p50/p95；
- correction recovery rate（接入真实引擎后计算）。

## 7. 通过标准

- P0：不得崩溃、死锁、丢键、重复上屏、泄露敏感输入或损坏用户数据；
- P1：目标候选质量、纠错、消歧和用户学习应达到项目设定阈值；
- P2：增强体验和产品可选能力，不阻塞基础版本。
