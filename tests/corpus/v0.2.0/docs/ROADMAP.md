# 开发路线图

## v0.1.0：基础正确性

- 全拼合法音节覆盖；
- 小鹤双拼映射；
- 零声母与隔音符；
- 单字、词组和基础长句；
- 中文字符、数字、标点和 ASCII；
- Backspace、Space、Enter、Escape 等基础状态机；
- 通用键盘动作定义。

## v0.2.0：语言模型和纠错（当前版本）

- 长句切分与候选质量指标；
- 同音词和切分歧义对照组；
- PCIe、固件、操作系统和输入法专业词库；
- 相邻键、漏键、重复键和交换键；
- 模糊音开关；
- 用户词频学习、删除、重置和隐私测试；
- 结果模板和自动评估脚本。

## v0.3.0：更多双拼方案

- 自然码双拼；
- 微软双拼；
- 搜狗双拼；
- 智能 ABC 双拼；
- 紫光双拼；
- 拼音加加双拼；
- 自定义双拼方案；
- 统一方案生成与反向校验。

## v0.4.0：高级功能

- V 模式；
- U 模式和部件拆字；
- 数字、日期和时间转换；
- Emoji 与符号面板；
- 辅助码；
- 联想预测和云候选；
- 隐私与用户数据清理测试扩展。

## v0.5.0：平台兼容性

- Windows 与 macOS；
- Windows 键盘、Apple 键盘和交叉使用；
- ANSI、ISO、JIS；
- QWERTY、Dvorak、Colemak；
- 全尺寸、87 键、60%/65%、笔记本和蓝牙键盘；
- Command、Option、Control、Windows、Alt、Fn/Globe；
- Windows TSF、macOS InputMethodKit 等平台接口；
- 浏览器、Office、代码编辑器、终端、聊天工具和系统输入框；
- 多显示器、高 DPI、远程桌面、睡眠唤醒和键盘重连。

> “平台兼容性”固定为 v0.5.0，后续版本不得再次提前或与通用引擎测试混合。
